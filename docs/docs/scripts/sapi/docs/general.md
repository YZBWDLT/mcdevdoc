## 坐标

### Vector3 接口

表示一个向量。

```typescript
interface Vector3 {
    x: number;
    y: number;
    z: number;
}
```

- x: number，向量的 X 坐标。
- y: number，向量的 Y 坐标。
- z: number，向量的 Z 坐标。
