## 实体&玩家运动器接口

对实体和玩家分别新增了三套不同类型的运动器接口，可用于控制实体玩家的运动轨迹：

- 轨迹运动器：用于驱动实体、玩家从一点到另一点的直线运动。
- 速度运动器：用于驱动实体、玩家根据初速度和加速度进行匀速/变速运动。
- 环绕运动器：用于驱动实体、玩家环绕指定坐标或指定实体运动。

详情请参考[实体运动器接口](/docs/docs/scripts/modapi/interfaces/entity/behavior)和[玩家运动器接口](/docs/docs/scripts/modapi/interfaces/player/behavior)。

## 自定义地形高度：增加替换节点

新增了 1 种高度控制节点：替换节点，开发者可将其配置在群系配置文件中，灵活控制和替换地形中的方块。例如下图就是使用新版的替换节点实现的效果。详情参考[这篇文档](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/4-zidingyiweidu/2-qunxidimao.html)。

## 原生 UI 控制接口补充

- 新增了一系列接口，补充了对[原生 UI](/docs/docs/scripts/modapi/interfaces/native_ui)的动态开启/关闭支持，详见接口原生 UI。
- 新增了获取和弹出所有 UI 堆栈顶的接口，覆盖支持了自定义 UI 和原生 UI 两种类型，详见接口[`GetTopUI`](/docs/docs/scripts/modapi/interfaces/custom_ui/general#gettopui)。

## UI 支持渲染方块网格体

新增了[渲染方块网格体模型接口](/docs/docs/scripts/modapi/interfaces/custom_ui/control)，支持将方块网格体数据渲染至 UI，可配合纸娃娃控件达成拖拽旋转效果。
