## 国际版对应的更新

2.11 跟进的国际版版本为 1.18.30。

## 重要功能更新

- 新增支持矩阵概念及其基本运算，详情参考`Matrix`。
- 新增陀螺仪系列接口，支持获取陀螺仪数据，控制上报频率，详情参考[`ToggleGyroSensor`](/docs/docs/scripts/modapi/interfaces/control#togglegyrosensor)等接口。
- 方块新增支持配置燃烧时长，详见[`netease:fuel`组件。](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/2-zidingyifangkuai/1-json-zujian.html)。
- 方块新增支持配置最大堆叠数量，详见[`minecraft:max_stack_size`组件。](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/2-zidingyifangkuai/1-json-zujian.html)。
- 新增根据权重控制多动画混合接口，详见[`SetAnim1DMultiControlParam`](/docs/docs/scripts/modapi/interfaces/model#setanim1dmulticontrolparam)接口。
- 新增支持动态添加后处理定义的接口，详见[`AddPostProcess`](/docs/docs/scripts/modapi/interfaces/post_process/custom#addpostprocess)。
- 后处理支持将某一 pass 处理结果传递到其他 pass 接口，详见[`PostPassResultToOtherPass`](/docs/docs/scripts/modapi/interfaces/post_process/custom#postpassresulttootherpass)。
- 屏幕拾取与射线检测等接口支持返回更精确的浮点数命中坐标，详见[`PickFacing`](/docs/docs/scripts/modapi/interfaces/control#pickfacing)、[`GetChosen`](/docs/docs/scripts/modapi/interfaces/control#getchosen)和[`getEntitiesOrBlockFromRay`](/docs/docs/scripts/modapi/interfaces/world/entity#getentitiesorblockfromray)三个接口。
- 新增一套实体 AOI 检测接口，详见[`CreateEntityAOI`](/docs/docs/scripts/modapi/interfaces/world/entity#createentityaoi)。
- 新增获取记分板记分项和玩家记分项的功能，详见[`GetAllScoreboardObjects`](/docs/docs/scripts/modapi/interfaces/world/scoreboard#getallscoreboardobjects)和[`GetAllPlayerScoreboardObjects`](/docs/docs/scripts/modapi/interfaces/world/scoreboard#getallplayerscoreboardobjects)接口。
- 新增设置玩家滑动条类设置的接口，如视野、亮度、灵敏度等等，详见[`SetSliderOption`](/docs/docs/scripts/modapi/interfaces/game_setting#setslideroption)接口。
- 新增支持自定义伤害类型，可在设置伤害[`Hurt`](/docs/docs/scripts/modapi/interfaces/entity/behavior#hurt)接口中传入伤害来源标签，并在相关的受伤事件参数中获取到对应的伤害来源标签。
- 新增一系列判断玩家控制状态的接口，详情参考[`IsCanMove`](/docs/docs/scripts/modapi/interfaces/control#iscanmove)等接口。
- 新增模拟玩家攻击生物的接口，详情参考[`PlayerAttackEntity`](/docs/docs/scripts/modapi/interfaces/player/behavior#playerattackentity)。
- Pushscreen 和 Popscreen 接口调用时现在会触发对应的 OnActive 和 OnDeactive 两个 UI 的生命周期函数，详见[界面创建流程及生命周期](https://mc.163.com/newdev/docs/mcguide/18-jiemianyujiaohu/30-ui-shuomingwendang.html)。

- <Add/> [`PlayerAttackEntity`](/docs/docs/scripts/modapi/interfaces/player/behavior#playerattackentity)（服务端），模拟玩家攻击某个生物。

## 接口调整

- <Change/> [`getEntitiesOrBlockFromRay`](/docs/docs/scripts/modapi/interfaces/world/entity#getentitiesorblockfromray)（服务端），返回值中添加精准碰撞坐标 hitPos，类型为 tuple（float,float,float）。
- <Change/> [`GetChunkMinPos`](/docs/docs/scripts/modapi/interfaces/world/map#getchunkminpos)（服务端），修复末地、下界的值异常，改用 entityId 创建组件后，即获取正常。
- <Change/> [`GetChunkMaxPos`](/docs/docs/scripts/modapi/interfaces/world/map#getchunkmaxpos)（服务端），修复末地、下界的值异常，改用 entityId 创建组件后，即获取正常。
- <Change/> [`Hurt`](/docs/docs/scripts/modapi/interfaces/entity/behavior#hurt)（服务端）， cause 类型新增 Custom 类型，新增 customTag 参数标识自定义伤害来源，可在 ActorHurtServerEvent、ActuallyHurtServerEvent、DamageEvent、PlayerHurtEvent、PlayerDieEvent、MobDieEvent 监听到标识。
- <Change/> [`GetItemBasicInfo`](/docs/docs/scripts/modapi/interfaces/item#getitembasicinfo)（服务端），物品类型添加 trident、potion、crossbow。
- <Change/> [`PickFacing`](/docs/docs/scripts/modapi/interfaces/control#pickfacing)（客户端），返回值中添加精准碰撞坐标 hitPosX、 hitPoxY、hitPosZ, 三者均为 float 类型。
- <Change/> [`GetChosen`](/docs/docs/scripts/modapi/interfaces/control#getchosen)（客户端），返回值中添加精准碰撞坐标 hitPosX、 hitPoxY、hitPosZ, 三者均为 float 类型。
- <Change/> [`GetItemBasicInfo`](/docs/docs/scripts/modapi/interfaces/item#getitembasicinfo)（客户端），物品类型添加 trident、potion、crossbow。
- <Change/> [`AddEntityMarker`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#addentitymarker)（客户端），增加是否反转 z 轴朝向。
- <Change/> [`DamageEvent`](/docs/docs/scripts/modapi/events/entity#damageevent)（服务端），新增 customTag 参数，用于接收使用 Hurt 接口传入的自定义伤害类型。
- <Change/> [`ActuallyHurtServerEvent`](/docs/docs/scripts/modapi/events/entity#actuallyhurtserverevent)（服务端），新增 customTag 参数，用于接收使用 Hurt 接口传入的自定义伤害类型。
- <Change/> [`MobDieEvent`](/docs/docs/scripts/modapi/events/entity#mobdieevent)（服务端），新增 cause 与 customTag 参数，cause 用于标明伤害来源，详见 Minecraft 枚举值文档的 ActorDamageCause，customTag 用于接收使用 Hurt 接口传入的自定义伤害类型。
- <Change/> [`PlayerHurtEvent`](/docs/docs/scripts/modapi/events/player#playerhurtevent)（服务端），新增 cause 与 customTag 参数，cause 用于标明伤害来源，详见 Minecraft 枚举值文档的 ActorDamageCause，customTag 用于接收使用 Hurt 接口传入的自定义伤害类型。
- <Change/> [`PlayerDieEvent`](/docs/docs/scripts/modapi/events/player#playerdieevent)（服务端），新增 cause 与 customTag 参数，cause 用于标明伤害来源，详见 Minecraft 枚举值文档的 ActorDamageCause，customTag 用于接收使用 Hurt 接口传入的自定义伤害类型。

- <Change/> [`StartDestroyBlockServerEvent`](/docs/docs/scripts/modapi/events/block#startdestroyblockserverevent)（服务端），新增 face 参数。
