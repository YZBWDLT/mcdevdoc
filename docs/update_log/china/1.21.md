## 重要功能更新

- 小地图增加如下更新：
  - 优化地图渲染，避免在低端机下出现明显的卡顿；
  - 支持自定义大小，同时可通过接口[`SetSize`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#setsize)动态改变大小；
  - 标记图标支持默认使用本地玩家的脸部显示，并可配置其大小与背景色，详见`MiniMap`。
  - 接口[`AddEntityMarker`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#addentitymarker)支持朝向标记；
  - 增加地图缩小放大功能，见接口[`ZoomIn`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#zoomin)和[`ZoomOut`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#zoomout)；
  - 静态标记默认保存到本地；
  - 小地图背景可在 ui json 中进行定制；
  - 更新了小地图示例`CustomMapMod`。
- 若干方块相关事件中的添加维度信息。
- 物品贴图支持使用[序列帧动画](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/1-zidingyiwupin/6-zidingyiwupintietushiyongxuliezhendonghua.html)。
- 支持动态修改物品、盔甲和方块贴图，详见[`ChangeItemTexture`](/docs/docs/scripts/modapi/interfaces/item#changeitemtexture)、[`ChangeArmorTextures`](/docs/docs/scripts/modapi/interfaces/item#changearmortextures)、[`ChangeBlockTextures`](/docs/docs/scripts/modapi/interfaces/block/render#changeblocktextures)。
- 支持[UI 控件对象](https://mc.163.com/newdev/docs/mcguide/18-jiemianyujiaohu/50-ui-kongjianduixiang.html)化开发，用法详见 UI 控件对象。
  - 实现控件基类`BaseUIControl`，包含控件的基础功能接口，详见 BaseUIControl；
  - 实现按钮控件类，继承自 BaseUIControl，除基础功能接口外包含按钮相关功能接口，详见`ButtonUIControl`；
  - 实现网格控件类，继承自 BaseUIControl，除基础功能接口外包含网格相关功能接口，详见`GridUIControl`；
  - 实现图片控件类，继承自 BaseUIControl，除基础功能接口外包含图片相关功能接口，详见`ImageUIControl`；
  - 实现文本控件类，继承自 BaseUIControl，除基础功能接口外包含文本相关功能接口，详见`LabelUIControl`；
  - 实现纸娃娃控件类，继承自 BaseUIControl，除基础功能接口外包含纸娃娃相关功能接口，详见`NeteasePaperDollUIControl`；
  - 实现进度条控件类，继承自 BaseUIControl，除基础功能接口外包含进度条相关功能接口，详见`ProgressBarUIControl`；
  - 实现滚动列表控件类，继承自 BaseUIControl，除基础功能接口外包含滚动列表相关功能接口，详见`ScrollViewUIControl`。
  - 实现开关控件类，继承自 BaseUIControl，除基础功能接口外包含开关相关功能接口，详见`SwitchToggleUIControl`。
  - 实现文本输入框控件类，继承自 BaseUIControl，除基础功能接口外包含文本输入框相关功能接口，详见`TextEditBoxUIControl`。
