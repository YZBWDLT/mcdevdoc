## 其他新增接口

- <Add/> [`PlayHudHeartBlinkAnim`](/docs/docs/scripts/modapi/interfaces/native_ui#playhudheartblinkanim)（客户端），播放原版受伤时血量变化的动画。
- <Add/> [`SetPlayerUIItem`](/docs/docs/scripts/modapi/interfaces/block/container#setplayeruiitem)（服务端），设置合成容器的物品。
- <Add/> [`AddActorGeometry`](/docs/docs/scripts/modapi/interfaces/entity/render#addactorgeometry)（客户端），增加生物渲染几何体。
- <Add/> [`RemoveActorGeometry`](/docs/docs/scripts/modapi/interfaces/entity/render#removeactorgeometry)（客户端），删除生物渲染几何体。
- <Add/> [`AddActorTexture`](/docs/docs/scripts/modapi/interfaces/entity/render#addactortexture)（客户端），增加生物渲染贴图。
- <Add/> [`RemoveActorTexture`](/docs/docs/scripts/modapi/interfaces/entity/render#removeactortexture)（客户端），删除生物渲染贴图。
- <Add/> [`SetPlayerItemInHandVisible`](/docs/docs/scripts/modapi/interfaces/player/render#setplayeriteminhandvisible)（客户端），设置是否隐藏玩家的手持物品模型显示。
- <Add/> [`GetBlockTextures`](/docs/docs/scripts/modapi/interfaces/block/render#getblocktextures)（客户端），获取方块的初始贴图信息。
- <Add/> [`SetEmoteSwitch`](/docs/docs/scripts/modapi/interfaces/native_ui#setemoteswitch)（客户端），设置表情开关。
- <Add/> [`BindModel`](/docs/docs/scripts/modapi/interfaces/effect/microsoft_particle#bindmodel)（客户端），绑定粒子发射器到骨骼模型上。
- <Add/> `GetBindingModleID`（客户端），获取粒子发射器绑定的骨骼模型 id。
- <Add/> [`AchievementCompleteEvent`](/docs/docs/scripts/modapi/events/world#achievementcompleteevent)（服务端），玩家完成自定义成就的事件。
- <Add/> [`AddPlayerCreatedClientEvent`](/docs/docs/scripts/modapi/events/world#addplayercreatedclientevent)（客户端），增加客户端其他玩家进入区块 AOI 后资源加载完成的事件。

## 接口调整

- <Change/> [`GetPlayerList`](/docs/docs/scripts/modapi/interfaces/world/entity#getplayerlist)（服务端），返回列表按照 id 进行排序。
- <Change/> [`SetAttrValue`](/docs/docs/scripts/modapi/interfaces/entity/attribute#setattrvalue)（服务端），设置值超过 float 表示范围时返回 False。
- <Change/> [`SetAttrMaxValue`](/docs/docs/scripts/modapi/interfaces/entity/attribute#setattrmaxvalue)（服务端），设置值超过 float 表示范围时返回 False。
- <Change/> [`RegisterBlockPatterns`](/docs/docs/scripts/modapi/interfaces/world/block_palette#registerblockpatterns)（服务端），已有相同 pattern 以及 defines 组合的合成时返回 False。
- <Change/> [`SetBlockNew`](/docs/docs/scripts/modapi/interfaces/world/block#setblocknew)（服务端），增加参数 isLegacy，默认为 False 即使用最新版本的 aux 对应的 state。
- <Change/> [`OnPlayerActiveShieldServerEvent`](/docs/docs/scripts/modapi/events/item#onplayeractiveshieldserverevent)（服务端），在潜行状态切换盾牌也会触发该事件。
- <Change/> [`StartRidingClientEvent`](/docs/docs/scripts/modapi/events/entity#startridingclientevent)（客户端），删除 cancel 参数，客户端触发事件时，玩家已经上马。

## 废弃

- <Change/> UnDefineEvent，监听自定义事件前不再需要 DefineEvent，所以也不再需要使用 UnDefineEvent。
