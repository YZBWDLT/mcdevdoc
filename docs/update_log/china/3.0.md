## 重要功能更新

- 支持获取实体的 NBT 标签，现在可以直接访问游戏中实体的 NBT 字典，并直接生成带有 NBT 标签的实体。详见[`GetEntityNBTTags`](/docs/docs/scripts/modapi/interfaces/entity/type#getentitynbttags)和[`CreateEngineEntityByNBT`](/docs/docs/scripts/modapi/interfaces/world/entity#createengineentitybynbt)接口。示例 Demo 与内容库也新增了对应的 Demo：自定义精灵蛋。
- 现在可以动态设置一个坐标或一片方块区域的群系，可用于改变群系效果，生物刷新规则等，详见[`SetBiomeByPos`](/docs/docs/scripts/modapi/interfaces/world/map#setbiomebypos)、[`SetBiomeByPosList`](/docs/docs/scripts/modapi/interfaces/world/map#setbiomebyposlist)、[`SetBiomeByVolume`](/docs/docs/scripts/modapi/interfaces/world/map#setbiomebyvolume)等接口。
- 使用[`GetBonePositionFromMinecraftObject`](/docs/docs/scripts/modapi/interfaces/model#getbonepositionfromminecraftobject)接口，您可以直接获取原版模型的骨骼世界坐标。有效增强物理交互与表现，进一步提高开发上限。
- 利用[`SetBiomeInfo`](/docs/docs/scripts/modapi/interfaces/world/map#setbiomeinfo)与[`GetBiomeInfo`](/docs/docs/scripts/modapi/interfaces/world/map#getbiomeinfo)，现在可以动态改变群系的气候，决定是否降雪或者降雨。
- 自定义物品新增[堆肥组件](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/1-zidingyiwupin/1-zidingyijichuwupin.html)。
- 自定义方块[挖掘组件](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/2-zidingyifangkuai/1-json-zujian.html)新增锄速度加成属性。

## 其他新增接口

- <Add/> [`IsTouchWithMouse`](/docs/docs/scripts/modapi/interfaces/control#istouchwithmouse)（客户端），获取是否正在使用鼠标点击模拟触屏。
- <Add/> [`CreateEngineEntityByNBT`](/docs/docs/scripts/modapi/interfaces/world/entity#createengineentitybynbt)（服务端），根据 nbt 数据创建实体。
- <Add/> [`SetBiomeInfo`](/docs/docs/scripts/modapi/interfaces/world/map#setbiomeinfo)（服务端），设置群系天气相关参数，受引擎限制，目前 snowAccumulation 参数没有效果,downfall 目前只影响湿度。
- <Add/> [`GetBiomeInfo`](/docs/docs/scripts/modapi/interfaces/world/map#getbiomeinfo)（服务端），获取群系天气相关参数。
- <Add/> [`SetBiomeByPos`](/docs/docs/scripts/modapi/interfaces/world/map#setbiomebypos)（服务端），增加设置生物群系接口。
- <Add/> [`SetBiomeByPosList`](/docs/docs/scripts/modapi/interfaces/world/map#setbiomebyposlist)（服务端），增加设置生物群系接口。
- <Add/> [`SetBiomeByVolume`](/docs/docs/scripts/modapi/interfaces/world/map#setbiomebyvolume)（服务端），增加设置生物群系接口。
- <Add/> [`GetEntityNBTTags`](/docs/docs/scripts/modapi/interfaces/entity/type#getentitynbttags)（服务端），获取实体的 NBT 标签。
- <Add/> [`PlayCustomUIMusic`](/docs/docs/scripts/modapi/interfaces/audio#playcustomuimusic)（客户端），播放 UI 音效，包括原版音效及自定义音效。
- <Add/> [`SetBlockRenderDistance`](/docs/docs/scripts/modapi/interfaces/block/render#setblockrenderdistance)（客户端），设置玩家周围区块的可渲染距离，无法超过视频设置中的能见度限制。
- <Add/> [`GetBlockRenderDistance`](/docs/docs/scripts/modapi/interfaces/block/render#getblockrenderdistance)（客户端），获取玩家周围的可渲染距离。
- <Add/> [`GetBonePositionFromMinecraftObject`](/docs/docs/scripts/modapi/interfaces/model#getbonepositionfromminecraftobject)（客户端），获取原版模型的骨骼世界坐标。

## 接口调整

- <Change/> [`SetAttrValue`](/docs/docs/scripts/modapi/interfaces/entity/attribute#setattrvalue)（服务端），新增对 AttrType.ARMOR 的支持。
- <Change/> `AddBlockItemListenForUseEvent`（服务端）， auxvalue 默认值从 0 改为*。
- <Change/> `RemoveBlockItemListenForUseEvent`（服务端）， auxvalue 默认值从 0 改为*。
- <Change/> [`SetMobStrengthMax`](/docs/docs/scripts/modapi/interfaces/entity/attribute#setmobstrengthmax)（服务端），增加的接口特殊情况说明：由于引擎限制，在羊驼被打时候会 reload 组件，strengthMax 会恢复成 llama.json 中的配置值（`minecraft:strength`）。
- <Change/> [`LocateStructureFeature`](/docs/docs/scripts/modapi/interfaces/world/map#locatestructurefeature)（服务端），支持只在未生成的区块中查找。
- <Change/> [`LocateNeteaseFeatureRule`](/docs/docs/scripts/modapi/interfaces/world/map#locateneteasefeaturerule)（服务端），支持获取未生成区块的地物结构。
- <Change/> [`SetPlayerGameType`](/docs/docs/scripts/modapi/interfaces/player/game_mode#setplayergametype)（服务端），新增对旁观模式的支持。
- <Change/> [`ChangeArmorTextures`](/docs/docs/scripts/modapi/interfaces/item#changearmortextures)（客户端），修复 uiIconTexture 不支持 None 和""的问题。
- <Change/> [`SetEntityRenderDistance`](/docs/docs/scripts/modapi/interfaces/entity/render#setentityrenderdistance)（客户端），实现调整为不影响方块的渲染距离。
- <Change/> `AddBlockItemListenForUseEvent`（客户端）， auxvalue 默认值从 0 改为*。
- <Change/> `RemoveBlockItemListenForUseEvent`（客户端）， auxvalue 默认值从 0 改为*。
- <Change/> [`SetCameraAnchor`](/docs/docs/scripts/modapi/interfaces/player/camera#setcameraanchor)（客户端），修复交互中心第一人称下没有跟随偏移的 BUG。
- <Change/> [`BindModelToEntity`](/docs/docs/scripts/modapi/interfaces/model#bindmodeltoentity)（客户端），新增 scale 参数控制挂接的模型缩放。
- <Change/> [`PlayerAttackEntityEvent`](/docs/docs/scripts/modapi/events/player#playerattackentityevent)（服务端），新增 isCrit 参数，用于判断本次攻击是否产生暴击。
- <Change/> [`DestroyBlockEvent`](/docs/docs/scripts/modapi/events/block#destroyblockevent)（服务端），新增掉落物实体 id 列表。
- <Change/> [`PlayerFeedEntityServerEvent`](/docs/docs/scripts/modapi/events/player#playerfeedentityserverevent)（服务端），调整备注，新增使用时注意事项。
- <Change/> [`EntityDieLoottableServerEvent`](/docs/docs/scripts/modapi/events/entity#entitydieloottableserverevent)（服务端），支持修改 itemDict 中的 userData,userData 必须为 NBT 数据格式，格式可参考 NBT 数据格式。

## 修复

- <Fix/> [`SetMobStrength`](/docs/docs/scripts/modapi/interfaces/entity/attribute#setmobstrength)（服务端），修复当羊驼被打时候，强度值恢复。修复强度值没有存档。
