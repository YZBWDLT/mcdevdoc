# 3.4（国际版 1.21.0）

网易在 2025 年 5 月 22 日上线 3.4，版本号为 V3.4 BE1.21.00，包含 Mod PC 包、手机测试版启动器与服务器引擎。这是中国版自 2017 年代理以来首次在次版本上与国际版保持一致。

> **注意**：本文原本是面向双端开发者的国际版更新汇总。随着本站的更新日志体系调整，国际版的内容已拆分为独立的前瞻文章，本文改为记录网易端的更新。

## 国际版对应的更新

3.4 跟进的国际版版本为 1.21.0，此前还合并了 1.20.60、1.20.70 与 1.20.80 的内容，国际版侧从狼铠到试炼密室都有涉及。

## 自定义容器

3.4 最重要的更新是新增的自定义容器，开发者可以实现自定义容器界面，支持配置其他方块组件（如自定义实体方块组件）、容器名、交互时打开的自定义 UI，以及自定义容器的大小。

- <Add/> 新增 [`PlayerTryPutCustomContainerItemServerEvent`](/docs/docs/scripts/modapi/events/item#playertryputcustomcontaineritemserverevent)（服务端），用于监听玩家将物品放入自定义容器。

## 客户端交互逻辑

`ClientItemTryUseEvent`、`ClientItemUseOnEvent`与`ClientBlockUseEvent`三个事件做了逻辑性调整。

- <Change/> 三个事件 cancel 时即可取消使用，无需服务端再次 cancel，且服务端事件将不再触发。
- <Change/> `ClientItemTryUseEvent`事件设置 cancel 为 `True`后，不再会向服务端同步物品使用网络包。
- <Change/> `ClientItemUseOnEvent`事件设置 ret 为 `True`后，不再会向服务端同步物品使用网络包。
- <Change/> `ClientBlockUseEvent`拦截交互逻辑时，不再会向服务端发送网络包。

## 相机与视角

- <Change/> `LockCamera`（客户端）的 lockRot 支持 roll 旋转。
- <Change/> `AddCameraTrackMotion`（客户端）的 targetRot 与 startRot 支持 roll 旋转。
- <Add/> 新版视角切换按钮贴图位于 `/textures/ui/perspective.png`，材质包开发者需要提前适配。

## 其他新增接口

- <Add/> [`GetIntPos`](/docs/docs/scripts/modapi/interfaces/general/math#getintpos)（服务端、客户端），获取坐标所在方块的位置。
- <Add/> [`GetHostPlayerId`](/docs/docs/scripts/modapi/interfaces/general/tool#gethostplayerid)（服务端、客户端），获取房主的 entityId。
- <Add/> [`GetPlayerCurrentExhaustionValue`](/docs/docs/scripts/modapi/interfaces/player/attribute#getplayercurrentexhaustionvalue)（服务端），获取玩家当前消耗度。
- <Add/> [`SetPlayerCurrentExhaustionValue`](/docs/docs/scripts/modapi/interfaces/player/attribute#setplayercurrentexhaustionvalue)（服务端），设置玩家当前消耗度。
- <Add/> [`IsOfficialSkin`](/docs/docs/scripts/modapi/interfaces/player/attribute#isofficialskin)（客户端），获取玩家穿戴的皮肤是否为官方 4D 皮肤。
- <Add/> [`IsHighLevelOfficialSkin`](/docs/docs/scripts/modapi/interfaces/player/attribute#ishighlevelofficialskin)（客户端），获取玩家穿戴的皮肤是否为史诗及以上的官方 4D 皮肤。
- <Add/> [`IsHighLevelMultiJointOfficialSkin`](/docs/docs/scripts/modapi/interfaces/player/attribute#ishighlevelmultijointofficialskin)（客户端），获取玩家穿戴的皮肤是否为史诗及以上的多关节官方 4D 皮肤。
- <Add/> [`GetPropertyBag`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#getpropertybag)（客户端），获取 PropertyBag。
- <Add/> [`SetPropertyBag`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#setpropertybag)（客户端），设置 PropertyBag。

## 其他接口调整

- <Change/> [`SpawnResources`](/docs/docs/scripts/modapi/interfaces/world/entity#spawnresources)（服务端）新增是否生成经验球参数，默认为 `False`，设成 `True` 时按原版采集逻辑进行经验球掉落，如矿石类方块会产生随机数量的经验球。
- <Change/> [`GetItemBasicInfo`](/docs/docs/scripts/modapi/interfaces/item#getitembasicinfo)（服务端、客户端）新增字段 `enchant_slot_type`。
- <Change/> [`GetActorRenderParams`](/docs/docs/scripts/modapi/interfaces/entity/render#getactorrenderparams)（客户端）修复返回数据。
- <Change/> [`BlockStrengthChangedServerEvent`](/docs/docs/scripts/modapi/events/block#blockstrengthchangedserverevent)（服务端）新增变化前的红石信号量参数。
- <Change/> [`BlockAnimateRandomTickEvent`](/docs/docs/scripts/modapi/events/block#blockanimaterandomtickevent)（客户端）新增 blockName 与 auxData 参数。
- <Change/> `ActorDamageCause`枚举中微软把 `suicide` 改成了 `self_destruct`。
- <Change/> `OriginGUIName`增加摄像机视角按钮。

## 修复

- <Fix/> 方块实体模型的渲染消失问题。现在将根据 `netease:aabb` 组件中 clip 字段作为裁减碰撞盒，开发者可以自行配置该字段大小控制模型显示大小。
- <Fix/> `ServerBlockUseEvent`（服务端）在客户端对应事件开启拦截开关时不再触发。
- <Fix/> `ServerItemTryUseEvent`（服务端）在 `ClientItemTryUseEvent`的 cancel 设置为 `True`时不再触发。
- <Fix/> `ServerItemUseOnEvent`（服务端）在 `ClientItemUseOnEvent`设置 ret 为 `True`时不再触发。

## 适配提醒

微软在 1.21.00 继续修改了部分方块 ID，如树叶、台阶等，详见 3.4 版本物品 ID 变更，相关链接请参阅基岩版扁平化，开发者需要注意适配。
