网易于 2023 年 6 月 21 日上线 2.7，版本号为 V2.7 BE1.18.30，包含 Mod PC 包、手机测试版启动器与服务器引擎。照例，我们进行一些关键性的内容总结。读者可以查看网易的官方文档：

<Button text="我的世界开发者官网" url="https://mc.163.com/newdev/docs/api/gengxinxinxi/2.7.html"/>

## 国际版对应的更新

2.7 跟进的国际版版本为 1.18.30。

<WikiButton item="基岩版1.18.30"/>

## 支持 UI 设置到世界坐标

- 在[CreateUI 接口](/docs/docs/scripts/modapi/interfaces/custom_ui/general)的参数中新增了绑定到世界坐标的参数，支持设置 UI 到指定坐标，详情参考 CreateUI 接口。

## 支持渲染指定掉落物

- 新增[AddDropItemToWorld 接口](/docs/docs/scripts/modapi/interfaces/block/render)，将指定掉落物添加到指定坐标，详情参考 AddDropItemToWorld 接口。

## 自定义大型特征

- 新增拼图方块、自定义大型特征和结构池的数据驱动 json，用于实现跨多个区块的大型随机特征（如原版村庄）效果，详情参考[这篇文档](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/4-zidingyiweidu/6-zidingyidaxingtezheng.html)。

## 中国版粒子支持拖尾渲染器

- 中国版粒子新增拖尾渲染模块，实现条带拖尾特效，详情请参考[中国版粒子特效说明文档](https://mc.163.com/newdev/docs/mcguide/16-meishu/9-texiao/70-zhongguobantexiaoshuxingxiangxishuoming.html)。

## UI 新增轮盘控件

- UI 新增了一种轮盘控件，可用于自定义轮盘菜单，详情请参考[轮盘控件说明文档](https://mc.163.com/newdev/docs/mcguide/18-jiemianyujiaohu/30-ui-shuomingwendang.html)。

## 自定义箱子

- 方块配置新增自定义箱子组件，可使方块具有箱子的储物功能，支持自定义容量，[方块 Json 组件文档](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/2-zidingyifangkuai/1-json-zujian.html)。

## 自定义树叶

- 新增了`netease:no_crop_face_block`组件，使其在相邻面渲染一个面，实现原版树叶方块的效果，详情请参考[方块 Json 组件文档](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/2-zidingyifangkuai/1-json-zujian.html)。

## 自定义工作台

- 新增了[自定义工作台](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/2-zidingyifangkuai/3-teshufangkuai/10-zidingyigongzuotai.html)组件，可让方块具有工作台的特性，支持自定义该工作台的专属配方，详情参考自定义工作台。

## 自定义随机偏移方块

- 新增随机偏移组件`netease:block_random_offset`，使方块放置时可自定义随机偏移范围，详情参考[方块 Json 组件文档](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/2-zidingyifangkuai/1-json-zujian.html)。

## 其他更新

- 相机支持设置翻滚角，详见`SetCameraRot`。
- 与自定义物品类似，自定义方块也支持 customtips 组件了，详见[方块 Json 组件文档](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/2-zidingyifangkuai/1-json-zujian.html)。
- 自定义属性接口现在支持存档了，详见[`SetAttr`](/docs/docs/scripts/modapi/interfaces/entity/custom_attribute#setattr)接口。
- 新增了官方聊天扩展的 5 个功能接口，用于开发者定制聊天功能，详见[`RegisterChatPrefix`](/docs/docs/scripts/modapi/interfaces/entity/chat#registerchatprefix)。

> **注意**：上述聊天扩展接口仅在全渠道上线后方能生效！

## 接口调整

- <Change/> [`CreateUI`](/docs/docs/scripts/modapi/interfaces/custom_ui/general#createui)（客户端），添加了 bindWorldPosition 参数用于绑定世界坐标。
- <Change/> [`LobbyGetAchievementStorage`](/docs/docs/scripts/modapi/interfaces/achievement#lobbygetachievementstorage)（服务端），支持在网络服使用。
- <Change/> [`LobbySetAchievementStorage`](/docs/docs/scripts/modapi/interfaces/achievement#lobbysetachievementstorage)（服务端），支持在网络服使用。
- <Change/> [`SpawnItemToPlayerInv`](/docs/docs/scripts/modapi/interfaces/player/container#spawnitemtoplayerinv)（服务端），当附魔信息错误时，无法生成物品，返回 False。调整前为会生成一个没有附魔的物品。
- <Change/> [`SetPlayerAllItems`](/docs/docs/scripts/modapi/interfaces/player/container#setplayerallitems)（服务端），当附魔信息错误时，无法生成物品，返回 False。调整前为会生成一个没有附魔的物品。
- <Change/> [`SetAttr`](/docs/docs/scripts/modapi/interfaces/entity/custom_attribute#setattr)（服务端），新增 needRestore 参数用于自动存档并在实体加载时恢复。
- <Change/> `SetCameraRot`（客户端），支持设置 Roll（翻滚角）的角度。

## 修复


当使用[物品信息字典](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/10-jibengainian/1-wodeshijiejichugainian.html)时，如果 enchantData 里的附魔等级超过该附魔的最高等级，将会导致对该物品的生成（如 SpawnItemToPlayerInv）和设置（如 SetEntityItem）等接口失败。在此版本之前，会生成一个无附魔的物品。
