## 国际版对应的更新

2.8 跟进的国际版版本为 1.18.30。

<WikiButton item="基岩版1.18.30"/>

## 模型与材质

- 骨骼模型支持多材质，新增支持隐藏指定的骨骼的接口，详情参考[模型使用多材质和贴图](/mcguide/16-美术/6-模型和动作/04-骨骼模型的使用#7. 模型使用多个材质及贴图)。
- 图中演示了模型头部单独设置材质，隐藏了一只翅膀。
- 骨骼模型支持多 pass 材质，详情参考[骨骼模型配置多 pass](https://mc.163.com/newdev/docs/mcguide/16-meishu/6-moxinghedongzuo/04-gugemoxingdeshiyong.html)。
- 图片演示了多 pass 的基础描边效果。
- 新增自定义老电视后处理效果、自定义扫描效果，新增设置[自定义后处理](https://mc.163.com/newdev/docs/mcguide/16-meishu/7-caizhiyuzhuoseqi/4-caizhishizhan.html)接口[`SetEnableByName`](/docs/docs/scripts/modapi/interfaces/post_process/custom#setenablebyname)，详情参考文档自定义后处理。
- 老电视机滤镜效果。
- 扫描效果。
- 更新了材质使用相关的教学文档，详情参考[材质介绍与着色器入门教程](https://mc.163.com/newdev/docs/mcguide/16-meishu/7-caizhiyuzhuoseqi/1-caizhijieshaoyuzhuoseqirumen.html)。
- 优化了官方已有材质、shader 的结构和格式。

## 粒子特效

- 粒子特效支持自定义材质，详见[中国版特效属性详细说明](https://mc.163.com/newdev/docs/mcguide/16-meishu/9-texiao/70-zhongguobantexiaoshuxingxiangxishuoming.html)。
- 中国版粒子的发射路径支持旋转，详见[中国版特效属性详细说明](https://mc.163.com/newdev/docs/mcguide/16-meishu/9-texiao/70-zhongguobantexiaoshuxingxiangxishuoming.html)。

## UI

- 图片控件支持旋转，详情参考[属性动画](https://mc.163.com/newdev/docs/mcguide/18-jiemianyujiaohu/30-ui-shuomingwendang.html)。
- UI 动画管理系列接口，可动态注册、添加、移除、播放 UI 动画，详情参考[属性动画](https://mc.163.com/newdev/docs/mcguide/18-jiemianyujiaohu/19-kongjianshuxingdonghua.html)。

## 玩家摄像机

- 新增交互球心、交互距离接口，可自由控制玩家的交互中心和可交互长度，详情参考[`SetPickCenterOffset`](/docs/docs/scripts/modapi/interfaces/player/behavior#setpickcenteroffset)等接口。
- 下图演示了交互中心向后偏移的效果。
- 支持关闭相机弹簧功能，可动态关闭[`SetCameraDistanceFixed`](/docs/docs/scripts/modapi/interfaces/player/camera#setcameradistancefixed)接口。

## 方块

- 支持 colormap 对指定维度生效，详情参考[自定义方块群系颜色](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/2-zidingyifangkuai/2-gongneng.html)。
- 下图演示了同一方块不同群系的颜色不同。

## 游戏控制与管理

- 修复了手柄模式下无法正常点击自定义 UI 按钮的问题。
- 新增手柄按键、扳机、摇杆事件，详见[`OnGamepadKeyPressClientEvent`](/docs/docs/scripts/modapi/events/control#ongamepadkeypressclientevent)等接口。
- 新增获取键盘、手柄的按键映射关系的接口，详见[`GetControllerLayout`](/docs/docs/scripts/modapi/interfaces/game_setting#getcontrollerlayout)接口。
- 新增锁定玩家修改游戏模式与规则权限的接口，详见[`LockGameRulesInfo`](/docs/docs/scripts/modapi/interfaces/world/game_rules#lockgamerulesinfo)和[`IsLockGameRulesInfo`](/docs/docs/scripts/modapi/interfaces/world/game_rules#islockgamerulesinfo)接口。
- 新增射线检测实体与方块接口，详见[`getEntitiesOrBlockFromRay`](/docs/docs/scripts/modapi/interfaces/world/entity#getentitiesorblockfromray)接口。
