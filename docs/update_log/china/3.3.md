## 重要功能更新

- 新增三类微软模型内置材质：描边、金属光泽、忽略光照，开发者可通过简单的参数配置实现高级渲染效果，详见[原版实体附加材质](https://mc.163.com/newdev/docs/mcguide/16-meishu/7-caizhiyuzhuoseqi/2-neizhicaizhiqingdan.html)。
- [自定义指令](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/9-zidingyizhiling.html)现支持参数变体配置，可在不开启作弊的情况下使用指令，并新增了一些参数类型。
- 支持播放方块/物品破坏粒子，以及物品被食用时的粒子，可用于增强游戏表现效果，实现加工、锻造等场景的完整视觉反馈链条。例如：机械动力中在传送带上压铸道具，农夫乐事砧板切碎食材等。
- 我们重新设计了底层数据协议，原生支持 Python 基础数据类型的直接存储和传输，包括 long、tuple、set 和 frozenset，便于开发者存储和传输复杂数据结构（如方块调色板）。涉及接口包括 SetConfigData、GetConfigData、Mod SDK 双端通信接口、Apollo 通信接口等。请不要在 3.3 存储含有 tuple 等数据后，在 3.2 旧版读取并再次存储，将导致数据格式错误。
- 新增物品组件[`netease:initial_user_data`](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/1-zidingyiwupin/1-zidingyijichuwupin.html)，用于指定在创造物品栏中注册的初始 NBT 数据，简化如自带附魔的物品或特殊属性道具的注册流程。
- 新增方块组件[`netease:block_animate_random_tick`](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/2-zidingyifangkuai/1-json-zujian.html)，该组件可方便地实现如落叶飘落、粒子飞散等效果，并对性能无明显影响。
- 新增维度组件[`netease:ban_vanilla_structure`](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/4-zidingyiweidu/1-zidingyiweidu.html)，用于灵活地屏蔽原版结构生成。
- 新增获取游戏版本号的接口，便于开发者提前向未来版本兼容。
- 新增获取/设置剪贴板内容的接口，便于外部软件与游戏内组件交互。
- [`ServerEntityTryPlaceBlockEvent`](/docs/docs/scripts/modapi/events/block#serverentitytryplaceblockevent)新增点击位置参数，支持修改位置和方块数据，开发者可通过事件参数动态调整方块属性和坐标，实现更精准的方块放置逻辑，便于制作自定义半砖、楼梯等方块。
- 所有[伤害事件](/docs/docs/scripts/modapi/events/entity)参数统一为 float 类型，并优化计算管线。请开发者注意“补偿伤害”的处理，避免将其视为真正伤害。
- 支持纯客户端实体，允许在客户端根据资源包定义直接显示实体模型，无需对应的服务端实体。
- 更新[UI 说明文档](https://mc.163.com/newdev/docs/mcguide/18-jiemianyujiaohu/30-ui-shuomingwendang.html)、[UI 数据绑定](https://mc.163.com/newdev/docs/mcguide/18-jiemianyujiaohu/70-ui-shujubangding.html)、[自定义配方](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/5-zidingyipeifang.html)、[性能监测与调试](https://mc.163.com/newdev/docs/mcguide/30-ceshi/5-xingnengjianceyutiaoshigongju.html)、[机器审核流程及指标介绍](https://mc.163.com/newdev/docs/mcguide/36-shenheyuxiajia/kecheng-03-jiqishenheliuchengjizhibiaojieshao.html)、[优化字节码](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/18-xingnengyouhua/daimayouhua.html)等文档，后续将持续更新更多教程，敬请期待。
- 为便于开发者搜索接口，[Preset API](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/14-yushewanfabiancheng/13-PresetAPI/gengxinxinxi/2.4.0.html)已移动至开发指南中。

- <Add/> [`CreateClientEntityByTypeStr`](/docs/docs/scripts/modapi/interfaces/world/entity#createcliententitybytypestr)（客户端），创建客户端实体，仅用于渲染。

- <Add/> [`GetLoadEffects`](/docs/docs/scripts/modapi/interfaces/entity/effect#getloadeffects)（服务端），获取所有已加载的状态效果。

- <Add/> [`RemoveTerrainDestroyParticleEffect`](/docs/docs/scripts/modapi/interfaces/world/render#removeterraindestroyparticleeffect)（客户端），停止指定位置播放的方块被开始破坏时的粒子效果。
- <Add/> [`GetLocalTime`](/docs/docs/scripts/modapi/interfaces/world/time#getlocaltime)（客户端），获取当前维度的时间。
- <Add/> [`SetClipboardContent`](/docs/docs/scripts/modapi/interfaces/general/tool#setclipboardcontent)（客户端），设置系统剪贴板内容。
- <Add/> [`GetClipboardContent`](/docs/docs/scripts/modapi/interfaces/general/tool#getclipboardcontent)（客户端），获取系统剪贴板内容。
- <Add/> [`AddUseItemParticleEffect`](/docs/docs/scripts/modapi/interfaces/world/render#adduseitemparticleeffect)（客户端），在指定位置播放指定物品被开始使用时的粒子效果。
- <Add/> [`RemoveUseItemParticleEffect`](/docs/docs/scripts/modapi/interfaces/world/render#removeuseitemparticleeffect)（客户端），停止指定位置播放的物品被开始使用时的粒子效果。
- <Add/> [`IsOnLadder`](/docs/docs/scripts/modapi/interfaces/player/behavior#isonladder)（客户端），获取玩家是否在梯子/藤蔓上。
- <Add/> [`IsInScaffolding`](/docs/docs/scripts/modapi/interfaces/player/behavior#isinscaffolding)（客户端），获取玩家是否在脚手架中。
- <Add/> [`CustomCommandTriggerServerEvent`](/docs/docs/scripts/modapi/events/world#customcommandtriggerserverevent)（服务端），新增参数变体返回参数。
- <Add/> [`MountTamingEvent`](/docs/docs/scripts/modapi/events/player#mounttamingevent)（服务端），玩家通过骑乘驯服生物事件。
- <Add/> [`PlayerAttackEntityEvent`](/docs/docs/scripts/modapi/events/player#playerattackentityevent)（客户端），客户端新增玩家攻击实体事件，只有本地玩家会触发。
- <Add/> [`BlockAnimateRandomTickEvent`](/docs/docs/scripts/modapi/events/block#blockanimaterandomtickevent)（客户端），客户端新增类似樱花树叶/末地烛的随机动效 Tick 事件。
- <Add/> [`HudButtonChangedClientEvent`](/docs/docs/scripts/modapi/events/ui#hudbuttonchangedclientevent)（客户端），当原生 HUD 按钮位置或大小改变时触发。

## 接口调整

- <Change/> `SetHurtByEntity`（服务端）， damage 改为浮点型。

- <Change/> [`WillAddEffectServerEvent`](/docs/docs/scripts/modapi/events/entity#willaddeffectserverevent)（服务端）， damage 改为浮点型。
- <Change/> [`RefreshEffectServerEvent`](/docs/docs/scripts/modapi/events/entity#refresheffectserverevent)（服务端）， damage 改为浮点型。
- <Change/> [`ActorHurtServerEvent`](/docs/docs/scripts/modapi/events/entity#actorhurtserverevent)（服务端）， damage 改为浮点型。
- <Change/> [`EntityEffectDamageServerEvent`](/docs/docs/scripts/modapi/events/entity#entityeffectdamageserverevent)（服务端）， damage 改为浮点型。
- <Change/> [`BlockDestroyByLiquidServerEvent`](/docs/docs/scripts/modapi/events/block#blockdestroybyliquidserverevent)（服务端），添加维度信息。

- <Change/> [`OriginGUIName`](/docs/docs/scripts/modapi/enums#originguiname)，增加新触控破坏/攻击按钮、建造/交互按钮、新触控摇杆按钮。
