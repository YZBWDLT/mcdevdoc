## 国际版对应的更新

2.6 跟进的国际版版本为 1.18.30。

<WikiButton item="基岩版1.18.30"/>

## 特效

- 在原版微软粒子的基础上支持发射骨骼模型，并且支持纹理和动画，详情请参考[这篇文档](https://mc.163.com/newdev/docs/mcguide/16-meishu/9-texiao/21-yuanbantexiaoshuxingxiangxishuoming.html)。

## 实体

- 在现有坐骑的接口上，新增了坐骑座位的增删改、骑乘者更换座位、锁定座位等接口，帮助开发者更便捷地实现丰富的骑乘效果。详情请参考[这篇文档](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/3-zidingyishengwu/05-shiyong-api-zidingyizuoqi.html)。
- 环绕实体运动器系列接口支持指定环绕半径，详情参考接口[添加环绕实体运动器](/docs/docs/scripts/modapi/interfaces/entity/behavior)。
- 轨迹运动器系列接口支持起始角度和目标角度，详情参考接口[添加轨迹运动器](/docs/docs/scripts/modapi/interfaces/entity/behavior)。
- 上述优化对实体、玩家、相机的运动器接口均生效。

## UI

- 网易版纸娃娃（NeteasePaperDoll）控件现在支持绕 X、Z 轴的拖拽旋转，详见下图：
- 为了帮助开发者更好地定制全新的 UI，本次新增了更多模拟[原生 UI](/docs/docs/scripts/modapi/interfaces/native_ui)操作的接口，详情见原生 UI 接口。
- 对暂停界面，背包界面等原生界面，现在不仅支持在他们之上添加自定义的控件，并且支持以`ScreenNode`对象管理他们，对他们进行直接修改，详见[原生界面修改](https://mc.163.com/newdev/docs/mcguide/18-jiemianyujiaohu/61-yuanshengjiemianxiugaiwendang.html)。
- 支持使用接口动态创建删除控件，而不是仅仅通过克隆控件的方式，详见[`CreateChildControl`](/docs/docs/scripts/modapi/interfaces/custom_ui/screen#createchildcontrol)以及[`RemoveChildControl`](/docs/docs/scripts/modapi/interfaces/custom_ui/screen#removechildcontrol)接口。
- 支持全局获取当前顶层界面的`ScreenNode`管理对象，详见[`GetTopUINode`](/docs/docs/scripts/modapi/interfaces/custom_ui/general#gettopuinode)接口。
- 富文本控件现在支持换行标签，详情参考[富文本控件介绍](https://mc.163.com/newdev/docs/mcguide/18-jiemianyujiaohu/30-ui-shuomingwendang.html)。
- 新增接口[`GetToggleState`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#gettogglestate)获取开关控件（toggle）的开关状态。
- 新增接口[`GetGridItem`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#getgriditem)获取网格控件（grid）的子节点。
- 新增接口[`GetScrollViewPercentValue`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#getscrollviewpercentvalue)获取滚动列表（scroll_view）的滚动条百分比。
- 将原有的 UI 控件示例模板按照控件的功能拆分为多个脚本，优化了代码的布局和注释。
- 详情可在内容库中查看 UI 控件示例，如下图所示。

## 物品

- `netease:render_offset`组件以前仅支持可蓄力物品，现在它可以对任意类型的自定义物品生效了。
- 此前多个 mod 使用同名物品分页会出现冲突，现在使用同名物品分页的 mod 物品会被合并显示在同一个分页下了。

## 方块

- 方块调色板系列接口支持剔除空气方块，详情参考接口[`GetBlockPaletteBetweenPos`](/docs/docs/scripts/modapi/interfaces/world/block_palette#getblockpalettebetweenpos)。

## 玩家

- 修改相机锚点和偏移时，会同步修改玩家的交互范围，避免了调整相机后选取方块的偏移问题，详见[`SetCameraOffset`](/docs/docs/scripts/modapi/interfaces/player/camera#setcameraoffset)和[`SetCameraAnchor`](/docs/docs/scripts/modapi/interfaces/player/camera#setcameraanchor)。
- 修复了渲染指定玩家皮肤时，会影响到其他同款皮肤玩家的问题。

## 其他更新

- 现在 mod 脚本运行出现报错时，将会打印到玩家设备中，玩家反馈模组问题时，可勾选上传此日志，开发者便可在开发者平台下载和查看该日志。
- 日志打印功能默认关闭，开发者需要通过[`SetMcpModLogCanPostDump`](/docs/docs/scripts/modapi/interfaces/general/debug#setmcpmodlogcanpostdump)接口开启该脚本的日志打印功能，接口对每个 mod 脚本（MCP）独立生效。
- 开启此功能后，除了代码报错会被打印，开发者也可以使用接口[`PostMcpModDump`](/docs/docs/scripts/modapi/interfaces/general/debug#postmcpmoddump)自定义打印 MCP 日志，此日志也会打印到玩家设备，并通过反馈上传到开发者的组件后台。
- 注意事项：
- 此功能依赖玩家客户端和开发者平台的更新，仅在全渠道上线后方可生效。
- 请勿打印过多自定义日志信息，避免玩家的存档大小快速膨胀，影响玩家对模组的体验。
- 日志在玩家本地只保留 7 天，超期日志自动清理。
- 在接口文档中增加了所有接口和事件的文档，供开发者在同一页面进行浏览和搜索，详见[Api 索引表](/docs/docs/scripts/modapi/overview)和[事件索引表](https://mc.163.com/newdev/docs/api/shijian/shijiansuoyinbiao.html)。
