## 国际版对应的更新

2.9 跟进的国际版版本为 1.18.30。

<WikiButton item="基岩版1.18.30"/>

## 材质与着色器

- 支持原版 BB 模型自定义 shader 的 Uniform 参数，实现动态材质表现，详见[`SetEntityExtraUniforms`](/docs/docs/scripts/modapi/interfaces/entity/render#setentityextrauniforms)和[`SetBlockEntityExtraUniforms`](/docs/docs/scripts/modapi/interfaces/block/render#setblockentityextrauniforms)系列接口。
- 新增支持动态替换骨骼模型的材质接口，详见[`SetModelMaterial`](/docs/docs/scripts/modapi/interfaces/model#setmodelmaterial)和[`SetModelMultiPassMaterial`](/docs/docs/scripts/modapi/interfaces/model#setmodelmultipassmaterial)系列接口。
- 新增获取骨骼模型 shader 的 Uniform 参数的接口，详见[`GetExtraUniformValue`](/docs/docs/scripts/modapi/interfaces/model#getextrauniformvalue)。
- 新增自定义后处理效果系列接口，包括获取开启状态，参数和管理多 pass 材质相关功能，详见[`InsertPassToPostprocess`](/docs/docs/scripts/modapi/interfaces/post_process/custom#insertpasstopostprocess)和[`CheckEnabledByName`](/docs/docs/scripts/modapi/interfaces/post_process/custom#checkenabledbyname)等接口。
- 根据反馈再次更新了材质使用相关的教学文档，补充了更详细的配置和接口说明，详情参考[材质介绍与着色器入门教程](https://mc.163.com/newdev/docs/mcguide/16-meishu/7-caizhiyuzhuoseqi/1-caizhijieshaoyuzhuoseqirumen.html)。

## NBT 系列接口

- 新增了部分获取和设置实体、玩家的 NBT 属性的接口，详见[实体属性](/docs/docs/scripts/modapi/interfaces/entity/attribute)、[实体行为](/docs/docs/scripts/modapi/interfaces/entity/behavior)、[玩家属性](/docs/docs/scripts/modapi/interfaces/player/attribute)和[玩家权限](/docs/docs/scripts/modapi/interfaces/player/permission)等模块的新增接口。

## 大型结构特征

- 支持下界和末地生成大型结构特征，详见[这篇文档](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/4-zidingyiweidu/6-zidingyidaxingtezheng.html)。
- 修复了概率丢失部分结构的问题。
- 修复了结构包含命令方块时，概率出现断言的问题。
- 新增大型结构生成事件，且支持取消生成，详见[`PlaceNeteaseLargeFeatureServerEvent`](/docs/docs/scripts/modapi/events/world#placeneteaselargefeatureserverevent)。

## 成就系统

- 成就系统的按钮被拖动时抛出事件，详见[`AchievementButtonMovedClientEvent`](/docs/docs/scripts/modapi/events/ui#achievementbuttonmovedclientevent)。
- 新增获取和设置成就系统按钮的接口，详见[`SetAchievementGatePosition`](/docs/docs/scripts/modapi/interfaces/custom_ui/achievement#setachievementgateposition)和[`GetAchievementGatePosition`](/docs/docs/scripts/modapi/interfaces/custom_ui/achievement#getachievementgateposition)。
- 替换了关闭按钮的 UI 资源。
- 修复成就系统概率重置的问题。

## UI

- 小地图控件支持增加文本标记，详见[`AddEntityTextMarker`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#addentitytextmarker)接口。
- 网易纸娃娃支持渲染某一类生物，无需关联某个实例，详见[`RenderEntity`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#renderentity)。
- 网易纸娃娃支持定义灯光方向，详见[`RenderSkeletonModel`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#renderskeletonmodel)接口。
- 修复了网易纸娃娃 arm_model 切换到第一人称时出现偏移的问题。
- [`GridComponentSizeChangedClientEvent`](/docs/docs/scripts/modapi/events/ui#gridcomponentsizechangedclientevent)新增抛出 grid 路径参数。
- [`GetPath`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#getpath) (客户端)，返回当前控件的相对路径。
- [`SetBindWorldPosition`](/docs/docs/scripts/modapi/interfaces/custom_ui/screen#setbindworldposition)，设置绑定到世界坐标的 UI 控件的位置。

## 物品分页

- 物品分页新增 sort_by_identifier 字段，支持该分页按照物品标识符分组，详见[这篇文档](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/13-zidingyiwupinfenye.html)。

## 游戏设置

- [`SetToggleOption`](/docs/docs/scripts/modapi/interfaces/game_setting#settoggleoption)新增多个可控制的游戏设置，包括十字键，平滑光照等等。

## 摄像机

- [`SetCameraAnchor`](/docs/docs/scripts/modapi/interfaces/player/camera#setcameraanchor) (客户端)支持 XZ 轴。
- 新增[`GetCameraRotation`](/docs/docs/scripts/modapi/interfaces/player/camera#getcamerarotation)替代原有 GetCameraRot，支持获取三个方向角度。

## 骨骼模型

- ModelComp 组件下部分接口支持传入 ModelId 参数，用于指定模型，如[`SetTexture`](/docs/docs/scripts/modapi/interfaces/model#settexture) (客户端)。

## 其他更新

- 修复了射线检测接口无法用于方块检测的问题，详见[`getEntitiesOrBlockFromRay`](/docs/docs/scripts/modapi/interfaces/world/entity#getentitiesorblockfromray)。
- 方块配置的`netease:block_chest`组件新增了 can_be_blocked 字段，用于控制箱子的开启是否受到实心方块的阻挡，详见[这篇文档](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/2-zidingyifangkuai/1-json-zujian.html)。
