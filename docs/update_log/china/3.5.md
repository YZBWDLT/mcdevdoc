## 自定义容器

自定义容器在 3.5 得到适配迭代，并新增了漏斗配置字段，可以将自定义容器变为漏斗，支持控制是否漏入漏出、设置漏入的面个数、设置漏入的槽位位置。

- <Change/> 对于 `netease_container`，[`SpawnItemToContainer`](/docs/docs/scripts/modapi/interfaces/block/container#spawnitemtocontainer)（服务端）支持设置物品；对于 `netease_ui_container`，[`GetPlayerUIItem`](/docs/docs/scripts/modapi/interfaces/block/container#getplayeruiitem)（服务端）与[`SetPlayerUIItem`](/docs/docs/scripts/modapi/interfaces/block/container#setplayeruiitem)（服务端）新增 `isNeteaseUI` 参数，为 `true` 时支持获取和设置物品。
- <Change/> [`PlayerTryPutCustomContainerItemServerEvent`](/docs/docs/scripts/modapi/events/item#playertryputcustomcontaineritemserverevent)（服务端）的 collectionName 改为对应容器 JSON 中 `custom_description` 字段，新增 collectionType（`netease_container` 与 `netease_ui_container`）代替原 collectionName。
- <Add/> [`PlayerTryAddCustomContainerItemServerEvent`](/docs/docs/scripts/modapi/events/item#playertryaddcustomcontaineritemserverevent)（服务端），玩家尝试将物品添加到自定义容器时触发该事件，当目标槽位已有同种物品时触发。
- <Add/> [`PlayerTryRemoveCustomContainerItemServerEvent`](/docs/docs/scripts/modapi/events/item#playertryremovecustomcontaineritemserverevent)（服务端），玩家尝试从自定义容器中移除物品时触发该事件。
- <Add/> [`ItemPushInCustomContainerServerEvent`](/docs/docs/scripts/modapi/events/item#itempushincustomcontainerserverevent)（服务端），漏斗漏入物品时触发该事件。
- <Add/> [`ItemPullOutCustomContainerServerEvent`](/docs/docs/scripts/modapi/events/item#itempulloutcustomcontainerserverevent)（服务端），漏斗漏出物品时触发该事件。
- <Add/> [`PlayerTryPutCustomContainerItemClientEvent`](/docs/docs/scripts/modapi/events/item#playertryputcustomcontaineritemclientevent)（客户端），玩家尝试将物品放入自定义容器时触发该事件。
- <Add/> [`PlayerTryAddCustomContainerItemClientEvent`](/docs/docs/scripts/modapi/events/item#playertryaddcustomcontaineritemclientevent)（客户端），玩家尝试将物品添加到自定义容器时触发该事件，当目标槽位已有同种物品时触发。
- <Add/> [`PlayerTryRemoveCustomContainerItemClientEvent`](/docs/docs/scripts/modapi/events/item#playertryremovecustomcontaineritemclientevent)（客户端），玩家尝试从自定义容器中移除物品时触发该事件。

## 自定义绘制渲染

3.5 新增了自定义绘制渲染接口，开发者可以使用其绘制盒子、圆、球、线条、文本与箭头形状，支持创建后设置颜色、缩放、位置等。该功能所有接口采用面向对象设计。

- <Add/> 形状创建接口：[`AddBoxShape`](/docs/docs/scripts/modapi/interfaces/render#addboxshape)、[`AddLineShape`](/docs/docs/scripts/modapi/interfaces/render#addlineshape)、[`AddCircleShape`](/docs/docs/scripts/modapi/interfaces/render#addcircleshape)、[`AddArrowShape`](/docs/docs/scripts/modapi/interfaces/render#addarrowshape)、[`AddTextShape`](/docs/docs/scripts/modapi/interfaces/render#addtextshape)与[`AddSphereShape`](/docs/docs/scripts/modapi/interfaces/render#addsphereshape)。
- <Add/> 形状属性读取接口：[`GetPos`](/docs/docs/scripts/modapi/interfaces/effect/microsoft_particle#getpos)、[`GetBoxScale`](/docs/docs/scripts/modapi/interfaces/render#getboxscale)、[`GetColor`](/docs/docs/scripts/modapi/interfaces/render#getcolor)、[`GetType`](/docs/docs/scripts/modapi/interfaces/render#gettype)、[`GetPriority`](/docs/docs/scripts/modapi/interfaces/render#getpriority)、[`GetVisible`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#getvisible)、[`GetEndPos`](/docs/docs/scripts/modapi/interfaces/render#getendpos)、[`GetRadius`](/docs/docs/scripts/modapi/interfaces/render#getradius)、[`GetSegments`](/docs/docs/scripts/modapi/interfaces/render#getsegments)、[`GetText`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#gettext)与[`GetLength`](/docs/docs/scripts/modapi/interfaces/render#getlength)。
- <Add/> 形状属性设置接口：[`SetPos`](/docs/docs/scripts/modapi/interfaces/effect/microsoft_particle#setpos)、[`SetBoxScale`](/docs/docs/scripts/modapi/interfaces/render#setboxscale)、[`SetEndPos`](/docs/docs/scripts/modapi/interfaces/render#setendpos)、[`SetRadius`](/docs/docs/scripts/modapi/interfaces/render#setradius)、[`SetSegments`](/docs/docs/scripts/modapi/interfaces/render#setsegments)、[`SetLength`](/docs/docs/scripts/modapi/interfaces/render#setlength)、[`SetText`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#settext)、[`SetColor`](/docs/docs/scripts/modapi/interfaces/entity/render#setcolor)与[`SetPriority`](/docs/docs/scripts/modapi/interfaces/render#setpriority)。
- <Add/> [`SetVisible`](/docs/docs/scripts/modapi/interfaces/custom_ui/control#setvisible)与[`Remove`](/docs/docs/scripts/modapi/interfaces/effect/microsoft_particle#remove)，用于删除单个形状与删除当前所有形状。
- <Add/> [`RemoveAll`](/docs/docs/scripts/modapi/interfaces/render#removeall)，用于设置通过 `AddDropItemToWorld` 添加的掉落物的位置、角度和缩放。

## HUD 界面字段变更

`hud_screen.json`的字段更新。为了适配原版更新，影响物品栏和经验栏可见性的部分 JSON 字段名称发生了变更。

| 旧字段                    | 新字段                |
| ------------------------- | --------------------- |
| `#exp_and_hotbar_visible` | `#hotbar_with_xp_bar` |
| `#only_hotbar_visible`    | `#hotbar_no_xp_bar`   |

影响范围包括原生指令 `/hud` 与 SDK 接口 `HideSlotBarGui`、`HideExpGui`。

> **注意**：如果 MOD 里还存在旧版的 `hud_screen.json`使用旧的字段，可能会覆盖上述字段更新，导致相关的指令或 API 失效，引发物品栏的一些可见性控制问题。请开发者检查并进行替换。

## 性能优化

- <Change/> `Matrix`、`Quaternion`与`Vector3`将有底层 C++ 进行计算，拥有更快速度，方便开发者实现自定义碰撞箱计算等。

- <Change/> [`SpawnItemToContainer`](/docs/docs/scripts/modapi/interfaces/block/container#spawnitemtocontainer)（服务端）支持自定义容器。
- <Change/> [`PlayerTryPutCustomContainerItemServerEvent`](/docs/docs/scripts/modapi/events/item#playertryputcustomcontaineritemserverevent)（服务端）的 collectionName 改为对应容器 JSON 中 `custom_description` 字段，新增 collectionType 代替原 collectionName。
