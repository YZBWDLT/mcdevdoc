## 国际版对应的更新

1.23 跟进的国际版版本为 1.16.201。

## 重要功能更新

- 由于部分物品的名称与附加值存在变更，物品信息字典添加了 newItemName 及 newAuxValue 字段以兼容，详见[1.23 版本物品 id 变更](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/13-mozu-sdk-biancheng/2-python-jiaobenkaifa/99-1-23-banbenwupin-id-biangeng.html)。
- 支持[微缩方块](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/10-weisuofangkuai.html)，方块的形状支持根据地图或自定义数据生成，详见微缩方块。
- 骨骼模型材质功能拓展，详见[材质配置说明](https://mc.163.com/newdev/docs/mcguide/16-meishu/7-caizhiyuzhuoseqi/3-caizhipeizhishuoming.html)，[材质的分类](https://mc.163.com/newdev/docs/mcguide/16-meishu/7-caizhiyuzhuoseqi/2-neizhicaizhiqingdan.html)，[骨骼模型自定义材质](https://mc.163.com/newdev/docs/mcguide/16-meishu/6-moxinghedongzuo/04-gugemoxingdeshiyong.html)（1.23 后续将会有更多材质与着色器的使用文档）。以及材质热更新的[`ReloadAllMaterials`](/docs/docs/scripts/modapi/interfaces/general/debug#reloadallmaterials)，[`ReloadOneShader`](/docs/docs/scripts/modapi/interfaces/general/debug#reloadoneshader)接口。
- 支持骨骼模型动作融合，详见[`SetAnimationBoneMask`](/docs/docs/scripts/modapi/interfaces/model#setanimationbonemask)，[`SetAnimLayer`](/docs/docs/scripts/modapi/interfaces/model#setanimlayer)等模型分类下的接口。
- 支持创建下界、末地、超平坦世界为模板的新维度，详见[自定义维度](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/4-zidingyiweidu/1-zidingyiweidu.html)。
- 支持自定义剪刀，详见`SetShearsDestoryBlockSpeed`，[`ShearsDestoryBlockBeforeServerEvent`](/docs/docs/scripts/modapi/events/block#shearsdestoryblockbeforeserverevent)等接口。
- 支持局部维度时间规则，详见[`SetUseLocalTime`](/docs/docs/scripts/modapi/interfaces/world/time#setuselocaltime)等时间分类下的接口。
- 支持自定义饥饿设置，详见[`SetPlayerStarveLevel`](/docs/docs/scripts/modapi/interfaces/player/attribute#setplayerstarvelevel)，[`SetPlayerStarveTick`](/docs/docs/scripts/modapi/interfaces/player/attribute#setplayerstarvetick)，[`SetPlayerNaturalStarve`](/docs/docs/scripts/modapi/interfaces/player/attribute#setplayernaturalstarve)等接口。
