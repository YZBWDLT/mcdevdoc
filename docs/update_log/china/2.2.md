## 国际版对应的更新

2.2 跟进的国际版版本为 1.18.0。

<WikiButton item="基岩版1.18.0"/>

## 重要功能更新

- 新增对[微软粒子](/docs/docs/scripts/modapi/interfaces/effect/microsoft_particle)的创建，播放控制和挂接支持，详见微软粒子。
- 自定义方块自由模型的每张贴图支持最大 64×64，关于自定义方块模型的制作请参考[这篇文档](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/2-zidingyifangkuai/5-zidingyifangkuaimoxing.html)。
- 方块几何体模型支持门、床、活塞、粘性活塞、告示牌、箱子类方块。
- 自定义方块及自定义方块模型的群系颜色，详见[这篇文档](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/2-zidingyifangkuai/2-gongneng.html)。
- 部分 UI 控件支持属性动画，详见[这篇文档](https://mc.163.com/newdev/docs/mcguide/18-jiemianyujiaohu/19-kongjianshuxingdonghua.html)。
- 新增[自定义成就](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/16-zidingyichengjiuxitong.html)系统，支持开发者定义自己的成就事件并展示，详见自定义成就。

特殊说明：

- 自定义维度中，如果使用了群系地貌（netease_biomes 目录中定义），则默认使用 2d 群系规则。
- 注：在 2.2 以及之后的版本，我们对自定义生物的移动流量进行了优化，距离玩家较远的生物会出现瞬移的情况，如果感觉效果较差，可在 components 手动添加`netease:ban_bandwidth_optimization:{}`组件来主动关闭此优化。
