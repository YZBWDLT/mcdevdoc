## 相机运动器

对玩家的相机支持了三种运动器接口，可用于单独控制玩家相机进行更平滑的轨迹运动，详情请参考[相机运动器接口](/docs/docs/scripts/modapi/interfaces/player/camera)。

- 轨迹运动器：用于驱动相机从一点到另一点的直线运动。
- 速度运动器：用于驱动相机根据初速度和加速度进行匀速/变速运动。
- 环绕运动器：用于驱动相机环绕指定坐标或指定实体运动。

环绕运动器将在后续版本支持支持固定环绕半径，请耐心等待。

## 物品容器 UI

为原生的物品容器 UI 增加了前后多个图层，可以调用代码动态修改各图层显示的图片，详情查看新增[接口文档](/docs/docs/scripts/modapi/interfaces/item)。开发者可在内容库 → 作品模板分页查看自定义物品和自定义熔炉两个 SDK 示例，同步更新了相应的物品容器 UI 相关的示例用法。

## 游戏区块动态加载范围调整

- 在 2.5 版本之前，游戏服务端的动态加载区块范围为客户端视野范围和模拟距离的最大值，从 2.5 版本开始将默认为模拟距离。
- 未加载的区块对服务端而言是虚空，无法在该区域进行召唤生物、放置物品等操作。
- 请开发者根据自身模组情况尽快调整和适配相关内容，可参考使用[`CheckChunkState`](/docs/docs/scripts/modapi/interfaces/world/map#checkchunkstate)接口验证是否加载，使用[`DoTaskOnChunkAsync`](/docs/docs/scripts/modapi/interfaces/world/map#dotaskonchunkasync)接口进行异步处理。

## 物品描述覆盖问题

- 修改[物品信息字典](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/10-jibengainian/1-wodeshijiejichugainian.html)的 Customtips 属性后会覆盖物品的 Json 组件[`netease:customtips`](https://mc.163.com/newdev/docs/mcguide/20-wanfakaifa/15-zidingyiyouxineirong/1-zidingyiwupin/1-zidingyijichuwupin.html)的内容。

## 平滑字体字号变动说明

- 修复了平滑字体指向错误字库的问题，会导致当前平滑字体的字号比之前的版本略大，请开发者根据自身模组的字体和 UI 适配情况进行检查和适配。
