# 1.21.70

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

有关于 1.21.70 的完整更新日志，可见下方的中文 Minecraft Wiki。按照惯例，本文只介绍 1.21.70 的关键更改。

<WikiButton item="基岩版1.21.70"/>

## 方块

### 数据驱动方块组件

- <Add/> [`minecraft:replaceable`](/docs/docs/blocks/components#minecraftreplaceable)组件，用于定义方块是否可被另一种方块在原位替代（类似于水、草丛或空气）。

### 战利品表

- <Change/> 战利品表的`match_tool`条件支持物品标签，不再需要实验性玩法。

## 实体

### 数据驱动实体组件

- <Add/> [`minecraft:is_collidable`](/docs/docs/entities/components/functional#minecraftis_collidable)组件，使实体拥有不可穿过的碰撞箱。
- <Add/> [`minecraft:entity_sensor`](/docs/docs/entities/components/sensors#minecraftentity_sensor)组件新增`y_offset`与`find_players_only`两个参数。
- <Add/> [`minecraft:body_rotation_axis_aligned`](/docs/docs/entities/components/deprecated#minecraftbody_rotation_axis_aligned)组件，使实体根据当前朝向自动旋转。

## 相机

- <Add/> 瞄准辅助功能走出实验性玩法，可以针对方块、实体进行瞄准，并支持自定义着色与每个玩家独立的颜色。

## 世界生成

- <Add/> 结构现在可以加载到未加载的区块中。

## ScriptAPI

该版本开放了`@minecraft/server`的`1.18.0`版本。

### 玩家

- <Add/> 开放了[`Player.spawnParticle`方法](/docs/docs/scripts/sapi/server/entity_and_player/player#spawnparticle-方法)，用于生成仅对该玩家可见的粒子。
- <Add/> 开放了[`InputButton`枚举](/docs/docs/scripts/sapi/server/entity_and_player/input#inputbutton-枚举)与[`ButtonState`枚举](/docs/docs/scripts/sapi/server/entity_and_player/input#buttonstate-枚举)，用于查询玩家的按键状态。
- <Add/> [`InputInfo`类](/docs/docs/scripts/sapi/server/entity_and_player/input#inputinfo-类)新增`getButtonState`方法与`getMovementVector`方法，用于查询按键状态与移动向量。

### 方块

- <Change/> 液体相关的接口从 beta 转为稳定版，包含[`LiquidType`枚举](/docs/docs/scripts/sapi/server/block/main#liquidtype-枚举)与方块含水、阻挡水流等判定方法。
