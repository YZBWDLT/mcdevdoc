# 1.21.80

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

有关于 1.21.80 的完整更新日志，可见下方的中文 Minecraft Wiki。按照惯例，本文只介绍 1.21.80 的关键更改。

<WikiButton item="基岩版1.21.80"/>

## 方块

### 数据驱动方块组件

- <Add/> [`minecraft:map_color`](/docs/docs/blocks/components#minecraftmap_color)组件的`tint_method`参数，用于定义方块的着色方法，将颜色与预定义的色调相乘。
- <Add/> [`minecraft:destruction_particles`](/docs/docs/blocks/components#minecraftdestruction_particles)组件的`tint_method`参数。
- <Add/> [`minecraft:material_instances`](/docs/docs/blocks/components#minecraftmaterial_instances)组件的`tint_method`参数与`isotropic`参数，后者用于允许纹理随机旋转，类似于原版泥土。
- <Add/> [`minecraft:material_instances`](/docs/docs/blocks/components#minecraftmaterial_instances)组件的`render_method`参数新增三个预设值：`blend_to_opaque`、`alpha_test_to_opaque`与`alpha_test_single_sided_to_opaque`，让方块在远处转为不透明，而不是直接消失。

### 方块面剔除

- <Add/> 现在允许在资源包内通过`block_culling`文件夹指定面剔除规则，并能够通过[`minecraft:geometry`](/docs/docs/blocks/components#minecraftgeometry)组件的`culling_layer`参数进行方块面剔除。

## 实体

### 数据驱动实体组件

- <Add/> [`minecraft:rideable`](/docs/docs/entities/components/functional#minecraftrideable)组件新增`dismount_mode`参数，用于定义乘客离开实体时的放置位置，可选`default`与`on_top_center`。
- <Add/> [`minecraft:rideable`](/docs/docs/entities/components/functional#minecraftrideable)组件新增`on_rider_enter_event`与`on_rider_exit_event`参数，用于定义实体被骑乘与停止被骑乘时在拥有者身上执行的事件。
- <Add/> [`minecraft:rideable`](/docs/docs/entities/components/functional#minecraftrideable)组件的`seats`参数新增`third_person_camera_radius`与`camera_relax_distance_smoothing`两个字段，前者用于设置第三人称视角的相机半径，后者让相机在被障碍物推近玩家后回到半径时带有弹性。
- <Change/> [`minecraft:leashable`](/docs/docs/entities/components/functional#minecraftleashable)组件的`preset`属性支持设置多个预设。
- <Add/> [`minecraft:interact`](/docs/docs/entities/components/functional#minecraftinteract)组件的`drop_item_y_offset`参数，用于定义丢弃物品时的 y 轴偏移。

### 实体过滤器

- <Add/> 加入了`has_equipment_tag`过滤器，检查实体是否装备了特定物品标签的物品。

## Molang

- <Add/> `query.leashed_entity_count`，返回该实体拴住了多少个实体。
- <Add/> `query.has_any_leashed_entity_of_type`，返回该实体是否拴住了给定实体的其中一种。

## 世界生成

- <Add/> 开放了`/place feature`命令，可以在世界生成时通过命令或接口放置地物。

## ScriptAPI

该版本开放了`@minecraft/server`的`1.19.0`版本。

### 世界

- <Add/> 开放了[`World.getDifficulty`方法](/docs/docs/scripts/sapi/server/world/main#getdifficulty-方法)与[`World.setDifficulty`方法](/docs/docs/scripts/sapi/server/world/main#setdifficulty-方法)，配合[`Difficulty`枚举](/docs/docs/scripts/sapi/server/world/main#difficulty-枚举)读取与设置世界难度。

### 维度

- <Add/> 开放了[`Dimension.placeFeature`方法](/docs/docs/scripts/sapi/server/dimension/main#placefeature-方法)与[`Dimension.placeFeatureRule`方法](/docs/docs/scripts/sapi/server/dimension/main#placefeaturerule-方法)，用于放置地物。

### 结构

- <Add/> 开放了[`StructureManager.placeJigsaw`方法](/docs/docs/scripts/sapi/server/world/structure#placejigsaw-方法)与[`StructureManager.placeJigsawStructure`方法](/docs/docs/scripts/sapi/server/world/structure#placejigsawstructure-方法)，用于按拼图结构放置结构。
