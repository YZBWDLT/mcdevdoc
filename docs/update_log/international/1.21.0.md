# 1.21.0

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';
import DataType from '/src/components/type/data';

有关于 1.21.0 的完整更新日志，可见下方的中文 Minecraft Wiki。按照惯例，本文只介绍 1.21.0 的关键更改。

<WikiButton item="基岩版1.21.0"/>

## 命令

- <Add/> 新增了`/hud`命令，用于控制 HUD 元素的显示。
- <Add/> 目标选择器新增`has_property`参数，用于筛选具有指定实体属性的实体。
- <Change/> 伤害类型`suicide`更名为`self_destruct`。
- <Add/> 新增游戏规则`tntExplosionDropDecay`，用于控制 TNT 爆炸后是否 100% 掉落。
- <Add/> 新增游戏规则`showDaysPlayed`，在左上角显示游玩天数。

## 物品

### 数据驱动物品组件

- <Add/> 自定义盔甲附着物现在可以使用原版纹饰作为纹饰，经过修改的原版图案可以应用于自定义盔甲附着物与物品。

## 方块

### 数据驱动方块组件

- <Add/> [`minecraft:geometry`](/docs/docs/blocks/components#minecraftgeometry)组件的`full_block`标识符，用于定义整块方块的几何体。
- <Add/> [`minecraft:geometry`](/docs/docs/blocks/components#minecraftgeometry)组件支持 UV 旋转，可以在应用于方块面前以 90 度的增量旋转指定的 UV 矩形。
- <Add/> [`minecraft:transformation`](/docs/docs/blocks/components#minecrafttransformation)组件加入了轴心点缩放与旋转。
- <Add/> [`minecraft:crafting_table`](/docs/docs/blocks/components#minecraftcrafting_table)组件的`crafting_tags`字段支持自定义标签的方块解锁自定义配方。

### 方块标签

- <Add/> 生物群系标签从 JSON 里的松散对象改为写在`minecraft:tags`组件下的`tags`数组中。

## 实体

### 数据驱动实体组件

- <Add/> [`minecraft:ageable`](/docs/docs/entities/components/functional#minecraftageable)组件的`interact_filters`参数，用于指定活动对象可以被喂食的条件。
- <Change/> [`minecraft:damage_sensor`](/docs/docs/entities/components/sensors#minecraftdamage_sensor)组件的`damage_modifier`与`damage_multiplier`参数现在会在受击后的伤害免疫计算中被考虑。
- <Add/> [`minecraft:entity_sensor`](/docs/docs/entities/components/sensors#minecraftentity_sensor)组件支持多个子检测器，每个子检测器可单独配置`event`、`require_all`、`minimum_count`、`maximum_count`、`range`、`event_filter`与`cooldown`。其中`cooldown`原本只能写在组件根级，本次起可按子检测器分别设置检测频率。
- <Add/> [`minecraft:interact`](/docs/docs/entities/components/functional#minecraftinteract)组件的 4 个参数：
    - `vibration`字段支持`entity_act`附加值。
    - `drop_item_slot`参数，用于指定移除并丢弃物品的物品栏槽位。
    - `equip_item_slot`与`drop_item_slot`参数支持盔甲槽位与物品栏槽位。
    - `repair_entity_item`参数，用于修复实体物品栏或盔甲槽中的物品。
- <Add/> [`minecraft:body_rotation_blocked`](/docs/docs/entities/components/functional#minecraftbody_rotation_blocked)组件，用于阻止生物在视觉上转身以与自身朝向相匹配。

### 实体事件

- <Add/> [`queue_command`](/docs/docs/entities/events#queue_command)事件响应，用于直接使实体执行命令。
- <Add/> [`emit_vibration`](/docs/docs/entities/events#emit_vibration)事件响应，允许实体以自身为振动源产生振动。

### 实体过滤器

- <Add/> [`is_panicking`](/docs/docs/entities/filters#is_panicking)过滤器，检查实体是否在执行`minecraft:behavior.panic`组件。
- <Add/> [`is_sprinting`](/docs/docs/entities/filters#is_sprinting)过滤器，检查实体是否在疾跑。
- <Add/> [`was_last_hurt_by`](/docs/docs/entities/filters#was_last_hurt_by)过滤器，检查对象是否为攻击过该实体的最后一个玩家或生物。
- <Add/> [`is_sitting`](/docs/docs/entities/filters#is_sitting)过滤器，检查实体是否处于坐下状态。
- <Add/> [`has_damaged_equipment`](/docs/docs/entities/filters#has_damaged_equipment)过滤器，检查实体的指定槽位中是否存在特定的已损坏装备。

### 生成规则

- <Add/> `minecraft:spawns_on_block_filter`、`minecraft:spawns_on_block_prevented_filter`与`minecraft:spawns_above_block_filter`支持方块描述符。

### 实体模型

- <Add/> 格式版本`1.21.0`起支持 UV 旋转，可以在应用于实体的立方体面前以 90 度的增量旋转指定的 UV 矩形。

## 配方

- <Add/> 有序配方新增<DataType type="boolean" name="assume_symmetry"/>属性，允许对称的有序配方使用不同的输出方式。

## Molang

- <Add/> 方块查询 Molang 走出实验性玩法：`query.relative_block_has_any_tag`、`query.relative_block_has_all_tags`、`query.block_neighbor_has_any_tag`、`query.block_neighbor_has_all_tags`、`query.block_has_any_tag`与`query.block_has_all_tags`。
- <Add/> 骨骼 Molang 走出实验性玩法：`query.bone_orientation_trs`与`query.bone_orientation_matrix`。
- <Add/> 物品冷却 Molang 走出实验性玩法：`query.is_cooldown_type`、`query.cooldown_time`与`query.cooldown_time_remaining`。
- <Add/> 记分板 Molang 走出实验性玩法：`query.scoreboard`，仅可在服务端使用。
- <Add/> 坐骑与乘客 Molang 走出实验性玩法：`query.rider_body_x_rotation`、`query.rider_body_y_rotation`、`query.rider_head_x_rotation`、`query.rider_head_y_rotation`、`query.ride_body_x_rotation`、`query.ride_body_y_rotation`、`query.ride_head_x_rotation`、`query.ride_head_y_rotation`、`query.is_attached`与`query.has_player_rider`。
- <Add/> `query.armor_slot_damage`，返回指定槽位中的盔甲物品的损坏值。

## ScriptAPI

该版本开放了`@minecraft/server`的`1.11.0`版本。

### 世界

- <Add/> 世界前事件：开放了[`WeatherChangeBeforeEvent`类](/docs/docs/scripts/sapi/server/world/before_events#weatherchangebeforeevent-类)与[`WorldBeforeEvents.weatherChange`属性](/docs/docs/scripts/sapi/server/world/before_events)，在天气变化前触发。
- <Add/> 世界后事件：开放了[`GameRuleChangeAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#gamerulechangeafterevent-类)与[`WorldAfterEvents.gameRuleChange`属性](/docs/docs/scripts/sapi/server/world/after_events)，在游戏规则变化后触发。
- <Add/> 世界前事件：开放了[`PlayerGameModeChangeBeforeEvent`类](/docs/docs/scripts/sapi/server/world/before_events#playergamemodechangebeforeevent-类)与[`WorldBeforeEvents.playerGameModeChange`属性](/docs/docs/scripts/sapi/server/world/before_events)，在玩家游戏模式变化前触发。
- <Add/> 世界后事件：开放了[`PlayerGameModeChangeAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#playergamemodechangeafterevent-类)与[`WorldAfterEvents.playerGameModeChange`属性](/docs/docs/scripts/sapi/server/world/after_events)，在玩家游戏模式变化后触发。
- <Add/> 开放了[`GameRules`类](/docs/docs/scripts/sapi/server/world/main#gamerules-类)与[`World.gameRules`属性](/docs/docs/scripts/sapi/server/world/main#world-类)，用于读取与设置游戏规则。

### 维度

- <Add/> 开放了[`Dimension.playSound`方法](/docs/docs/scripts/sapi/server/dimension/main#playsound-方法)，用于在指定位置播放音效。

### 方块

- <Add/> 开放了[`BlockTypes`类](/docs/docs/scripts/sapi/server/block/main#blocktypes-类)与[`Block.typeId`属性](/docs/docs/scripts/sapi/server/block/main#block-类)，用于获取方块的原版 ID。
- <Add/> 开放了[`Block.setType`方法](/docs/docs/scripts/sapi/server/block/main#settype-方法)，用于替换方块。
- <Add/> 开放了[`BlockVolumeBase`类](/docs/docs/scripts/sapi/server/dimension/volume#blockvolumebase-类)、[`ListBlockVolume`类](/docs/docs/scripts/sapi/server/dimension/volume#listblockvolume-类)，用于定义方块域并迭代其中的位置。

### 实体

- <Add/> 开放了[`EntityTameMountComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entitytamemountcomponent-类)，用于获取实体的骑乘驯服相关属性。
- <Add/> 开放了[`EntityAddRiderComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entityaddridercomponent-类)与[`EntityRideableComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entityrideablecomponent-类)，用于获取实体的乘客与被骑乘相关属性。
- <Add/> 开放了[`EntityNavigationComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entitynavigationcomponent-类)及其各寻路方式子类，用于获取实体的寻路参数。
- <Add/> 开放了[`EntityColor2Component`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entitycolor2component-类)，用于获取实体的颜色参数。
- <Add/> 开放了[`Seat`类](/docs/docs/scripts/sapi/server/entity_and_player/component#seat-类)，用于表示实体的座位。

### 玩家

- <Add/> 开放了[`Player.startItemCooldown`方法](/docs/docs/scripts/sapi/server/entity_and_player/player#startitemcooldown-方法)与[`Player.getItemCooldown`方法](/docs/docs/scripts/sapi/server/entity_and_player/player#getitemcooldown-方法)，用于设置与查询物品冷却。
- <Add/> 开放了[`Player.getGameMode`方法](/docs/docs/scripts/sapi/server/entity_and_player/player#getgamemode-方法)与[`Player.setGameMode`方法](/docs/docs/scripts/sapi/server/entity_and_player/player#setgamemode-方法)，用于获取与设置玩家的游戏模式。
- <Add/> 开放了[`Player.selectedSlotIndex`属性](/docs/docs/scripts/sapi/server/entity_and_player/player#player-类)，用于获取玩家当前选中的物品栏槽位。

### 物品

- <Add/> 开放了[`ItemEnchantableComponent`类](/docs/docs/scripts/sapi/server/item/component#itemenchantablecomponent-类)，用于获取物品的附魔相关属性。
- <Add/> 开放了[`Enchantment`接口](/docs/docs/scripts/sapi/server/item/enchantment#enchantment-接口)、[`EnchantmentSlot`枚举](/docs/docs/scripts/sapi/server/item/enchantment#enchantmentslot-枚举)、[`EnchantmentType`类](/docs/docs/scripts/sapi/server/item/enchantment#enchantmenttype-类)与[`EnchantmentTypes`类](/docs/docs/scripts/sapi/server/item/enchantment#enchantmenttypes-类)，用于描述物品的附魔。

### 显示

- <Add/> 开放了[`HudElement`枚举](/docs/docs/scripts/sapi/server/entity_and_player/player#hudelement-枚举)，用于控制玩家 HUD 元素的显示。
