# 1.21.130

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

1.21.130 更新了群骑纷争（Mounts of Mayhem），主要更新了矛、鹦鹉螺、骆驼尸壳等。

有关于 1.21.130 的完整更新日志，可见下方的中文 Minecraft Wiki。按照惯例，本文只介绍 1.21.130 的关键技术性更改。

<WikiButton item="基岩版1.21.130"/> <WikiButton item="群骑纷争"/>

## 物品

### 数据驱动物品组件

- <Add/> [`minecraft:kinetic_weapon`](/docs/docs/items/components#minecraftkinetic_weapon)组件，定义物品可造成动能伤害，类似于矛。使用时每刻会对视线向量上的无阻挡目标造成一次伤害。
- <Add/> [`minecraft:piercing_weapon`](/docs/docs/items/components#minecraftpiercing_weapon)组件，定义物品可对视线向量直线上检测到的所有实体造成戳刺伤害，类似于矛。
- <Add/> [`minecraft:swing_sounds`](/docs/docs/items/components#minecraftswing_sounds)组件，定义该物品的挥舞音效。
- <Add/> [`minecraft:use_modifiers`](/docs/docs/items/components#minecraftuse_modifiers)组件的`start_sound`参数，定义开始使用物品时播放的音效。
- <Add/> [`minecraft:cooldown`](/docs/docs/items/components#minecraftcooldown)组件的`type`参数，以互斥的方式定义冷却时间所应用的操作，因此一种操作的冷却时间不会影响另一种操作。

### 物品标签

- <Change/> 现在带有[`minecraft:is_shovel`](/docs/docs/items/tags)标签的自定义物品可以像锹一样转化方块。

## 方块

### 数据驱动方块组件

- <Add/> [`minecraft:precipitation_interactions`](/docs/docs/blocks/components#minecraftprecipitation_interactions)组件由实验性玩法移动至稳定版。

## 实体

### 数据驱动实体组件

- <Add/> [`minecraft:rotation_locked_to_vehicle`](/docs/docs/entities/components#minecraftrotation_locked_to_vehicle)组件，使实体的身体旋转方向与整体旋转方向自动对齐其所骑乘的坐骑。
- <Add/> [`minecraft:behavior.use_kinetic_weapon`](/docs/docs/entities/components#minecraftbehavioruse_kinetic_weapon)意向，允许实体使用动能武器，间歇性地冲向目标并在攻击后重新拉开距离。
    - 使用`hijack_mount_navigation`参数时，坐骑需要运行[`minecraft:behavior.mount_pathing`](/docs/docs/entities/components#minecraftbehaviormount_pathing)意向。
- <Add/> [`minecraft:behavior.float`](/docs/docs/entities/components#minecraftbehaviorfloat)意向的`chance_per_tick_to_float`和`time_under_water_to_dismount_passengers`参数，分别定义每刻施加向上推力的概率，以及漂浮的坐骑在使乘客脱离前头部可以处于水下的秒数。
- <Add/> [`minecraft:behavior.nearest_attackable_target`](/docs/docs/entities/components#minecraftbehaviornearest_attackable_target)意向的`target_acquisition_probability`参数，定义实体接受所寻找到的目标的概率，取值`0.0`-`1.0`，默认值为`1.0`。
- <Change/> [`minecraft:behavior.nearest_attackable_target`](/docs/docs/entities/components#minecraftbehaviornearest_attackable_target)意向的`attack_interval`参数改为支持范围，可分别指定搜寻目标前的最短与最长时间（单位秒），最短时间现在可以设置为`0`以外的值。
- <Add/> [`minecraft:dash_action`](/docs/docs/entities/components#minecraftdash_action)的`can_dash_underwater`参数，定义该实体是否能在水下冲刺，默认值为`false`。
- <Add/> [`minecraft:burns_in_daylight`](/docs/docs/entities/components#minecraftburns_in_daylight)的`protection_slot`参数，用于指定可提供阳光下燃烧保护的装备槽位，默认值为`slot.armor.head`。
- <Change/> [`minecraft:ageable`](/docs/docs/entities/components#minecraftageable)和[`minecraft:breedable`](/docs/docs/entities/components#minecraftbreedable)组件的`transform_to_item`参数更名为`result_item`，并改为在每个物品项中分别定义，以允许不同物品在使用后变成不同物品。
- <Add/> [`minecraft:healable`](/docs/docs/entities/components#minecrafthealable)和[`minecraft:tameable`](/docs/docs/entities/components#minecrafttameable)组件物品项的`result_item`参数，定义成功交互后所消耗物品被替换成的物品。
- <Change/> [`minecraft:addrider`](/docs/docs/entities/components#minecraftaddrider)组件现在支持多名骑乘者，`riders`数组中的每一项定义一名骑乘者。
- <Add/> [`minecraft:breathable`](/docs/docs/entities/components#minecraftbreathable)组件的`can_dehydrate`参数，默认值为`false`。设置为`true`时，只能在水下呼吸的实体在脱离水后会受到脱水伤害。
- <Add/> [`minecraft:exhaustion_values`](/docs/docs/entities/components#minecraftexhaustion_values)组件的`lunge`参数，定义触发突刺附魔时的消耗度，会随附魔等级倍增。
- <Add/> [`minecraft:mob_effect`](/docs/docs/entities/components#minecraftmob_effect)组件的`ambient`参数，使施加的效果按环境效果渲染，并且不会因超时而闪烁。
- <Change/> 现在下列 AI 意向组件的解析会更加严格，在`1.21.130`及更高格式版本中将无法加载包含无效数据的实体 JSON：
    - [`minecraft:behavior.explore_outskirts`](/docs/docs/entities/components#minecraftbehaviorexplore_outskirts)
    - [`minecraft:behavior.investigate_suspicious_location`](/docs/docs/entities/components#minecraftbehaviorinvestigate_suspicious_location)

### 实体过滤器

- <Add/> [`is_controlling_passenger_family`](/docs/docs/entities/filters#is_controlling_passenger_family)过滤器，用于检查控制坐骑的乘客是否属于指定族。
- <Add/> [`is_in_same_vehicle`](/docs/docs/entities/filters#is_in_same_vehicle)过滤器，用于检查测试主体是否与调用者乘坐同一载具。
- <Add/> [`has_item_with_component`](/docs/docs/entities/filters#has_item_with_component)过滤器，用于检查实体手持的物品是否带有指定组件。

## 世界生成

### 生物群系

- <Add/> 客户端 Molang 查询 query.entity_biome_has_all_tags、query.entity_biome_has_any_tags 和 query.entity_biome_has_any_identifier 不再需要开启实验性玩法，已正式可用。

## Molang

- <Add/> 加入了 4 个与[`minecraft:kinetic_weapon`](/docs/docs/items/components#minecraftkinetic_weapon)组件相关的查询，分别返回主手物品的`delay`值，以及其`damage_conditions`、`knockback_conditions`、`dismount_conditions`的`max_duration`值；主手物品没有该组件时返回`0`：
    - query.kinetic_weapon_delay
    - query.kinetic_weapon_damage_duration
    - query.kinetic_weapon_knockback_duration
    - query.kinetic_weapon_dismount_duration
- <Add/> 加入了 query.ticks_since_last_kinetic_weapon_hit 查询，用于返回使用者最后一次用动能武器命中某物以来经过的刻数；未使用动能武器或未命中任何物体时返回`-1.0`。使用者被卸载时发生的命中不会被计入。
- <Add/> 加入了 3 个资源包设置查询。仅资源包可用。
    - query.get_pack_setting('命名空间:滑块名')：返回滑块的值。
    - query.is_pack_setting_enabled('命名空间:开关名')：返回开关是否开启。
    - query.is_pack_setting_selected('命名空间:下拉菜单名, 命名空间:下拉选项名')：返回下拉选项是否被选中。

## Vibrant Visuals

<Add/> 在灵动视效中加入了数据驱动立方体贴图光照与效果的能力。立方体贴图配置文件应放在资源包的`cubemaps`目录中，例如：

```json showLineNumbers title="cubemaps/mycubemap.json"
{
    "format_version": "1.21.130",
    "minecraft:cubemap_settings": {
        "description": {
            "identifier": "mypack:mycubemap"
        },
        "lighting": {
            "ambient_light_illuminance": {
                "0.00000": 4.0,
                "1.000000": 4.0
            },
            "sky_light_contribution": 1.0,
            "directional_light_contribution": 1.0,
            "affected_by_atmospheric_scattering": true,
            "affected_by_volumetric_scattering": true
        }
    }
}
```

- `format_version`：必需参数，需填写`1.21.130`。
- `minecraft:cubemap_settings`：必需参数，立方体贴图配置。
    - `description`：必需参数，描述信息。
        - `identifier`：必需参数，立方体贴图的标识符。若为`minecraft:default_cubemap`，则默认被所有生物群系使用。
    - `lighting`：必需参数，光照配置。其下的所有参数均可选。
        - `ambient_light_illuminance`：一个数字对，前一个值表示当日时间，应在`0.0`-`1.0`之间；后一个值表示环境光，应在`0.0`-`100000.0`之间。全天所有时间的默认值为`5.625`。
        - `sky_light_contribution`：天空光照的贡献，应在`0.0`-`1.0`之间。默认值为`1.0`。
        - `directional_light_contribution`：定向光照的贡献，应在`0.0`-`1.0`之间。默认值为`1.0`。
        - `affected_by_atmospheric_scattering`：立方体贴图的大气散射状态。默认值为`false`。
        - `affected_by_volumetric_scattering`：立方体贴图的体积散射状态。默认值为`true`。

<Add/> 生物群系的`client_biome.json`中新增了`minecraft:cubemap_identifier`组件，用于引用立方体贴图。若要应用自定义立方体贴图，需要在此指定与配置文件相同的标识符：

```json showLineNumbers title="biomes/river.client_biome.json"
{
    "format_version": "1.21.130",
    "minecraft:client_biome": {
        "description": {
            "identifier": "minecraft:river"
        },
        "components": {
            "minecraft:cubemap_identifier": {
                "cubemap_identifier": "mypack:mycubemap"
            }
        }
    }
}
```

## ScriptAPI

该版本开放了`@minecraft/server`的`2.4.0`版本和`@minecraft/server-ui`的`2.0.0`版本的脚本。

### 世界

- <Add/> [`AABB`接口](/docs/docs/scripts/sapi/server/general#aabb-接口)，代表一个轴对齐的碰撞箱。
- <Add/> [`Entity.getAABB`方法](/docs/docs/scripts/sapi/server/entity_and_player/entity#getaabb-方法)，用于获取实体的碰撞箱。
- <Add/> [`GetBlocksStandingOnOptions`接口](/docs/docs/scripts/sapi/server/entity_and_player/entity#getblocksstandingonoptions-接口)、[`Entity.getBlockStandingOn`方法](/docs/docs/scripts/sapi/server/entity_and_player/entity#getblockstandingon-方法)和[`Entity.getAllBlocksStandingOn`方法](/docs/docs/scripts/sapi/server/entity_and_player/entity#getallblocksstandingon-方法)，用于获取实体脚下所站立的方块。
- <Add/> 战利品表发现接口由测试版开放至`2.4.0`版本。

### 方块

- <Add/> [`BlockRedstoneProducerComponent`类](/docs/docs/scripts/sapi/server/block/component#blockredstoneproducercomponent-类)，用于获取方块的红石生产者组件。
- <Add/> [`InvalidBlockComponentError`类](/docs/docs/scripts/sapi/server/block/component#invalidblockcomponenterror-类)，代表无效的方块组件。
- <Add/> [`BlockComponentBlockBreakEvent`类](/docs/docs/scripts/sapi/server/system/custom_block_component#blockcomponentblockbreakevent-类)，方块被破坏时调用。

### 实体

- <Add/> [`ControlScheme`枚举](/docs/docs/scripts/sapi/server/entity_and_player/input#controlscheme-枚举)，以及[`Player`类](/docs/docs/scripts/sapi/server/entity_and_player/player#player-类)的`setControlScheme()`方法与`getControlScheme()`方法，用于设置与获取玩家的操作方案。

### 物品

- <Add/> [`Potions`类](/docs/docs/scripts/sapi/server/item/potion#potions-类)、[`PotionDeliveryType`类](/docs/docs/scripts/sapi/server/item/potion#potiondeliverytype-类)和[`PotionEffectType`类](/docs/docs/scripts/sapi/server/item/potion#potioneffecttype-类)，用于查询药水效果类型与递送类型，并据此构造药水物品堆叠。
- <Add/> [`ItemPotionComponent`类](/docs/docs/scripts/sapi/server/item/component#itempotioncomponent-类)，用于获取药水物品的效果类型与递送类型。
- <Add/> [`InvalidPotionDeliveryTypeError`类](/docs/docs/scripts/sapi/server/item/potion#invalidpotiondeliverytypeerror-类)和[`InvalidPotionEffectTypeError`类](/docs/docs/scripts/sapi/server/item/potion#invalidpotioneffecttypeerror-类)，代表无效的药水递送类型与药水效果类型。

### 世界生成

- <Add/> [`LiquidSettings`枚举](/docs/docs/scripts/sapi/server/world/structure#liquidsettings-枚举)，以及[`JigsawPlaceOptions`接口](/docs/docs/scripts/sapi/server/world/structure#jigsawplaceoptions-接口)与[`JigsawStructurePlaceOptions`接口](/docs/docs/scripts/sapi/server/world/structure#jigsawstructureplaceoptions-接口)的`liquidSettings`属性，用于定义可含水方块与已有液体重叠时的处理方式。
