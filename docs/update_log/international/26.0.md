# 26.0

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

26.0 是基岩版改用新版本号格式后的首个正式版本，发布于 2026 年 2 月 10 日。从这一版起，主版本号按年份编号，内部格式版本仍沿用`1.26.x`。本次更新的技术性内容以开放实验性功能为主，碰撞箱、连接、支撑等一批方块功能不再需要开启实验性选项，实体 JSON 的解析也收紧了。

有关于 26.0 的完整更新日志，可见下方的中文 Minecraft Wiki。本文只介绍 26.0 的关键技术性更改。

<WikiButton item="基岩版26.0"/>

## 命令

- <Add/> [`/packstack`](/docs/docs/commands/all_commands#packstack)命令，用于在聊天栏输出当前附加包的数据。

## 物品

### 数据驱动物品组件

- <Change/> [`minecraft:damage`](/docs/docs/items/components#minecraftdamage)组件的伤害取值范围扩大到`0`\~`32767`。

## 方块

### 方块几何体

- <Change/> [`minecraft:geometry`](/docs/docs/blocks/components#minecraftgeometry)组件中`minecraft:geometry.full_block`的下面（DOWN）旋转了 180 度，与原版非数据驱动方块及 Java 版保持一致。
    - 需要沿用旧几何体的方块可显式指定`minecraft:geometry.full_block_v1`。
    - 格式版本低于`1.26.0`且仍在用`minecraft:geometry.full_block`的现有方块不受影响。

### 数据驱动方块组件

- <Add/> [`minecraft:collision_box`](/docs/docs/blocks/components#minecraftcollision_box)组件的复合碰撞箱，现在可以用数组定义最多 16 个子碰撞箱。并且 Y 方向上，方块大小与`origin`相加后的上限从`16`提高到`24`。
- <Add/> [`minecraft:redstone_consumer`](/docs/docs/blocks/components#minecraftredstone_consumer)组件，允许方块接收红石信号并触发脚本事件。
- <Add/> [`minecraft:connection_rule`](/docs/docs/blocks/components#minecraftconnection_rule)组件，用于自定义方块之间的连接规则。
- <Add/> [`minecraft:support`](/docs/docs/blocks/components#minecraftsupport)组件，用于定义方块的支撑面与支撑形状。
- <Add/> [`minecraft:leashable`](/docs/docs/blocks/components#minecraftleashable)组件，允许玩家把拴绳系在方块上。
- <Add/> [`minecraft:liquid_detection`](/docs/docs/blocks/components#minecraftliquid_detection)组件的`use_liquid_clipping`参数，用于定义是否按碰撞箱裁剪液体的渲染。
- <Add/> [`minecraft:material_instances`](/docs/docs/blocks/components#minecraftmaterial_instances)组件的`alpha_masked_tint`参数，用于定义是否在 alpha 通道上应用`tint_method`指定的着色。

### 方块特征与方块状态

- <Add/> [`minecraft:connection`](/docs/docs/blocks/traits#minecraftconnection)方块特征，用于让自定义方块像栅栏一样与相邻方块建立连接。
- <Add/> [`minecraft:corner_and_cardinal_direction`](/docs/docs/blocks/traits#minecraftplacement_direction)方块状态，用于定义方块的拐角朝向。
    - 该方块状态的内角状态目前未正确设置，属于已知问题，将在后续版本修复。

## 实体

### 实体组件解析更严格

- <Change/> 现在下列 AI 意向组件的解析会更加严格，并且在`1.26.0`及更高版本中将无法加载包含无效数据的实体 JSON：
    - [`minecraft:behavior.defend_village_target`](/docs/docs/entities/components#minecraftbehaviordefend_village_target)
    - [`minecraft:behavior.nearest_attackable_target`](/docs/docs/entities/components#minecraftbehaviornearest_attackable_target)
    - [`minecraft:behavior.guardian_attack`](/docs/docs/entities/components#minecraftbehaviorguardian_attack)
    - [`minecraft:behavior.delayed_attack`](/docs/docs/entities/components#minecraftbehaviordelayed_attack)
    - [`minecraft:behavior.dragonstrafeplayer`](/docs/docs/entities/components#minecraftbehaviordragonstrafeplayer)
    - [`minecraft:behavior.dragonchargeplayer`](/docs/docs/entities/components#minecraftbehaviordragonchargeplayer)
    - [`minecraft:behavior.melee_attack`](/docs/docs/entities/components#minecraftbehaviormelee_attack)
    - [`minecraft:behavior.melee_box_attack`](/docs/docs/entities/components#minecraftbehaviormelee_box_attack)
    - [`minecraft:behavior.stomp_attack`](/docs/docs/entities/components#minecraftbehaviorstomp_attack)
    - [`minecraft:behavior.timer_flag_1`](/docs/docs/entities/components#minecraftbehaviortimer_flag_1)
    - [`minecraft:behavior.timer_flag_2`](/docs/docs/entities/components#minecraftbehaviortimer_flag_2)
    - [`minecraft:behavior.timer_flag_3`](/docs/docs/entities/components#minecraftbehaviortimer_flag_3)
    - [`minecraft:behavior.move_towards_dwelling_restriction`](/docs/docs/entities/components#minecraftbehaviormove_towards_dwelling_restriction)
    - [`minecraft:behavior.move_towards_home_restriction`](/docs/docs/entities/components#minecraftbehaviormove_towards_home_restriction)
- <Change/> 其中的部分参数现在只接受带`min`与`max`值的对象，写成其他格式将无法解析：
    - [`minecraft:behavior.nearest_attackable_target`](/docs/docs/entities/components#minecraftbehaviornearest_attackable_target)的`attack_interval`参数。
    - [`minecraft:behavior.dragonchargeplayer`](/docs/docs/entities/components#minecraftbehaviordragonchargeplayer)与[`minecraft:behavior.dragonstrafeplayer`](/docs/docs/entities/components#minecraftbehaviordragonstrafeplayer)的`target_zone`参数。
    - 三个`minecraft:behavior.timer_flag_*`意向的`cooldown_range`与`duration_range`参数。

### 注视行为

- <Change/> 下列意向组件的`look_time`参数改为只接受带`min`与`max`值的对象，数组写法在`1.26.0`起弃用。
    - [`minecraft:behavior.look_at_entity`](/docs/docs/entities/components#minecraftbehaviorlook_at_entity)
    - [`minecraft:behavior.look_at_player`](/docs/docs/entities/components#minecraftbehaviorlook_at_player)
    - [`minecraft:behavior.look_at_target`](/docs/docs/entities/components#minecraftbehaviorlook_at_target)
    - [`minecraft:behavior.look_at_trading_player`](/docs/docs/entities/components#minecraftbehaviorlook_at_trading_player)
- <Change/> 这些组件不再接受`target_distance`参数。传入该参数不会报错，而是被静默忽略并使用默认值。

### 数据驱动实体组件

- <Add/> [`minecraft:jump.dynamic`](/docs/docs/entities/components#minecraftjumpdynamic)组件的`regular_skip_data`与`fast_skip_data`参数，分别定义普通跳跃与快速跳跃使用的数据。
    - 两者结构相同，均包含`distance_scale`、`height`、`jump_delay`与`animation_duration`。
- <Add/> 新增实体组件`minecraft:offspring`，用于定义后代的出生方式。[`minecraft:breedable`](/docs/docs/entities/components#minecraftbreedable)组件因此被拆分，只保留求偶、怀孕与触发事件的逻辑。
- <Change/> [`minecraft:interact`](/docs/docs/entities/components#minecraftinteract)组件的`swing`参数默认值改为`true`。
- <Change/> 修复了[`minecraft:equippable`](/docs/docs/entities/components#minecraftequippable)组件的`on_equip`与`on_unequip`在世界加载时被触发的问题，现在只在游戏内发生交互时执行。
- <Change/> 修复了[`minecraft:behavior.fire_at_target`](/docs/docs/entities/components#minecraftbehaviorfire_at_target)组件的`max_head_rotation_x`与`max_head_rotation_y`参数被反向应用的问题。

## 世界生成

### 生物群系

- <Add/> 新增`minecraft:village_type`生物群系组件，用于决定该生物群系中村庄的类型。
- <Add/> 新增下列生物群系标签：
    - `slime`：允许史莱姆在通常高度之上生成。
    - `swamp_water_huge_mushroom`：允许巨型蘑菇在沼泽的浅水中生成。
    - `fast_fishing`：提高该生物群系中的钓鱼速度。
    - `high_seas`：改变鲑鱼的行为。
    - `surface_mineshaft`：将该生物群系中地表废弃矿井的方块改为深色橡木。
- <Change/> 下界现在支持生物群系替换。下界的替换只能配合`minecraft:overworld`、`minecraft:frozen_ocean`、`minecraft:capped`与`minecraft:the_end`这几种`minecraft:surface_builder`使用。
    - 同一个生物群系上同时使用主世界替换与下界替换是可行的，但不建议这样做。
- <Change/> `biomes_client.json`中没有命名空间的生物群系，现在会带默认命名空间应用于`base_game_version`低于`1.21.40`的世界。

## Molang

- <Change/> 格式版本不低于`1.26.0`时，`minecraft:client_entity`与`minecraft:attachable`的`pre_animation`与`initialize`现在支持跨多行的花括号作用域。

## Vibrant Visuals

- <Add/> 光照配置文件现在可以按一天中的时段分别指定环境光颜色、环境光照度与天空光强度。
- <Add/> 水效果配置文件新增`biome_water_color_contribution`参数，用于控制`*.client_biome.json`中各生物群系水体颜色的贡献度。
    - 取值`0.0`\~`1.0`，默认值为`0.0`。

## ScriptAPI

该版本开放了`@minecraft/server`的`2.5.0`版本。

### 世界

- **世界后事件**：
    - <Add/> 玩家挥舞事件：开放了[`PlayerSwingStartAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#playerswingstartafterevent-类)、[`PlayerSwingStartAfterEventSignal`类](/docs/docs/scripts/sapi/server/world/after_events#playerswingstartaftereventsignal-类)、[`PlayerSwingEventOptions`接口](/docs/docs/scripts/sapi/server/world/event_types#playerswingeventoptions-接口)、[`EntitySwingSource`枚举](/docs/docs/scripts/sapi/server/world/event_types#entityswingsource-枚举)与[`HeldItemOption`枚举](/docs/docs/scripts/sapi/server/world/event_types#helditemoption-枚举)，用于在玩家开始挥舞时触发回调。
    - <Change/> 实体受伤后事件：[`EntityHurtAfterEvent`](/docs/docs/scripts/sapi/server/world/after_events#entityhurtafterevent-类)现在在伤害量为`0`时也会发送。

### 方块

- <Add/> [`BlockComponentTypes`](/docs/docs/scripts/sapi/server/block/component#blockcomponenttypes-枚举)枚举补充了`PrecipitationInteractions`、`RedstoneProducer`、`MapColor`与`Movable`四个成员。
- **自定义方块组件**：
    - <Add/> 红石更新回调：开放了[`BlockComponentRedstoneUpdateEvent`类](/docs/docs/scripts/sapi/server/system/custom_block_component#blockcomponentredstoneupdateevent-类)和[`BlockCustomComponent.onRedstoneUpdate`](/docs/docs/scripts/sapi/server/system/custom_block_component#blockcustomcomponent-接口)。

### 修复

- 修复了旧脚本版本中[`ItemStack`类](/docs/docs/scripts/sapi/server/item/main#itemstack-类)和[`Entity`类](/docs/docs/scripts/sapi/server/entity_and_player/entity#entity-类)的`getComponents`方法可能在数组内返回`undefined`的问题。
