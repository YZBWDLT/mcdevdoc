# 1.21.110

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

1.21.111 更新了铜器时代（Copper Age），主要更新了更多的铜制品、铜工具、铜装备和铜傀儡。

有关于 1.21.111 的完整更新日志，可见下方的中文 Minecraft Wiki。按照惯例，本文只介绍 1.21.111 的关键技术性更改。

<WikiButton item="基岩版1.21.111"/> <WikiButton item="铜器时代"/>

## ID 变更

- <Change/> 锁链的 ID 变更为`iron_chain`，以和铜链区分。

## 命令

- <Add/> 为[`/camera`](/docs/docs/commands/all_commands#camera)加入了视场角语法，以设置玩家的视场角：

  ```mcfunction
  /camera <玩家: target> fov_clear [视场角缓动时间: float] [视场角缓动类型: Easing]
  /camera <玩家: target> fov_set <视场角值: float> [视场角缓动时间: float] [视场角缓动类型: Easing]
  ```

## 物品

- <Change/> 现在所有可食用物品均带有`minecraft:is_food`标签，但发光浆果除外。

## 方块

### blocks.json

- <Add/> 加入了扁平化的`oak_planks`、`​spruce_planks`、`​birch_planks`、`​jungle_planks`、`​acacia_planks`、`​dark_oak_planks`、`mossy_stone_brick_double_slab`、`​smooth_quartz_double_slab`、`​normal_stone_double_slab`、`​cut_sandstone_double_slab`和`​cut_red_sandstone_double_slab`定义。现在其他数据驱动方块可以安全地调用这些贴图。

### 方块模型

- <Add/> 为`item_display_transforms`对象加入了新的字段`embedded`，此组件用于定义嵌入方块（如花盆）时的模型变换。若此字段未定义，则默认变换比例为`0.75`，类似于其应用于大部分原版花的情况。

### 数据驱动方块组件

- <Change/> [`minecraft:material_instances`](/docs/docs/blocks/components#minecraftmaterial_instances)组件的各个材质实例的`render_method`参数现在必须保证一致。

## 实体

### 数据驱动实体组件

- <Add/> [`minecraft:vertical_movement_action`](/docs/docs/entities/components#minecraftvertical_movement_action)，定义该实体将可由玩家的跳跃行为控制竖直方向上的运动。
- <Add/> [`minecraft:interact`](/docs/docs/entities/components#minecraftinteract)组件的`equip_item_slot`参数现在支持`slot.weapon.mainhand`和`slot.weapon.offhand`。
- <Change/> [`minecraft:input_air_controlled`](/docs/docs/entities/components#minecraftinput_air_controlled)更名为[`minecraft:free_camera_controlled`](/docs/docs/entities/components#minecraftfree_camera_controlled)。
- <Change/> [`minecraft:input_air_controlled`](/docs/docs/entities/components#minecraftinput_air_controlled)更名为[`minecraft:free_camera_controlled`](/docs/docs/entities/components#minecraftfree_camera_controlled)。
- <Change/> 现在下列 AI 意向组件的解析会更加严格，在`1.21.110`及更高格式版本版本中将无法加载包含无效数据的实体 JSON：

  - [`minecraft:behavior.slime_random_direction`](/docs/docs/entities/components#minecraftbehaviorslime_random_direction)
  - [`minecraft:behavior.sniff`](/docs/docs/entities/components#minecraftbehaviorsniff)
  - [`minecraft:behavior.sonic_boom`](/docs/docs/entities/components#minecraftbehaviorsonic_boom)

### 实体事件

- <Add/> [`drop_item`](/docs/docs/entities/events#drop_item)事件响应，允许实体丢弃物品。

## 生物群系

- <Add/> 自定义生物群系不再需要开启实验性玩法。
- <Change/> `minecraft:overworld_generation_rules`组件和`​minecraft:multinoise_generation_rules`组件现在不会对生物群系生成起作用，并且会在用于自定义生物群系时返回内容日志错误。
- <Add/> `minecraft:biome_music`组件加入了`underwater_music`参数，用于启用生物群系的水下音乐。

## ScriptAPI

该版本开放了`@minecraft/server`的`2.2.0`版本的脚本。

### 世界

- **战利品表**：
  - <Add/> [`LootTableManager`类](/docs/docs/scripts/sapi/docs/world/loot_table#loottablemanager-类)，管理战利品表。

### 实体

- **玩家**：
  - <Add/> 为[`Player`类](/docs/docs/scripts/sapi/docs/entity_and_player/player#player-类)开放了`applyImpulse()`和`​clearVelocity()`方法。
- **相机**：
  - <Add/> 为[`Camera`类](/docs/docs/scripts/sapi/docs/entity_and_player/camera#camera-类)开放了`setFov()`方法。

### 物品

- <Add/> [`InvalidItemStackError`类](/docs/docs/scripts/sapi/docs/item/item_stack#invaliditemstackerror-类)，代表这是一个无效的物品堆叠。
- <Change/> 现在[`ItemStack`类](/docs/docs/scripts/sapi/docs/item/item_stack#itemstack-类)和[`ContainerSlot`类](/docs/docs/scripts/sapi/docs/item/container#containerslot-类)的`setLore()`方法支持使用[`RawMessage`接口](/docs/docs/scripts/sapi/docs/general#rawmessage-接口)。
- <Add/> 开放了[`ItemStack`类](/docs/docs/scripts/sapi/docs/item/item_stack#itemstack-类)和[`ContainerSlot`类](/docs/docs/scripts/sapi/docs/item/container#containerslot-类)的`getRawLore()`方法。
- **物品组件**：
