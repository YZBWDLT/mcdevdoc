# 1.21.50

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';

有关于 1.21.50 的完整更新日志，可见下方的中文 Minecraft Wiki。按照惯例，本文只介绍 1.21.50 的关键更改。

<WikiButton item="基岩版1.21.50"/>

## 命令

- <Add/> [`/schedule`](/docs/docs/commands/all_commands#schedule)命令新增`delay`重载，用于延迟执行函数。

## 物品

### 数据驱动物品组件

- <Add/> [`minecraft:block_placer`](/docs/docs/items/components#minecraftblock_placer)组件，用于渲染所引用方块的物品图标。

## 方块

### 数据驱动方块组件

- <Add/> [`minecraft:destructible_by_mining`](/docs/docs/blocks/components#minecraftdestructible_by_mining)组件，可为原版与自定义方块设置工具等级。

## 实体

### 数据驱动实体组件

- <Add/> [`minecraft:cannot_be_attacked`](/docs/docs/entities/components/functional#minecraftcannot_be_attacked)组件，用于阻止其他实体攻击此实体，除非满足例外过滤器。原版恶魂使用了该组件。
- <Add/> [`minecraft:ignore_cannot_be_attacked`](/docs/docs/entities/components/functional#minecraftignore_cannot_be_attacked)组件，让自定义生物可以攻击带有`minecraft:cannot_be_attacked`组件的实体，而无需修改被攻击方的设置。
- <Add/> [`minecraft:behavior.summon_entity`](/docs/docs/entities/components/ai#minecraftbehaviorsummon_entity)组件支持指定一个事件，在召唤出的实体上立即调用。

### 实体事件

- <Add/> `play_sound`事件响应，允许实体发出音效。
- <Add/> `emit_particle`事件响应，允许在实体的碰撞箱中心释放粒子。

## 世界生成

- <Add/> 客户端生物群系 JSON 新增`minecraft:ambient_sounds`组件，用于定义每个生物群系的环境音效。
- <Add/> 客户端生物群系 JSON 新增`minecraft:biome_music`组件，其`volume_multiplier`字段会在听者位于对应生物群系内时逐渐影响音乐音量。

## Molang

- <Add/> `query.client_memory_tier`、`query.server_memory_tier`与`query.client_max_render_distance`三个查询，返回平台与设备的内存、渲染距离信息。

## ScriptAPI

该版本开放了`@minecraft/server`的`1.16.0`版本。

### 世界

- <Add/> 世界前事件：开放了`ItemUseOnBeforeEvent.isFirstEvent`属性，用于判断这次交互是不是自玩家开始交互以来的第一次交互。
- <Add/> 世界后事件：开放了`ItemUseOnAfterEvent.isFirstEvent`属性，用于判断这次交互是不是自玩家开始交互以来的第一次交互。

> **注意**：`ItemUseOnBeforeEvent`与`ItemUseOnAfterEvent`已在脚本`2.0.0`（游戏 1.21.90）移除，现改用`PlayerInteractWithBlockBeforeEvent`与`PlayerInteractWithBlockAfterEvent`。

### 维度

- <Add/> 开放了[`Dimension.containsBlock`方法](/docs/docs/scripts/sapi/server/dimension/main#containsblock-方法)，检查提供的方块域是否含有特定方块。
- <Add/> 开放了[`Dimension.getBlocks`方法](/docs/docs/scripts/sapi/server/dimension/main#getblocks-方法)，获取提供的方块域内特定的方块信息。
- <Add/> 开放了[`Dimension.fillBlocks`方法](/docs/docs/scripts/sapi/server/dimension/main#fillblocks-方法)，在提供的方块域内按要求填充方块；配套的[`BlockFillOptions`接口](/docs/docs/scripts/sapi/server/dimension/volume#blockfilloptions-接口)定义填充条件。
- <Add/> 开放了[`UnloadedChunksError`类](/docs/docs/scripts/sapi/server/dimension/main#unloadedchunkserror-类)，在玩家尝试在已加载的区块外填充方块时报错。

### 方块

- <Add/> 开放了[`BlockFluidContainerComponent`类](/docs/docs/scripts/sapi/server/block/component#blockfluidcontainercomponent-类)，用于获取液体容器的性质。
- <Add/> 开放了[`FluidContainer`类](/docs/docs/scripts/sapi/server/block/component#fluidcontainer-类)，用于表示液体容器的内容。

### 玩家

- <Add/> 开放了[`ClientSystemInfo`类](/docs/docs/scripts/sapi/server/entity_and_player/player#clientsysteminfo-类)与[`Player.clientSystemInfo`属性](/docs/docs/scripts/sapi/server/entity_and_player/player#player-类)，用于获取玩家当前所使用的平台信息。
- <Add/> 开放了[`PlatformType`枚举](/docs/docs/scripts/sapi/server/entity_and_player/player#platformtype-枚举)，代表玩家当前所使用的平台。
