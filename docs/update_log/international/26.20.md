# 26.20

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';
import Fix from '/src/components/highlight/fix';
import Remove from '/src/components/highlight/remove';

26.20 是一次小版本更新。方块的标签改由`minecraft:tags`组件声明，一批组件的参数开始严格校验取值范围；实体侧则新增了装备变化与死亡生成两个组件，并把`follow_target_captain`重构成了`follow_target_leader`。

有关于 26.20 的完整更新日志，可见下方的中文 Minecraft Wiki。本文只介绍 26.20 的关键技术性更改。

<WikiButton item="基岩版26.20"/>

## 物品

- <Change/> 带有`item_lock`的物品不能再放入书架方块中。
- <Change/> 自定义方块使用的盔甲渲染控制器由`controller.render.armor`改为`controller.render.armor.v2`，修复了部分自定义盔甲无法正常渲染的问题。
- <Fix/> 使用[`minecraft:block_placer`](/docs/docs/items/components#minecraftblock_placer)组件并指定`replace_block_item`的自定义物品，在熔炉配方中被错误分类的问题。

## 方块

### 数据驱动方块组件

- <Add/> [`minecraft:chest_obstruction`](/docs/docs/blocks/components#minecraftchest_obstruction)组件，定义方块是否可阻挡箱子打开。

- <Change/> [`minecraft:placement_direction`](/docs/docs/blocks/traits#minecraftplacement_direction)方块特征的`rotation_offset`不再接受`0.5`的容差，取值必须是`90`的倍数，且应在`0`\~`360`之间。
- <Change/> `blocks_to_corner_with`参数要求`minecraft:corner_and_cardinal_direction`必须是`enabled_states`的成员之一。
- <Change/> 方块描述中的`menu_category`不再接受空的`group`值，且`category`成为必填项。详见[方块描述](/docs/docs/blocks/description)。
- <Change/> [`minecraft:light_dampening`](/docs/docs/blocks/components#minecraftlight_dampening)与[`minecraft:light_emission`](/docs/docs/blocks/components#minecraftlight_emission)组件的值严格限制在`0`\~`15`之间。
- <Change/> [`minecraft:material_instances`](/docs/docs/blocks/components#minecraftmaterial_instances)组件的`ambient_occlusion`参数不再接受布尔值，必须写作`0.0`\~`10.0`之间的数值，默认值为`1.0`。
- <Change/> [`minecraft:geometry`](/docs/docs/blocks/components#minecraftgeometry)组件的`culling_shape`标识符严格校验：使用`minecraft`命名空间时只能是`minecraft:empty`或`minecraft:unit_cube`，自定义标识符必须以字母或数字开头与结尾。
- <Change/> [`minecraft:flower_pottable`](/docs/docs/blocks/components#minecraftflower_pottable)组件不能再写在方块置换中。
- <Change/> [`minecraft:redstone_producer`](/docs/docs/blocks/components#minecraftredstone_producer)组件若要在方块置换中使用，必须同时在基础组件中定义。
- <Change/> [`minecraft:destruction_particles`](/docs/docs/blocks/components#minecraftdestruction_particles)组件未指定`texture`参数时，改为沿用[`minecraft:material_instances`](/docs/docs/blocks/components#minecraftmaterial_instances)的`down`或`*`贴图，不再使用泥土贴图。
- <Fix/> 自定义方块在花盆中的垂直偏移与原版不一致的问题。缺少`geometry`参数时现在会输出内容错误。
- <Fix/> [`minecraft:item_visual`](/docs/docs/blocks/components#minecraftitem_visual)与`minecraft:embedded_visual`组件对纹理变种报出多余内容日志警告的问题。
- <Fix/> 方块置换中的`tag:`条目在升级到格式版本`1.26.20`时被静默丢弃的问题。

### 方块标签

- <Change/> 方块标签不再能以`tag:`开头的顶层条目写在组件列表中，必须改用[`minecraft:tags`](/docs/docs/blocks/components#minecrafttags)组件声明。

## 实体

### 数据驱动实体组件

- <Change/> [`minecraft:friction_modifier`](/docs/docs/entities/components/functional#minecraftfriction_modifier)组件的行为现在与描述一致：取值越高，摩擦力对实体的影响越大。其中`0.0`表示没有摩擦，`1.0`表示常规摩擦，`2.0`表示双倍摩擦。
    - 该组件现在只影响地面摩擦，不再部分影响空气阻力与液体阻力。
    - 该组件现在能正确作用于玩家与其他客户端预测实体。
    - 需要沿用旧行为的实体可以加上[`minecraft:uses_legacy_friction`](/docs/docs/entities/components/functional#minecraftuses_legacy_friction)组件。
- <Add/> [`minecraft:on_equipment_changed`](/docs/docs/entities/components/functional#minecrafton_equipment_changed)组件，用于在装备槽位中的物品被装备或卸下时执行实体事件。
    - 其`slots`参数是一个列表，每一项包含`slot`、`on_equip`与`on_unequip`。
    - 装备变化时只取第一个匹配的槽位。该组件不适用于`minecraft:inventory`的槽位，那类槽位请改用[`minecraft:equippable`](/docs/docs/entities/components/functional#minecraftequippable)。
- <Add/> [`minecraft:spawn_on_death`](/docs/docs/entities/components/functional#minecraftspawn_on_death)组件，用于在实体死亡时生成实体。
    - `entity_to_spawn`指定生成的实体，不指定时生成自身。
    - `spawn_method`可选`born`、`spawned`（默认值）与`summoned`。
    - `spawn_amount`指定生成数量，默认值为`1`；`inherit_parent_name`指定是否继承名称，默认值为`true`。
    - `additional_spawn_range`指定额外的随机生成范围，`filters`指定触发条件。
- <Change/> [`minecraft:knockback_resistance`](/docs/docs/entities/components/functional#minecraftknockback_resistance)组件现在接受负值，最低可到`-2`，此时击退会被放大。
- <Change/> [`minecraft:damage_sensor`](/docs/docs/entities/components/sensors#minecraftdamage_sensor)组件的`deals_damage`参数新增取值`no_but_entity_effects_apply`，不施加伤害，但保留击退、魔咒与其他攻击效果。
- <Change/> [`minecraft:behavior.follow_target_captain`](/docs/docs/entities/components/deprecated#minecraftbehaviorfollow_target_captain)重构为[`minecraft:behavior.follow_target_leader`](/docs/docs/entities/components/ai#minecraftbehaviorfollow_target_leader)。
    - 新增`always_look_for_leader`参数，默认值为`false`，为`true`时找不到有效首领就会持续搜索。
    - `leader_filters`为必填参数，用于判断目标能否作为首领。
    - `search_cooldown`参数指定重新搜索的间隔刻数，默认值为`20`。
- <Add/> [`minecraft:behavior.pickup_items`](/docs/docs/entities/components/ai#minecraftbehaviorpickup_items)组件的`on_pickup_item_start`与`on_pickup_item_end`事件响应。
- <Change/> 现在下列 AI 意向组件的解析会更加严格，并且在`1.26.20`及更高版本中将无法加载包含无效数据的实体 JSON：[`minecraft:behavior.hide`](/docs/docs/entities/components/ai#minecraftbehaviorhide)、[`minecraft:behavior.mingle`](/docs/docs/entities/components/ai#minecraftbehaviormingle)、[`minecraft:behavior.move_to_poi`](/docs/docs/entities/components/ai#minecraftbehaviormove_to_poi)、[`minecraft:behavior.move_to_village`](/docs/docs/entities/components/ai#minecraftbehaviormove_to_village)、[`minecraft:behavior.sleep`](/docs/docs/entities/components/ai#minecraftbehaviorsleep)、[`minecraft:behavior.stroll_towards_village`](/docs/docs/entities/components/ai#minecraftbehaviorstroll_towards_village)、[`minecraft:behavior.equip_item`](/docs/docs/entities/components/ai#minecraftbehaviorequip_item)、[`minecraft:behavior.move_outdoors`](/docs/docs/entities/components/ai#minecraftbehaviormove_outdoors)、[`minecraft:behavior.move_indoors`](/docs/docs/entities/components/ai#minecraftbehaviormove_indoors)、[`minecraft:behavior.admire_item`](/docs/docs/entities/components/ai#minecraftbehavioradmire_item)、[`minecraft:behavior.barter`](/docs/docs/entities/components/ai#minecraftbehaviorbarter)、[`minecraft:behavior.eat_carried_item`](/docs/docs/entities/components/ai#minecraftbehavioreat_carried_item)、[`minecraft:behavior.find_cover`](/docs/docs/entities/components/ai#minecraftbehaviorfind_cover)、[`minecraft:behavior.find_mount`](/docs/docs/entities/components/ai#minecraftbehaviorfind_mount)、[`minecraft:behavior.find_underwater_treasure`](/docs/docs/entities/components/ai#minecraftbehaviorfind_underwater_treasure)、[`minecraft:behavior.flee_sun`](/docs/docs/entities/components/ai#minecraftbehaviorflee_sun)、[`minecraft:behavior.float`](/docs/docs/entities/components/ai#minecraftbehaviorfloat)、[`minecraft:behavior.follow_owner`](/docs/docs/entities/components/ai#minecraftbehaviorfollow_owner)、[`minecraft:behavior.follow_parent`](/docs/docs/entities/components/ai#minecraftbehaviorfollow_parent)、[`minecraft:behavior.hold_ground`](/docs/docs/entities/components/ai#minecraftbehaviorhold_ground)、[`minec     - [`minecraft:behavior.admire_item`](/docs/docs/entities/components/ai#minecraftbehavioradmire_item)的`sound_interval`参数。
    - [`minecraft:behavior.jump_around_target`](/docs/docs/entities/components/ai#minecraftbehaviorjump_around_target)的`valid_distance_to_target`与`landing_distance_from_target`参数。

### 实体过滤器

- <Add/> [`has_same_equipment_in_slot_as`](/docs/docs/entities/filters#has_same_equipment_in_slot_as)实体过滤器，用于检查两个槽位中的装备是否相同。
- <Remove/> `has_equipment_block_tag`实体过滤器。方块标签不应用于判断物品行为，需要检查装备时请改用`has_same_equipment_in_slot_as`。

## 世界生成

### 地物

- <Add/> `minecraft:structure_template_feature`的`rotate_around_center`参数，为`true`时结构围绕中心旋转，默认值为`false`。
- <Add/> `snap_to_surface_feature`的`embed_in_surface`参数，用于指定被吸附的地物是否嵌入表面，默认值为`false`。

### 拼图

- <Add/> 拼图结构模板池现在可以使用`minecraft:feature_pool_element`放置地物。
- <Change/> 地物可以连接到目标名称任意的拼图方块，不再只支持`minecraft:bottom`。

## ScriptAPI

该版本开放了`@minecraft/server`的`2.7.0`版本。

### 实体

- <Add/> [`Entity.addItem`方法](/docs/docs/scripts/sapi/server/entity_and_player/entity#additem-方法)，用于直接向实体或玩家的物品栏添加物品。
- <Add/> [`InvalidEntityComponentError`类](/docs/docs/scripts/sapi/server/entity_and_player/entity#invalidentitycomponenterror-类)，用于表示实体组件相关错误。

### 维度

- <Add/> [`BiomeTypes`类](/docs/docs/scripts/sapi/server/dimension/biome#biometypes-类)，以及它的[`get`方法](/docs/docs/scripts/sapi/server/dimension/biome#get-方法)与[`getAll`方法](/docs/docs/scripts/sapi/server/dimension/biome#getall-方法)。
- <Add/> [`BiomeType.getTags`方法](/docs/docs/scripts/sapi/server/dimension/biome#gettags-方法)与[`BiomeType.hasTags`方法](/docs/docs/scripts/sapi/server/dimension/biome#hastags-方法)，用于读取生物群系标签。

### 瞄准辅助

- <Add/> [`AimAssistRegistry`类](/docs/docs/scripts/sapi/server/entity_and_player/aim_assist#aimassistregistry-类)、[`AimAssistCategory`类](/docs/docs/scripts/sapi/server/entity_and_player/aim_assist#aimassistcategory-类)、[`AimAssistPreset`类](/docs/docs/scripts/sapi/server/entity_and_player/aim_assist#aimassistpreset-类)、[`PlayerAimAssist`类](/docs/docs/scripts/sapi/server/entity_and_player/aim_assist#playeraimassist-类)与[`AimAssistTargetMode`枚举](/docs/docs/scripts/sapi/server/entity_and_player/aim_assist#aimassisttargetmode-枚举)，用于注册与查询瞄准辅助的类别、预设与玩家设置。
- <Add/> [`World.getAimAssist`方法](/docs/docs/scripts/sapi/server/world/main#getaimassist-方法)与[`Player.getAimAssist`方法](/docs/docs/scripts/sapi/server/entity_and_player/player#getaimassist-方法)，用于获取世界与玩家的瞄准辅助对象。

### 其他

- <Add/> `@minecraft/common`的`InvalidArgumentErrorType`枚举新增`InvalidType`与`UnsupportedValue`两个成员。
- <Change/> 错误内容日志现在会带上包名，便于排查是哪个附加包出错。
