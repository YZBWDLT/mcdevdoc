# 1.21.20

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

有关于 1.21.20 的完整更新日志，可见下方的中文 Minecraft Wiki。按照惯例，本文只介绍 1.21.20 的关键更改。

<WikiButton item="基岩版1.21.20"/>

## 物品

### 数据驱动物品组件

- <Add/> [`minecraft:custom_components`](/docs/docs/items/components#minecraftcustom_components)组件，用于声明自定义物品组件。
- <Add/> [`minecraft:damage_absorption`](/docs/docs/items/components#minecraftdamage_absorption)组件，用于定义该物品在穿戴时可吸收何种类型的伤害。
- <Add/> [`minecraft:durability_sensor`](/docs/docs/items/components#minecraftdurability_sensor)组件，用于定义物品在降低耐久度后触发的事件。
- <Add/> [`minecraft:interact`](/docs/docs/entities/components/functional#minecraftinteract)组件的`slot.armor.body`值，装备到该槽位的物品会装备到实体的身体部位。

## 方块

### 数据驱动方块组件

- <Add/> [`minecraft:custom_components`](/docs/docs/blocks/components#minecraftcustom_components)组件，用于声明自定义方块组件。

## 实体

### 数据驱动实体组件

- <Add/> [`minecraft:behavior.swim_up_for_breath`](/docs/docs/entities/components/ai#minecraftbehaviorswim_up_for_breath)组件，让生物在快要无法呼吸时尝试移动到能呼吸空气的位置。原版河豚使用了此组件，基于原版海豚构建的自定义内容需要自行添加该组件才能启用此 AI 行为。
- <Add/> [`minecraft:behavior.teleport_to_owner`](/docs/docs/entities/components/ai#minecraftbehaviorteleport_to_owner)组件，让实体传送到它的主人身边，用于`minecraft:behavior.follow_owner`过慢或优先级过低时的应急情况。
- <Change/> `minecraft:behavior.move_away_from_target`组件更名为[`minecraft:behavior.move_around_target`](/docs/docs/entities/components/ai#minecraftbehaviormove_around_target)组件。
- <Add/> 开放了`owner_distance`实体过滤器，用于检查实体与其主人之间的距离。

## 世界生成

- <Add/> `scatter_feature`地物新增`distribution`字段，定义散布设置。

## ScriptAPI

该版本开放了`@minecraft/server`的`1.13.0`版本与`@minecraft/server-ui`的`1.2.0`版本。

### 维度

- <Add/> 开放了[`Dimension.getTopmostBlock`方法](/docs/docs/scripts/sapi/server/dimension/main#gettopmostblock-方法)与[`VectorXZ`接口](/docs/docs/scripts/sapi/server/general#vectorxz-接口)，用于获取最高处方块。

### 实体

- <Add/> 开放了[`EntityLeashableComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entityleashablecomponent-类)，用于获取实体的拴绳相关参数。

### 脚本 UI

- <Add/> 开放了[`ModalFormData.submitButton`方法](/docs/docs/scripts/sapi/server-ui/traditional#submitbutton-方法)，用于更改模态表单的提交按钮文本。
