# 26.10

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';
import Fix from '/src/components/highlight/fix';

26.10 更新了**小鬼当家（Tiny Takeover）**，主要包括幼年生物的外观模型。开发侧的内容以组件调整为主：`minecraft:pushable`被拆成两个组件，`minecraft:buoyant`换了控制浮动的参数。Vibrant Visuals 正式支持了彩色光源。此外，脚本侧开放了`2.6.0`版本，带来治疗、拾取、掉落的整套事件。

有关于 26.10 的完整更新日志，可见下方的中文 Minecraft Wiki。本文只介绍 26.10 的关键技术性更改。

<WikiButton item="基岩版26.10"/>

## 命令

- <Change/> [`/camera`](/docs/docs/commands/all_commands#camera)命令的`attach_to_entity`、`detach_from_entity`与`play_spline`语法不再需要实验性玩法。

## 物品

### 数据驱动物品组件

- <Add/> [`minecraft:block_placer`](/docs/docs/items/components#minecraftblock_placer)组件的`aligned_placement`参数，为`true`时按住交互键放置的方块会对齐到玩家朝向。默认值为`false`。

## 方块

### 数据驱动方块组件

- <Change/> [`minecraft:liquid_detection`](/docs/docs/blocks/components#minecraftliquid_detection)组件的`detection_rules`不再接受空数组，写成空数组会导致方块加载失败并产生内容错误。
- <Fix/> [`minecraft:placement_filter`](/docs/docs/blocks/components#minecraftplacement_filter)与[`minecraft:block_placer`](/docs/docs/items/components#minecraftblock_placer)组件配合`liquid_clipped`使用时，无法放置到液体方块上的问题。
- <Fix/> [`minecraft:item_visual`](/docs/docs/blocks/components#minecraftitem_visual)组件中的`minecraft:geometry`越界导致客户端崩溃的问题。
- <Fix/> 关闭环境光遮蔽的自定义方块不再偶发出现黑色顶点，使用自定义几何体的方块的环境光遮蔽也有所改善。
- <Fix/> [`minecraft:geometry`](/docs/docs/blocks/components#minecraftgeometry)组件的`minecraft:geometry.full_block`在物品展示框中旋转错误的问题。

### 方块特征

- <Fix/> 使用`minecraft:corner_and_cardinal_direction`方块状态的方块，与同类型的楼梯相邻时现在能正确形成内角。
    - 对于`base_game_version`为`26.10`或更高的世界，不同材质楼梯相邻时不再漏水。

## 实体

### 数据驱动实体组件

- <Add/> [`minecraft:ageable`](/docs/docs/entities/components/functional#minecraftageable)组件的四个参数：
    - `pause_growth_items`参数，定义可让幼年实体暂停成长的物品。
    - `reset_growth_items`参数，定义可重置幼年实体成长进度的物品。
    - `pause_growth`参数，定义成长被暂停时触发的事件。
    - `reset_growth`参数，定义成长进度被重置时触发的事件。
- <Change/> [`minecraft:pushable`](/docs/docs/entities/components/deprecated#minecraftpushable)组件不再被解析，由下面两个组件取代：
    - [`minecraft:pushable_by_block`](/docs/docs/entities/components/attributes#minecraftpushable_by_block)，等同于原来的`is_pushable_by_piston`，存在时活塞与潜影盒可以推动该实体。
    - [`minecraft:pushable_by_entity`](/docs/docs/entities/components/attributes#minecraftpushable_by_entity)，等同于原来的`is_pushable`，存在时其他实体可以推动该实体。
- [`minecraft:buoyant`](/docs/docs/entities/components/functional#minecraftbuoyant)组件的两个参数：
    - <Change/> `simulate_waves`参数由`movement_type`参数取代。
    - <Add/> `can_auto_step_from_liquid`参数，定义实体被推向相邻固体方块时能否自行上岸。默认值为`false`。
- <Change/> 现在下列 AI 意向组件的解析会更加严格，并且在`1.26.10`及更高版本中将无法加载包含无效数据的实体 JSON：[`minecraft:behavior.drop_item_for`](/docs/docs/entities/components/ai#minecraftbehaviordrop_item_for)、[`minecraft:behavior.fertilize_farm_block`](/docs/docs/entities/components/ai#minecraftbehaviorfertilize_farm_block)、[`minecraft:behavior.harvest_farm_block`](/docs/docs/entities/components/ai#minecraftbehaviorharvest_farm_block)、[`minecraft:behavior.inspect_bookshelf`](/docs/docs/entities/components/ai#minecraftbehaviorinspect_bookshelf)、[`minecraft:behavior.lay_egg`](/docs/docs/entities/components/ai#minecraftbehaviorlay_egg)、[`minecraft:behavior.ram_attack`](/docs/docs/entities/components/ai#minecraftbehaviorram_attack)、[`minecraft:behavior.celebrate`](/docs/docs/entities/components/ai#minecraftbehaviorcelebrate)、[`minecraft:behavior.celebrate_survive`](/docs/docs/entities/components/ai#minecraftbehaviorcelebrate_survive)、[`minecraft:behavior.random_search_and_dig`](/docs/docs/entities/components/ai#minecraftbehaviorrandom_search_and_dig)、[`minecraft:behavior.swim_with_entity`](/docs/docs/entities/components/ai#minecraftbehaviorswim_with_entity)、[`minecraft:behavior.take_flower`](/docs/docs/entities/components/ai#minecraftbehaviortake_flower)、[`minecraft:behavior.trade_with_player`](/docs/docs/entities/components/ai#minecraftbehaviortrade_with_player)、[`minecraft:behavior.teleport_to_owner`](/docs/docs/entities/components/ai#minecraftbehaviorteleport_to_owner)、[`minecraft:behavior.work`](/docs/docs/entities/components/ai#minecraftbehaviorwork)、[`minecraft:behavior.work_composter`](/docs/docs/entities/components/ai#minecraftbehaviorwork_composter)、[`minecraft:behavior.move_to_land`](/docs/docs/entities/components/ai#minecraftbehaviormove_to_land)、[`minecraft:behavior.move_to_water`](/docs/docs/entities/components/ai#minecraftbehaviormove_to_water)、[`minecraft:behavior.ocelot_sit_on_block`](/docs/docs/entities/components/ai#minecraftbehaviorocelot_sit_on_block)、[`minecraft:behavior.raid_garden`](/docs/docs/entities/components/ai#minecraftbehaviorraid_garden)、[`minecraft:behavior.stomp_turtle_egg`](/docs/docs/entities/components/ai#minecraftbehaviorstomp_turtle_egg)、[`minecraft:behavior.offer_flower`](/docs/docs/entities/components/ai#minecraftbehavioroffer_flower)、[`minecraft:behavior.play_dead`](/docs/docs/entities/components/ai#minecraftbehaviorplay_dead)、[`minecraft:behavior.play`](/docs/docs/entities/components/ai#minecraftbehaviorplay)。
    - 其中的部分参数现在只接受带`min`与`max`值的对象，写成其他格式将无法解析：
        - [`minecraft:behavior.drop_item_for`](/docs/docs/entities/components/ai#minecraftbehaviordrop_item_for)的`time_of_day_range`参数。
        - [`minecraft:behavior.ram_attack`](/docs/docs/entities/components/ai#minecraftbehaviorram_attack)的`cooldown_range`参数。
        - [`minecraft:behavior.celebrate`](/docs/docs/entities/components/ai#minecraftbehaviorcelebrate)的`sound_interval`与`jump_interval`参数。
        - [`minecraft:behavior.celebrate_survive`](/docs/docs/entities/components/ai#minecraftbehaviorcelebrate_survive)的`fireworks_interval`参数。
        - [`minecraft:behavior.random_search_and_dig`](/docs/docs/entities/components/ai#minecraftbehaviorrandom_search_and_dig)的`cooldown_range`与`digging_duration_range`参数。
        - [`minecraft:behavior.play_dead`](/docs/docs/entities/components/ai#minecraftbehaviorplay_dead)的`random_damage_range`参数。
    - [`minecraft:behavior.lay_egg`](/docs/docs/entities/components/ai#minecraftbehaviorlay_egg)的`lay_seconds`参数现在只接受大于等于`0`的数值。

### 实体过滤器

- <Add/> [`is_tamed`](/docs/docs/entities/filters#is_tamed)实体过滤器，用于检查目标实体是否已被驯服。

### 客户端实体文件

- <Add/> [`minecraft:client_entity`](/docs/docs/entities/description)的`held_item_scale`参数，用于缩放实体手持物品的渲染大小。默认值为`1.0`。

### 其他

- <Change/> 单个游戏刻内请求生成的经验球超过 512 个时，会触发内容警告。

## 世界生成

### 地物

- <Change/> 地物文件的加载不再要求文件名与目录层级，现在只按 JSON 中的`identifier`识别，可以放在任意子目录中。

### 装饰器

- <Add/> `canopy_decorator`的`decoration_blocks_sequence`参数，允许按顺序连续放置多个方块，每个方块可单独指定`count`。
    - 旧的`decoration_block`与`num_steps`写法仍然可用，两者同时存在时以新写法为准。

## Molang

- <Add/> `query.get_level_seed_based_fraction`查询不再需要开启实验性玩法。

## Vibrant Visuals

- <Add/> 正式开放了彩色光源。资源包需在`local_lighting.json`中提供`static_light`条目；没有提供`static_light`与`light_color`的方块使用统一的默认光照颜色。
- <Add/> 粒子现在也支持静态光照着色，活塞、移动方块、告示牌、床与箱子等更多方块加入了本地静态光照。
- <Change/> 移除了对`ESSL_300`着色器语言的支持。

## 专用服务器

- <Add/> `@minecraft/server-net`新增了四个 HTTP 请求错误类型：`HttpRequestBodyTooLargeError`、`HttpRequestLimitExceededError`、`HttpRequestNotAllowedError`与`HttpsOnlyError`。
- <Add/> 服务器运营者现在可以在`permissions.json`的`module_permissions`中为`@minecraft/server-net`配置允许的 URI、是否强制 HTTPS、请求体大小上限、并发请求数上限与会话头。

    ```json showLineNumbers title="config/default/permissions.json"
    {
        "allowed_modules": ["@minecraft/server-net"],
        "module_permissions": {
            "@minecraft/server-net": {
                "allowed_uris": ["https://example.com/"],
                "force_https": true,
                "max_body_bytes": 1048576,
                "max_concurrent_requests": 1,
                "session_headers": {
                    "session-data": "abc123"
                }
            }
        }
    }
    ```
