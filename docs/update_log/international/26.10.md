# 26.10

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

:::warning[注意]

本文仍在编辑，仅供参考。

:::

26.10 更新了幼年生物的外观模型（Tiny Takeover），开发侧的内容以组件调整为主：`minecraft:pushable`被拆成两个组件，`minecraft:buoyant`换了控制浮动的参数。此外，脚本侧开放了`2.6.0`版本，带来治疗、拾取、掉落的整套事件和瞄准辅助接口。

有关于 26.10 的完整更新日志，可见下方的中文 Minecraft Wiki。本文只介绍 26.10 的关键技术性更改。

<WikiButton item="基岩版26.10"/>

## 物品

### 数据驱动物品组件

- <Add/> [`minecraft:block_placer`](/docs/docs/items/components#minecraftblock_placer)组件的`aligned_placement`参数，为`true`时按住交互键放置的方块会对齐到玩家朝向。默认值为`false`。
    - 该参数需要格式版本不低于`1.26.0`。

## 方块

### 数据驱动方块组件

- <Add/> [`minecraft:liquid_detection`](/docs/docs/blocks/components#minecraftliquid_detection)组件的`detection_rules`不再接受空数组，写成空数组会导致方块加载失败并产生内容错误。
- <Change/> 修复了[`minecraft:placement_filter`](/docs/docs/blocks/components#minecraftplacement_filter)与[`minecraft:block_placer`](/docs/docs/items/components#minecraftblock_placer)组件配合`liquid_clipped`使用时，无法放置到液体方块上的问题。
- <Change/> 修复了[`minecraft:item_visual`](/docs/docs/blocks/components#minecraftitem_visual)组件中的`minecraft:geometry`越界导致客户端崩溃的问题。
- <Change/> 关闭环境光遮蔽的自定义方块不再偶发出现黑色顶点，使用自定义几何体的方块的环境光遮蔽也有所改善。

### 方块状态

- <Change/> 使用`minecraft:corner_and_cardinal_direction`方块状态的方块，与同类型的楼梯相邻时现在能正确形成内角。
    - 对于`base_game_version`为`26.10`或更高的世界，不同材质楼梯相邻时不再漏水。

## 实体

### 年龄成长控制

- <Add/> [`minecraft:ageable`](/docs/docs/entities/components#minecraftageable)组件的`pause_growth_items`参数，定义可让幼年实体暂停成长的物品。
- <Add/> [`minecraft:ageable`](/docs/docs/entities/components#minecraftageable)组件的`reset_growth_items`参数，定义可重置幼年实体成长进度的物品。

### 实体事件

- <Add/> `pause_growth`与`reset_growth`实体事件响应，分别在成长被暂停与被重置时触发。

### 可推动组件拆分

- <Change/> [`minecraft:pushable`](/docs/docs/entities/components#minecraftpushable)组件不再被解析，由下面两个组件取代：
    - [`minecraft:pushable_by_block`](/docs/docs/entities/components#minecraftpushable_by_block)，等同于原来的`is_pushable_by_piston`，存在时活塞与潜影盒可以推动该实体。
    - [`minecraft:pushable_by_entity`](/docs/docs/entities/components#minecraftpushable_by_entity)，等同于原来的`is_pushable`，存在时其他实体可以推动该实体。

### 浮力组件

- <Change/> [`minecraft:buoyant`](/docs/docs/entities/components#minecraftbuoyant)组件的`simulate_waves`参数由`movement_type`取代。
    - `movement_type`可选`waves`（按速度模拟波浪，默认值）、`bobbing`（以恒定节奏上下浮动）与`none`（不浮动）。
    - `big_wave_probability`与`big_wave_speed`只在`movement_type`为`waves`时生效。
- <Add/> [`minecraft:buoyant`](/docs/docs/entities/components#minecraftbuoyant)组件的`can_auto_step_from_liquid`参数，定义实体被推向相邻固体方块时能否自行上岸。默认值为`false`。

### 实体过滤器

- <Add/> [`is_tamed`](/docs/docs/entities/filters#is_tamed)实体过滤器，用于检查目标实体是否已被驯服。

### 实体组件解析更严格

- <Change/> 现在下列 AI 意向组件的解析会更加严格，并且在`1.26.10`及更高版本中将无法加载包含无效数据的实体 JSON：
    - 农业与交互类：[`minecraft:behavior.drop_item_for`](/docs/docs/entities/components#minecraftbehaviordrop_item_for)、[`minecraft:behavior.fertilize_farm_block`](/docs/docs/entities/components#minecraftbehaviorfertilize_farm_block)、[`minecraft:behavior.harvest_farm_block`](/docs/docs/entities/components#minecraftbehaviorharvest_farm_block)、[`minecraft:behavior.inspect_bookshelf`](/docs/docs/entities/components#minecraftbehaviorinspect_bookshelf)、[`minecraft:behavior.lay_egg`](/docs/docs/entities/components#minecraftbehaviorlay_egg)。
    - 战斗与移动类：[`minecraft:behavior.ram_attack`](/docs/docs/entities/components#minecraftbehaviorram_attack)、[`minecraft:behavior.celebrate`](/docs/docs/entities/components#minecraftbehaviorcelebrate)、[`minecraft:behavior.celebrate_survive`](/docs/docs/entities/components#minecraftbehaviorcelebrate_survive)、[`minecraft:behavior.random_search_and_dig`](/docs/docs/entities/components#minecraftbehaviorrandom_search_and_dig)、[`minecraft:behavior.swim_with_entity`](/docs/docs/entities/components#minecraftbehaviorswim_with_entity)、[`minecraft:behavior.take_flower`](/docs/docs/entities/components#minecraftbehaviortake_flower)、[`minecraft:behavior.trade_with_player`](/docs/docs/entities/components#minecraftbehaviortrade_with_player)、[`minecraft:behavior.teleport_to_owner`](/docs/docs/entities/components#minecraftbehaviorteleport_to_owner)、[`minecraft:behavior.work`](/docs/docs/entities/components#minecraftbehaviorwork)、[`minecraft:behavior.work_composter`](/docs/docs/entities/components#minecraftbehaviorwork_composter)、[`minecraft:behavior.move_to_land`](/docs/docs/entities/components#minecraftbehaviormove_to_land)、[`minecraft:behavior.move_to_water`](/docs/docs/entities/components#minecraftbehaviormove_to_water)、[`minecraft:behavior.ocelot_sit_on_block`](/docs/docs/entities/components#minecraftbehaviorocelot_sit_on_block)、[`minecraft:behavior.raid_garden`](/docs/docs/entities/components#minecraftbehaviorraid_garden)、[`minecraft:behavior.stomp_turtle_egg`](/docs/docs/entities/components#minecraftbehaviorstomp_turtle_egg)、[`minecraft:behavior.offer_flower`](/docs/docs/entities/components#minecraftbehavioroffer_flower)、[`minecraft:behavior.play_dead`](/docs/docs/entities/components#minecraftbehaviorplay_dead)、[`minecraft:behavior.play`](/docs/docs/entities/components#minecraftbehaviorplay)。
- <Change/> 其中的部分参数现在只接受带`min`与`max`值的对象，写成其他格式将无法解析：
    - [`minecraft:behavior.drop_item_for`](/docs/docs/entities/components#minecraftbehaviordrop_item_for)的`time_of_day_range`参数。
    - [`minecraft:behavior.ram_attack`](/docs/docs/entities/components#minecraftbehaviorram_attack)的`cooldown_range`参数。
    - [`minecraft:behavior.celebrate`](/docs/docs/entities/components#minecraftbehaviorcelebrate)的`sound_interval`与`jump_interval`参数。
    - [`minecraft:behavior.celebrate_survive`](/docs/docs/entities/components#minecraftbehaviorcelebrate_survive)的`fireworks_interval`参数。
    - [`minecraft:behavior.random_search_and_dig`](/docs/docs/entities/components#minecraftbehaviorrandom_search_and_dig)的`cooldown_range`与`digging_duration_range`参数。
    - [`minecraft:behavior.play_dead`](/docs/docs/entities/components#minecraftbehaviorplay_dead)的`random_damage_range`参数。
- <Change/> [`minecraft:behavior.lay_egg`](/docs/docs/entities/components#minecraftbehaviorlay_egg)的`lay_seconds`参数现在只接受大于等于`0`的数值。

### 其他

- <Change/> 单个游戏刻内请求生成的经验球超过 512 个时，会触发内容警告。
- <Add/> [`minecraft:client_entity`](/docs/docs/entities/description)的`held_item_scale`参数，用于缩放实体手持物品的渲染大小。默认值为`1.0`。

## 世界生成

### 地物

- <Change/> 地物文件的加载不再要求文件名与目录层级，现在只按 JSON 中的`identifier`识别，可以放在任意子目录中。

### 装饰器

- <Add/> `canopy_decorator`的`decoration_blocks_sequence`参数，允许按顺序连续放置多个方块，每个方块可单独指定`count`。
    - 旧的`decoration_block`与`num_steps`写法仍然可用，两者同时存在时以新写法为准。

## Molang

- <Add/> `query.get_level_seed_based_fraction`查询不再需要开启实验性玩法。

## Vibrant Visuals

- <Add/> 彩色方块光照不再需要开启「Render Dragon Features for Creator」实验性玩法，也不再需要预览版。
    - 资源包需在`local_lighting.json`中提供`static_light`条目；没有提供`static_light`与`light_color`的方块使用统一的默认光照颜色。
- <Add/> 粒子现在也支持静态光照着色，活塞、移动方块、告示牌、床与箱子等更多方块加入了本地静态光照。

## ScriptAPI

该版本开放了`@minecraft/server`的`2.6.0`版本。

### 世界

- <Add/> 常加载区域：开放了[`TickingAreaManager`类](/docs/docs/scripts/sapi/server/world/tickingarea#tickingareamanager-类)、[`TickingArea`接口](/docs/docs/scripts/sapi/server/world/tickingarea#tickingarea-接口)，以及[`World.tickingAreaManager`属性](/docs/docs/scripts/sapi/server/world/main)。
- <Add/> [`World.seed`属性](/docs/docs/scripts/sapi/server/world/main)，用于获取世界种子。
- **世界前事件**
    - <Add/> 实体受伤前事件：开放了[`EntityHurtBeforeEvent`类](/docs/docs/scripts/sapi/server/world/before_events#entityhurtbeforeevent-类)与[`EntityHurtBeforeEventOptions`接口](/docs/docs/scripts/sapi/server/world/event_types#entityhurtbeforeeventoptions-接口)。
    - <Add/> 实体治疗前事件：开放了[`EntityHealBeforeEvent`类](/docs/docs/scripts/sapi/server/world/before_events#entityhealbeforeevent-类)。
    - <Add/> 实体拾取物品前事件：开放了[`EntityItemPickupBeforeEvent`类](/docs/docs/scripts/sapi/server/world/before_events#entityitempickupbeforeevent-类)。
- **世界后事件**
    - <Add/> 实体治疗后事件：开放了[`EntityHealAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#entityhealafterevent-类)、[`EntityHealCause`枚举](/docs/docs/scripts/sapi/server/world/event_types#entityhealcause-枚举)、[`EntityHealSource`类](/docs/docs/scripts/sapi/server/world/event_types#entityhealsource-类)与[`EntityHealEventOptions`接口](/docs/docs/scripts/sapi/server/world/event_types#entityhealeventoptions-接口)。
    - <Add/> 实体拾取物品后事件：开放了[`EntityItemPickupAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#entityitempickupafterevent-类)与[`ItemFilter`接口](/docs/docs/scripts/sapi/server/world/event_types#itemfilter-接口)。
    - <Add/> 实体掉落物品事件：开放了[`EntityItemDropAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#entityitemdropafterevent-类)与[`EntityItemDropEventOptions`接口](/docs/docs/scripts/sapi/server/world/event_types#entityitemdropeventoptions-接口)。

### 维度

- <Add/> 生物群系查询：开放了[`Dimension.containsBiomes`方法](/docs/docs/scripts/sapi/server/dimension/main#containsbiomes-方法)与[`BiomeFilter`接口](/docs/docs/scripts/sapi/server/dimension/biome#biomefilter-接口)。

### 方块

- <Add/> [`Block.getComponents`方法](/docs/docs/scripts/sapi/server/block/main#getcomponents-方法)与[`Block.hasComponent`方法](/docs/docs/scripts/sapi/server/block/main#hascomponent-方法)，用于读取方块上的组件。
- **自定义方块组件**
    - <Add/> 实体事件：开放了[`BlockComponentEntityEvent`类](/docs/docs/scripts/sapi/server/system/custom_block_component#blockcomponententityevent-类)。
    - <Add/> 红石更新事件：[`BlockComponentRedstoneUpdateEvent`类](/docs/docs/scripts/sapi/server/system/custom_block_component#blockcomponentredstoneupdateevent-类)新增`previousPowerLevel`属性，用于获取上一刻的红石信号强度。

### 物品

- <Add/> [`ItemDurabilityComponent`类](/docs/docs/scripts/sapi/server/item/component#itemdurabilitycomponent-类)的`unbreakable`属性，用于设置物品不会损坏。
- <Add/> [`FeedItem`接口](/docs/docs/scripts/sapi/server/entity_and_player/component#feeditem-类)的`resultItem`属性，用于获取喂食产生的物品。
- <Add/> `Block`、`BlockPermutation`、`BlockType`、`EntityType`与`ItemType`的`localizationKey`属性，用于获取本地化键名。

### 相机与瞄准辅助

- <Add/> 相机动画与附着：开放了[`Camera.playAnimation`方法](/docs/docs/scripts/sapi/server/entity_and_player/camera#playanimation-方法)与[`Camera.attachToEntity`方法](/docs/docs/scripts/sapi/server/entity_and_player/camera#attachtoentity-方法)，以及`EntityAttachPoint`枚举、`CameraAttachOptions`接口与`AnimationOptions`接口。
- <Add/> 相机样条：开放了`CatmullRomSpline`、`LinearSpline`、`SplineAnimation`、`ProgressKeyFrame`与`RotationKeyFrame`，用于沿样条播放相机动画。
- <Add/> 瞄准辅助：开放了[`AimAssistRegistry`类](/docs/docs/scripts/sapi/server/entity_and_player/aim_assist#aimassistregistry-类)、[`AimAssistCategory`类](/docs/docs/scripts/sapi/server/entity_and_player/aim_assist#aimassistcategory-类)、[`AimAssistPreset`类](/docs/docs/scripts/sapi/server/entity_and_player/aim_assist#aimassistpreset-类)、[`PlayerAimAssist`类](/docs/docs/scripts/sapi/server/entity_and_player/aim_assist#playeraimassist-类)与[`AimAssistTargetMode`枚举](/docs/docs/scripts/sapi/server/entity_and_player/aim_assist#aimassisttargetmode-枚举)。

### 修复

- 修复了`isValid`在模拟玩家生成后返回`false`的问题。

## 专用服务器

- <Add/> `@minecraft/server-net`新增了四个 HTTP 请求错误类型：`HttpRequestBodyTooLargeError`、`HttpRequestLimitExceededError`、`HttpRequestNotAllowedError`与`HttpsOnlyError`。
- <Add/> 服务器运营者现在可以在`permissions.json`的`module_permissions`中为`@minecraft/server-net`配置允许的 URI、是否强制 HTTPS、请求体大小上限、并发请求数上限与会话头。

    ```json showLineNumbers title="config/default/permissions.json"
    {
        "allowed_modules": ["@minecraft/server-net"],
        "module_permissions": {
            "@minecraft/server-net": {
                "allowed_uris": ["https://example.com/"],
                "force_https": true,
                "max_body_bytes": 1048576,
                "max_concurrent_requests": 1,
                "session_headers": {
                    "session-data": "abc123"
                }
            }
        }
    }
    ```
