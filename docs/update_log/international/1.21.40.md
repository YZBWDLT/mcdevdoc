# 1.21.40

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

有关于 1.21.40 的完整更新日志，可见下方的中文 Minecraft Wiki。按照惯例，本文只介绍 1.21.40 的关键更改。

<WikiButton item="基岩版1.21.40"/>

## 命令

- <Add/> [`/effect`](/docs/docs/commands/all_commands#effect)命令新增无限时长重载与移除特定状态效果的重载。
- <Add/> [`/schedule`](/docs/docs/commands/all_commands#schedule)命令新增清除队列函数的重载，以及延迟执行函数与清除延迟执行函数的重载。

## 物品

### 数据驱动物品组件

- <Add/> [`minecraft:bundle_interaction`](/docs/docs/items/components#minecraftbundle_interaction)组件，为物品启用收纳袋的交互模式与物品提示。
- <Add/> [`minecraft:storage_item`](/docs/docs/items/components#minecraftstorage_item)组件，用于定义该物品为可存储物品，可以存储其他物品。

## 方块

### 数据驱动方块组件

- <Add/> [`minecraft:redstone_conductivity`](/docs/docs/blocks/components#minecraftredstone_conductivity)组件，用于定义方块的红石导体属性。
- <Add/> [`minecraft:destructible_by_mining`](/docs/docs/blocks/components#minecraftdestructible_by_mining)组件的`item_specific_speeds`参数，用于为不同物品设置不同的挖掘速度。

## 实体

### 数据驱动实体组件

- <Add/> [`minecraft:home`](/docs/docs/entities/components/functional#minecrafthome)组件的`restriction_type`参数，用于定义如何将实体限制在其原点位置。
- <Add/> [`minecraft:dimension_bound`](/docs/docs/entities/components/functional#minecraftdimension_bound)组件，用于阻止生物通过传送门切换维度。
- <Add/> [`minecraft:transient`](/docs/docs/entities/components/functional#minecrafttransient)组件，使带有该组件的实体永远不会被世界保存。
- <Change/> `minecraft:lookat`组件更名为[`minecraft:looked_at`](/docs/docs/entities/components/functional#minecraftlooked_at)组件，并大幅扩展了该组件的功能。
- <Change/> [`minecraft:damage_sensor`](/docs/docs/entities/components/sensors#minecraftdamage_sensor)组件的`deals_damage`参数不再支持布尔值，改为支持`yes`、`no`与`no_but_side_effects_apply`三个值。
- <Add/> [`minecraft:explode`](/docs/docs/entities/components/functional#minecraftexplode)组件新增`damage_scaling`、`toggles_blocks`、`knockback_scaling`、`particle_effect`、`sound_effect`、`negates_fall_damage`与`allow_underwater`参数。

## 世界生成

- <Add/> `minecraft:single_block_feature`地物，可以在世界生成时随机放置方块，并为每种朝向与参数生成放置配置。

## ScriptAPI

该版本开放了`@minecraft/server`的`1.15.0`版本。

### 世界

- <Add/> 开放了[`World.isHardcore`属性](/docs/docs/scripts/sapi/server/world/main#world-类)，用于判断这个世界是否为极限模式。
- <Add/> 世界前事件：开放了[`WorldBeforeEvents.playerInteractWithBlock`属性](/docs/docs/scripts/sapi/server/world/before_events)，玩家与方块交互前触发事件。
- <Add/> 世界前事件：开放了[`WorldBeforeEvents.playerInteractWithEntity`属性](/docs/docs/scripts/sapi/server/world/before_events)，玩家与实体交互前触发事件。
- <Add/> 世界后事件：开放了[`WorldAfterEvents.playerInteractWithBlock`属性](/docs/docs/scripts/sapi/server/world/after_events)，玩家与方块交互后触发事件。
- <Add/> 世界前事件：开放了[`PlayerInteractWithBlockBeforeEvent.isFirstEvent`属性](/docs/docs/scripts/sapi/server/world/before_events#playerinteractwithblockbeforeevent-类)，用于判断这次交互是不是自玩家开始交互以来的第一次交互。
- <Add/> 世界后事件：开放了[`PlayerInteractWithBlockAfterEvent.isFirstEvent`属性](/docs/docs/scripts/sapi/server/world/after_events#playerinteractwithblockafterevent-类)，用于判断这次交互是不是自玩家开始交互以来的第一次交互。
- <Add/> 世界后事件：开放了[`PlayerInteractWithBlockAfterEvent.beforeItemStack`属性](/docs/docs/scripts/sapi/server/world/after_events#playerinteractwithblockafterevent-类)，返回在交互前所使用的物品信息。
- <Add/> 世界后事件：开放了[`WorldAfterEvents.playerInteractWithEntity`属性](/docs/docs/scripts/sapi/server/world/after_events)，玩家与实体交互后触发事件。

### 方块

- <Add/> 开放了[`Block.getRedstonePower`方法](/docs/docs/scripts/sapi/server/block/main#getredstonepower-方法)，用于获取方块的充能能量。
- <Add/> 开放了[`BlockVolume`类](/docs/docs/scripts/sapi/server/dimension/volume#blockvolume-类)、[`BlockLocationIterator`类](/docs/docs/scripts/sapi/server/dimension/volume#blocklocationiterator-类)与[`BlockVolumeIntersection`枚举](/docs/docs/scripts/sapi/server/dimension/volume#blockvolumeintersection-枚举)，用于定义方块域并迭代其中的位置。

### 实体

- <Add/> 开放了[`EntityBreathableComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entitybreathablecomponent-类)，用于获取实体的呼吸相关参数。
