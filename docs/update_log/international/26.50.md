# 26.50

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

26.50 更新了 ~_荒野更新第 2 部分_~ 奔赴荒野（Wilderness Bound），更新了羊毛楼梯、混凝土楼梯和坐垫等。开发性功能上，方块的实验性功能也集中转正：水平多方块、`minecraft:sound`组件与自定义维度 JSON 都不再需要实验性玩法。实体侧新增了粉末雪与传送相关的组件，格式版本`1.26.50`起还有一批组件改用了更严格的 schema。脚本侧开放`2.10.0`版本。

有关于 26.50 的完整更新日志，可见下方的中文 Minecraft Wiki。本文只介绍 26.50 的关键技术性更改。

<WikiButton item="基岩版26.50"/>

## 命令

- <Add/> [`/serveridentity`](/docs/docs/commands/all_commands#serveridentity)命令，用于保存、删除与查询专用服务器的标识密钥。
- <Change/> 移除了非操作员玩家使用命令时的自选扩展。

## 物品

### 战利品表

- <Add/> 所有战利品表条件新增可选的`operator`参数。
    - 取`==`或`equals`时条件成立则生效，取`!=`或`not`时条件不成立才生效。省略时等同于`==`。

## 方块

### 数据驱动方块组件

- <Add/> [`minecraft:block_entity`](/docs/docs/blocks/components#minecraftblock_entity)组件不再需要实验性玩法。格式版本`1.26.20`及以上的方块可以直接使用。
- <Change/> 把带有该组件的自定义方块替换为另一个方块定义时，现在会创建新的方块实体，原方块的动态属性不再被继承。只改变方块状态时，方块实体与其动态属性会保留。
- <Add/> [`minecraft:sound`](/docs/docs/blocks/components#minecraftsound)组件，由实验性玩法开放，用于为方块及其置换分配音效。需要格式版本不低于`1.26.20`。
    - `blocks.json`中的值会覆盖组件提供的值，置换中的值也一样。

### 方块特征

- <Change/> [`minecraft:multi_block`](/docs/docs/blocks/traits#minecraftmulti_block)方块特征的水平方向不再需要实验性玩法。
- <Change/> 多方块上的方块实体限制已移除，每个部件都可以有自己的方块实体。
- <Change/> `/fill`命令的多方块行为已扩展到脚本的填充接口，例如[`Dimension.fillBlocks`方法](/docs/docs/scripts/sapi/server/dimension/main#fillblocks-方法)。
- <Add/> 原版栅栏、玻璃板、铁栏杆、铜栏杆与绊线现在暴露`minecraft:connection_north`、`minecraft:connection_east`、`minecraft:connection_south`与`minecraft:connection_west`四个状态。
- <Add/> 紫颂植株与火现在暴露`minecraft:connection_north`、`minecraft:connection_east`、`minecraft:connection_south`、`minecraft:connection_west`、`minecraft:connection_up`与`minecraft:connection_down`六个状态。
- <Change/> 基础游戏版本为`1.26.50`或更高的新世界中，薄栅栏与绊线的连接状态变化会触发相邻方块更新，既有世界保留仅客户端更新。

### 方块标签

- <Add/> 所有原版树叶方块现在带有`minecraft:leaves`标签。原版树木地物改为用`"tags": "query.any_tag('minecraft:leaves')"`匹配树叶，新增的树叶方块不必再逐个加入每个地物。
- <Change/> `minecraft:is_shears_item_destructible`标签现在也会赋予剪刀的破坏速度加成。

## 实体

### 数据驱动实体组件

- <Change/> 格式版本为`1.26.50`或更高的实体定义，在下列组件中使用了无效数据时会加载失败：
  [`minecraft:anger_level`](/docs/docs/entities/components/functional#minecraftanger_level)、[`minecraft:barter`](/docs/docs/entities/components/functional#minecraftbarter)、[`minecraft:boss`](/docs/docs/entities/components/functional#minecraftboss)、[`minecraft:collision_box`](/docs/docs/entities/components/attributes#minecraftcollision_box)、[`minecraft:damage_over_time`](/docs/docs/entities/components/functional#minecraftdamage_over_time)、[`minecraft:exhaustion_values`](/docs/docs/entities/components/functional#minecraftexhaustion_values)、[`minecraft:flocking`](/docs/docs/entities/components/functional#minecraftflocking)、[`minecraft:game_event_movement_tracking`](/docs/docs/entities/components/functional#minecraftgame_event_movement_tracking)、[`minecraft:grows_crop`](/docs/docs/entities/components/functional#minecraftgrows_crop)、[`minecraft:home`](/docs/docs/entities/components/functional#minecrafthome)、[`minecraft:trade_table`](/docs/docs/entities/components/functional#minecrafttrade_table)、[`minecraft:physics`](/docs/docs/entities/components/attributes#minecraftphysics)、[`minecraft:tamemount`](/docs/docs/entities/components/functional#minecrafttamemount)、[`minecraft:preferred_path`](/docs/docs/entities/components/functional#minecraftpreferred_path)、[`minecraft:instant_despawn`](/docs/docs/entities/components/functional#minecraftinstant_despawn)、[`minecraft:insomnia`](/docs/docs/entities/components/functional#minecraftinsomnia)。
- <Change/> 下列参数需要改写：
    - [`minecraft:interact`](/docs/docs/entities/components/functional#minecraftinteract)的`interactions`、`spawn_entities`与`play_sounds`只接受数组。
    - [`minecraft:projectile`](/docs/docs/entities/components/functional#minecraftprojectile)不再接受别名参数。`spawn_chance`中的`first_spawn_chance`与`second_spawn_chance`改为接受`0.0`\~`1.0`的数值，`anchor`改为接受`origin`、`eye_height`与`middle`三个字符串取值，`impact_damage`的`damage`改为接受带`min`与`max`的对象，`mob_effects`的`effects`改为接受实体效果实例的数组。
- <Add/> [`minecraft:behavior.ranged_attack`](/docs/docs/entities/components/ai#minecraftbehaviorranged_attack)组件的`in_range_movement_mode`参数，可选`hold_position`（在射程内保持位置）与`follow_target`（在射程内继续靠近）。
    - 该组件的`attack_range`参数改为接受区间，取代原来的`attack_radius_min`与`attack_radius`。
- <Change/> [`minecraft:behavior.follow_mob`](/docs/docs/entities/components/ai#minecraftbehaviorfollow_mob)的 schema 更严格，目标因组件组变更而停止或移除时会打断实体的寻路。
- <Add/> [`minecraft:freezing_immune`](/docs/docs/entities/components/functional#minecraftfreezing_immune)组件，用于声明实体免疫粉末雪的冻结。非生物实体默认免疫。
- <Add/> [`minecraft:freezing_vulnerable`](/docs/docs/entities/components/functional#minecraftfreezing_vulnerable)组件，用于声明实体可以被粉末雪冻伤。
- <Add/> [`minecraft:can_stand_on_powder_snow`](/docs/docs/entities/components/functional#minecraftcan_stand_on_powder_snow)组件，用于声明实体可以站在粉末雪顶部。
    - `lightweight`类型族不再赋予该能力。
- <Add/> [`minecraft:teleport`](/docs/docs/entities/components/functional#minecraftteleport)的两个参数：
    - `teleports_on_projectile_hit`参数，用于定义实体是否躲开飞来的弹射物。默认值为`false`。
    - `projectile_filter`参数，用于定义弹射物需要满足的条件。
- <Add/> [`minecraft:block_movement_slowdown_immunity`](/docs/docs/entities/components/functional#minecraftblock_movement_slowdown_immunity)组件，存在时实体不受蜘蛛网等方块的移动减速影响。
- <Change/> [`minecraft:projectile`](/docs/docs/entities/components/functional#minecraftprojectile)组件的`isolated_physics`参数对使用原版弹射物`runtime_identifier`的实体开启时会产生内容错误。
- <Change/> [`minecraft:ambient_sound_interval`](/docs/docs/entities/components/functional#minecraftambient_sound_interval)组件的环境音效不再被运行时覆盖。
    - 此前实体的头部在水中、离地或处于幼体状态时，`event_names`会被覆盖成`ambient.in.water`、`ambient.in.air`与`ambient.baby`。现在改为在`event_names`中用条件条目自行声明。
    - 旧版定义的实体会自动获得`minecraft:uses_legacy_ambient_sounds`组件以保留原行为，该组件本身已弃用。

## 世界生成

### 地物

- <Add/> 新的地物`minecraft:conditional_list`，按条件列表依次求值并放置地物。
    - `conditional_features`是条件与地物的对应列表，每一项包含`places_feature`与可选的 Molang 条件。
    - `early_out_scheme`控制何时停止求值，可选`condition_success`、`placement_success`与`none`（默认值）。
- <Add/> 新的地物`minecraft:multipart_block_column_feature`，用于放置由一至四种方块组成的柱状结构。
    - 四个部分分别是`tip_block`、`frustum_block`、`middle_block`与`base_block`，默认生长方向为`UP`。
    - `height_range`参数定义柱状结构的高度区间，`may_place_on`与`may_replace`分别限制可放置的表面与可替换的方块。
- `snap_to_surface_feature`的 3 个参数：
    - <Change/> `surface`参数新增`wall`取值，允许地物吸附到墙面。
    - <Add/> `allow_non_air_placement`参数，用于控制吸附起点位于非空气、非液体方块内部时能否穿过固体方块吸附。
    - <Change/> `vertical_search_range`参数更名为`search_range`。

### 自定义维度

- <Add/> **自定义维度现在可以用 JSON 定义，并能配置维度高度。**
- <Add/> 自定义维度 JSON 的`minecraft:default_biome`组件，用于配置该维度生成的生物群系。
    - 该组件现在可选，且只对自定义维度有效。写在原版维度上会产生内容错误。

## Molang

- <Add/> `query.has_all_biome_tags`与`query.has_any_biome_tags`查询，用于判断当前放置位置的生物群系是否拥有全部或部分给定标签。
- <Add/> `query.head_is_in_water`查询，用于判断实体的头部是否在水中。
- <Add/> `query.is_pack_setting_selected`查询，用于读取包设置中激活的选项。

## ScriptAPI

该版本开放了`@minecraft/server`的`2.10.0`版本与`@minecraft/server-ui`的`2.2.0`版本，`@minecraft/server-graphics`也升为`1.0.0`。

### 世界

- <Add/> 声音定义注册表：开放了[`World.soundDefinitionRegistry`属性](/docs/docs/scripts/sapi/server/world/main)与[`SoundDefinitionRegistry`类](/docs/docs/scripts/sapi/server/world/main#sounddefinitionregistry-类)，用于查询已注册的声音定义。
- <Add/> [`PrimitiveShapesManager.getShapes`方法](/docs/docs/scripts/sapi/server/world/primitive_shapes#getshapes-方法)，用于查询管理器中保存的全部图元形状；可配合[`PrimitiveShapeQueryOptions`接口](/docs/docs/scripts/sapi/server/world/primitive_shapes#primitiveshapequeryoptions-接口)收窄结果。
- **世界前事件**
    - <Add/> 实体驯服前事件：开放了[`EntityTamedBeforeEvent`类](/docs/docs/scripts/sapi/server/world/before_events#entitytamedbeforeevent-类)。
- **世界后事件**
    - <Add/> 实体驯服后事件：开放了[`EntityTamedAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#entitytamedafterevent-类)与[`EntityTamedEventOptions`接口](/docs/docs/scripts/sapi/server/world/event_types#entitytamedeventoptions-接口)。
    - <Add/> 实体潜行事件：开放了[`EntityStartSneakingAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#entitystartsneakingafterevent-类)与[`EntityStopSneakingAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#entitystopsneakingafterevent-类)。
    - <Add/> 音效播放完成事件：开放了[`SoundCompletedAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#soundcompletedafterevent-类)，在受跟踪的音效播放完毕时触发，可通过`soundInstanceId`属性取得对应的声音实例。

### 维度

- <Add/> [`Dimension.cloneBlocks`方法](/docs/docs/scripts/sapi/server/dimension/main#cloneblocks-方法)，用于复制或移动方块区域；配套的[`CloneMode`枚举](/docs/docs/scripts/sapi/server/dimension/volume#clonemode-枚举)定义操作方式。
- <Add/> [`BlockQueryOptions`接口](/docs/docs/scripts/sapi/server/dimension/volume#blockqueryoptions-接口)，供[`Dimension.getBlocks`方法](/docs/docs/scripts/sapi/server/dimension/main#getblocks-方法)使用。
- <Add/> [`BlockVolumeBase.getClosest`方法](/docs/docs/scripts/sapi/server/dimension/volume#getclosest-方法)与[`BlockVolumeBase.getFarthest`方法](/docs/docs/scripts/sapi/server/dimension/volume#getfarthest-方法)，分别按由近到远、由远到近的顺序返回体积内的若干个方块坐标。
- <Change/> [`DimensionTypes`类](/docs/docs/scripts/sapi/server/system/custom_dimension#dimensiontypes-类)的`get`与`getAll`方法现在除原版维度类型外也会返回自定义维度类型。

### 方块

- <Add/> [`BlockDynamicPropertiesComponent`类](/docs/docs/scripts/sapi/server/block/component#blockdynamicpropertiescomponent-类)，用于让方块存储动态属性；[`BlockInstrumentComponent`类](/docs/docs/scripts/sapi/server/block/component#blockinstrumentcomponent-类)，表示方块可分配给其上下的乐器。

### 实体

- <Change/> [`Entity.teleport`方法](/docs/docs/scripts/sapi/server/entity_and_player/entity#teleport-方法)在实体带有乘客且目标维度与当前维度不同时会抛出错误，需要先让乘客下车。
- <Change/> [`EffectTypes`](/docs/docs/scripts/sapi/server/entity_and_player/effect#effecttypes-类)的`get`与`getAll`方法现在可以在前事件中调用。

### 物品

- <Add/> [`ItemBlockDynamicPropertiesComponent`类](/docs/docs/scripts/sapi/server/item/component#itemblockdynamicpropertiescomponent-类)，用于让物品形态的方块存储动态属性。

### 声音

- <Add/> [`SoundInstance`类](/docs/docs/scripts/sapi/server/general#soundinstance-类)新增`id`、`soundEventId`、`recipient`与`durationInfo`属性，用于标识该声音实例、读取其声音事件与播放对象，以及查询时长信息。
- <Add/> [`SoundDurationInfo`类](/docs/docs/scripts/sapi/server/general#sounddurationinfo-类)，用于查询音效的时长与播放进度。
- <Add/> [`SoundDefinition`类](/docs/docs/scripts/sapi/server/general#sounddefinition-类)，表示`sound_definitions.json`中一条声音的静态元数据；[`SoundDefinitionDurationInfo`接口](/docs/docs/scripts/sapi/server/general#sounddefinitiondurationinfo-接口)与[`SoundDefinitionMusicInfo`接口](/docs/docs/scripts/sapi/server/general#sounddefinitionmusicinfo-接口)，分别描述其中声明的时长与音乐信息；[`SoundDefinitionFilter`接口](/docs/docs/scripts/sapi/server/world/main#sounddefinitionfilter-接口)，用于收窄声音定义的查询范围。
- <Change/> [`Player.playSound`方法](/docs/docs/scripts/sapi/server/entity_and_player/player#playsound-方法)除音效 ID 外也接受[`SoundDefinition`类](/docs/docs/scripts/sapi/server/general#sounddefinition-类)。

### 相机

- <Add/> [`Camera.addShake`方法](/docs/docs/scripts/sapi/server/entity_and_player/camera#addshake-方法)与[`Camera.stopShaking`方法](/docs/docs/scripts/sapi/server/entity_and_player/camera#stopshaking-方法)，用于为相机添加或停止晃动；[`CameraShakeOptions`接口](/docs/docs/scripts/sapi/server/entity_and_player/camera#camerashakeoptions-接口)与[`CameraShakeType`枚举](/docs/docs/scripts/sapi/server/entity_and_player/camera#camerashaketype-枚举)分别定义晃动的参数与类型。
- <Add/> [`Player.fogSettings`属性](/docs/docs/scripts/sapi/server/entity_and_player/player)、[`FogSettings`类](/docs/docs/scripts/sapi/server/entity_and_player/player#fogsettings-类)与[`FogSettingsError`类](/docs/docs/scripts/sapi/server/entity_and_player/player#fogsettingserror-类)，用于自定义玩家的雾效。

### 界面

- <Add/> `@minecraft/server-ui`的[`CustomForm.image`方法](/docs/docs/scripts/sapi/server-ui/data_driven)，用于在自定义表单中显示图片；[`ImageOptions`接口](/docs/docs/scripts/sapi/server-ui/data_driven#imageoptions-接口)定义图片的点击回调与提示等选项。

### 其他模块

- <Add/> [`@minecraft/server-graphics`](/docs/docs/scripts/sapi/server-graphics/main)升为`1.0.0`，模块内的接口全部转正。该模块要求`@minecraft/server`的`2.3.0`或更高版本。

## 其他

- <Change/> `.mcstructure`结构文件升级到第二版。`block_indices`改用 NBT 的`IntArrayTag`存储，第二层方块数组在没有内容时会被省略，文件体积约缩小一半。旧版结构仍可加载，并在下次保存时升级。
- <Add/> 包设置新增多选类型，可用`query.is_pack_setting_selected`查询激活的选项。
- <Add/> `sound_definitions.json`的声音定义新增`allow_concurrent_streaming`，格式版本`1.26.50`起默认值为`true`。
- <Change/> 相机预设`minecraft:follow_orbit`在格式版本`1.26.50`起首次应用时不再重置玩家视角。
- <Change/> 格式化代码`§9`、`§h`、`§i`、`§j`、`§m`、`§n`、`§p`、`§q`、`§s`、`§t`、`§u`与`§v`的颜色值有调整，自定义文本颜色需要重新对照。
