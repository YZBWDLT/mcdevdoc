# 26.40

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

:::warning[注意]

本文仍在编辑，仅供参考。

:::

26.40 让`minecraft:multi_block`方块特征与`minecraft:instrument_sound`方块组件走出了实验性，实体侧则放开了击退规则组件，并调整了弹射物的伤害与反弹写法。脚本侧开放`2.9.0`版本。

有关于 26.40 的完整更新日志，可见下方的中文 Minecraft Wiki。本文只介绍 26.40 的关键技术性更改。

<WikiButton item="基岩版26.40"/>

## 命令

- <Change/> [`/clone`](/docs/docs/commands/all_commands#clone)不再克隆不完整的床，床的两个部分都必须落在克隆体积内。
- <Change/> [`/fill`](/docs/docs/commands/all_commands#fill)现在支持放置使用`minecraft:multi_block`的方块。

## 物品

- <Change/> 格式版本为`1.26.30`或更高的物品定义，必须在`minecraft:item.components`中至少包含一个条目。`components`为空时会注册失败并产生内容错误，不再回退到旧版物品解析。
- <Change/> 修复了自定义物品定义覆盖原版定义时的若干问题。旧格式版本的自定义定义现在能覆盖格式版本`1.16`或更高的原版物品，使用扁平化标识符的定义也能覆盖旧标识符的原版定义。
- <Change/> [`minecraft:shooter`](/docs/docs/items/components#minecraftshooter)组件现在可以在未定义弹药的情况下射击。
- <Add/> 配方`minecraft:recipe_smithing_transform`的`addition`参数现在接受带有`minecraft:transform_materials`标签的物品。
- <Add/> `item_display_transforms`新增`shelf`偏移，用于控制物品在书架方块中的定位。
    - 格式版本低于`1.26.40`的内容会把`fixed`变换复制给`shelf`，从`1.26.40`起可以分别定义两者的变换。

## 方块

### 多方块

- <Add/> [`minecraft:multi_block`](/docs/docs/blocks/traits#minecraftmulti_block)方块特征，由实验性玩法开放。该特征让单个方块占据多个方块位置，各部件视为一个整体。
    - 其`direction`参数取垂直方向时无需实验性玩法，取水平方向（`north`、`south`、`east`、`west`）仍需开启实验性玩法。
- <Add/> `minecraft:multi_block_feature`生物群系装饰特征，用于放置由`minecraft:multi_block`定义的方块。
- <Change/> 十六向放置旋转现在与既有的`cardinal_direction`、`facing_direction`方向一致。

### 数据驱动方块组件

- <Add/> [`minecraft:instrument_sound`](/docs/docs/blocks/components#minecraftinstrument_sound)组件，由实验性玩法开放。
- <Change/> [`minecraft:geometry`](/docs/docs/blocks/components#minecraftgeometry)组件的`n_way_visual_rotation`参数不再需要实验性玩法。
- <Change/> `shapes`文件夹中定义了体素形状的原版方块，现在无需实验性玩法即可参与体素形状剔除。

### 方块状态

- <Add/> 原版栅栏现在暴露`minecraft:connection_north`、`minecraft:connection_east`、`minecraft:connection_south`与`minecraft:connection_west`四个状态。
- <Add/> 原版台阶现在暴露`minecraft:corner`状态，可选`none`、`inner_left`、`inner_right`、`outer_left`与`outer_right`。
- <Change/> 基础游戏版本为`1.26.40`或更高的世界中，栅栏连接变化与台阶转角变化会向相邻方块发送服务端方块更新，既有世界保留旧行为。

### 修复

- <Change/> 修复了使用[`minecraft:tick`](/docs/docs/blocks/components#minecrafttick)组件的自定义方块，从带有刻数据的结构放置时刻频率高于预期的问题。

## 实体

    - 行为组件：[`minecraft:cannot_be_attacked`](/docs/docs/entities/components#minecraftcannot_be_attacked)、[`minecraft:floats_in_liquid`](/docs/docs/entities/components#minecraftfloats_in_liquid)、[`minecraft:ignore_cannot_be_attacked`](/docs/docs/entities/components#minecraftignore_cannot_be_attacked)、[`minecraft:wants_jockey`](/docs/docs/entities/components#minecraftwants_jockey)、[`minecraft:annotation.open_door`](/docs/docs/entities/components#minecraftannotationopen_door)、`minecraft:bucketable`、[`minecraft:hide`](/docs/docs/entities/components#minecrafthide)、[`minecraft:jump.dynamic`](/docs/docs/entities/components#minecraftjumpdynamic)、[`minecraft:jump.static`](/docs/docs/entities/components#minecraftjumpstatic)、[`minecraft:managed_wandering_trader`](/docs/docs/entities/components#minecraftmanaged_wandering_trader)、[`minecraft:persistent`](/docs/docs/entities/components#minecraftpersistent)、[`minecraft:trade_resupply`](/docs/docs/entities/components#minecrafttrade_resupply)、[`minecraft:trust`](/docs/docs/entities/components#minecrafttrust)。

    - AI 意向：[`minecraft:behavior.charge_held_item`](/docs/docs/entities/components#minecraftbehaviorcharge_held_item)、[`minecraft:behavior.drink_potion`](/docs/docs/entities/components#minecraftbehaviordrink_potion)、[`minecraft:behavior.eat_block`](/docs/docs/entities/components#minecraftbehavioreat_block)、[`minecraft:behavior.knockback_roar`](/docs/docs/entities/components#minecraftbehaviorknockback_roar)、[`minecraft:behavior.leap_at_target`](/docs/docs/entities/components#minecraftbehaviorleap_at_target)、[`minecraft:behavior.move_to_block`](/docs/docs/entities/components#minecraftbehaviormove_to_block)、[`minecraft:behavior.nap`](/docs/docs/entities/components#minecraftbehaviornap)、[`minecraft:behavior.ranged_attack`](/docs/docs/entities/components#minecraftbehaviorranged_attack)、[`minecraft:behavior.silverfish_merge_with_stone`](/docs/docs/entities/components#minecraftbehaviorsilverfish_merge_with_stone)、[`minecraft:behavior.silverfish_wake_up_friends`](/docs/docs/entities/components#minecraftbehaviorsilverfish_wake_up_friends)、[`minecraft:behavior.snacking`](/docs/docs/entities/components#minecraftbehaviorsnacking)、[`minecraft:behavior.squid_dive`](/docs/docs/entities/components#minecraftbehaviorsquid_dive)、[`minecraft:behavior.squid_flee`](/docs/docs/entities/components#minecraftbehaviorsquid_flee)、[`minecraft:behavior.squid_idle`](/docs/docs/entities/components#minecraftbehaviorsquid_idle)、[`minecraft:behavior.squid_move_away_from_ground`](/docs/docs/entities/components#minecraftbehaviorsquid_move_away_from_ground)、[`minecraft:behavior.squid_out_of_water`](/docs/docs/entities/components#minecraftbehaviorsquid_out_of_water)、[`minecraft:behavior.stalk_and_pounce_on_target`](/docs/docs/entities/components#minecraftbehaviorstalk_and_pounce_on_target)、[`minecraft:behavior.summon_entity`](/docs/docs/entities/components#minecraftbehaviorsummon_entity)。
- <Change/> 其中的部分参数也需要改写法：
    - [`minecraft:behavior.beg`](/docs/docs/entities/components#minecraftbehaviorbeg)的`look_time`参数与[`minecraft:behavior.float_wander`](/docs/docs/entities/components#minecraftbehaviorfloat_wander)的`float_duration`参数现在必须是带`min`与`max`值的对象。
    - [`minecraft:behavior.ranged_attack`](/docs/docs/entities/components#minecraftbehaviorranged_attack)的`attack_interval`参数改为接受区间，取代原来的`attack_interval_min`与`attack_interval_max`。
- <Change/> 修复了格式版本`1.26.40`起的下列意向中`on_kill`被错误映射到`on_attack`、导致击杀目标时不触发的问题：
    - [`minecraft:behavior.delayed_attack`](/docs/docs/entities/components#minecraftbehaviordelayed_attack)、[`minecraft:behavior.melee_attack`](/docs/docs/entities/components#minecraftbehaviormelee_attack)、[`minecraft:behavior.melee_box_attack`](/docs/docs/entities/components#minecraftbehaviormelee_box_attack)、[`minecraft:behavior.stomp_attack`](/docs/docs/entities/components#minecraftbehaviorstomp_attack)、[`minecraft:behavior.use_kinetic_weapon`](/docs/docs/entities/components#minecraftbehavioruse_kinetic_weapon)。

### 数据驱动实体组件

- <Add/> [`minecraft:pushable_by_entity`](/docs/docs/entities/components#minecraftpushable_by_entity)组件的`require_collision_overlap`参数，用于定义两个实体是否必须碰撞箱重叠才能推动。
    - 格式版本`1.26.40`起默认值为`true`，更早的版本默认为`false`。
- <Change/> [`minecraft:apply_knockback_rules`](/docs/docs/entities/components#minecraftapply_knockback_rules)组件不再需要实验性玩法，并有以下改动：
    - `scale_previous_velocity`更名为`slowdown_scale`。
    - `horizontal_power`不再在内部乘以`0.4`。水平与垂直方向取相近的值时，击退效果现在也相近。
    - 弃用`horizontal_hit_angle_scale`、`vertical_hit_angle_scale`与`vertical_position_angle_scale`。
    - 新增`knockback_mode`参数，可选`relative_horizontal`（默认值，从攻击者指向目标施加水平击退）与`hit_direction`（按命中方向与命中点施加击退）。
- <Add/> [`minecraft:projectile`](/docs/docs/entities/components#minecraftprojectile)组件`impact_damage`中的`ceil_pre_critical_damage`参数，为`true`时在应用暴击倍率前先向上取整伤害。
- <Change/> [`minecraft:projectile`](/docs/docs/entities/components#minecraftprojectile)组件`impact_damage`中的`power_multiplier`现在独立于难度随机化生效，默认值从`2`改为`0`。
- <Change/> [`minecraft:projectile`](/docs/docs/entities/components#minecraftprojectile)组件的`semi_random_diff_damage`参数由`difficulty_randomization`取代，后者可选`none`（默认值）、`additive`与`multiplicative`。
    - 早于`1.26.40`的内容加载时会自动升级，以保留原行为。
- <Change/> [`minecraft:projectile`](/docs/docs/entities/components#minecraftprojectile)组件的`should_bounce`参数由布尔值改为枚举，可选`no`（默认值）、`if_invulnerable`与`if_no_damage_dealt`。旧的`true`会自动升级为`if_invulnerable`，`false`升级为`no`。

## 世界生成

- <Change/> 同一行为包中有多个地物使用相同`identifier`时，内容日志现在会报错。
- <Change/> 生成的 JSON Schema 改为更细粒度的布局，不再为每个注册类型生成独立的自包含 schema。

## Vibrant Visuals

- <Change/> 修复了组件渲染的自定义方块在开启 Vibrant Visuals 时，被手持、掉落或展示在物品展示框、书架中不显示自发光与 MER 效果的问题。
- <Change/> 修复了自定义维度的雾色与昼夜亮度不匹配的问题。
- <Change/> 修复了使用自动方块面 UV 分配且纹理尺寸偏小的自定义方块出现纹理渗色的问题。

## ScriptAPI

该版本开放了`@minecraft/server`的`2.9.0`版本。

### 世界

- **世界后事件**
    - <Add/> 玩家破坏方块事件：开放了[`PlayerStartBreakingBlockAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#playerstartbreakingblockafterevent-类)、[`PlayerCancelBreakingBlockAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#playercancelbreakingblockafterevent-类)与[`PlayerBreakingBlockEventOptions`接口](/docs/docs/scripts/sapi/server/world/event_types#playerbreakingblockeventoptions-接口)。

### 维度

- <Add/> [`Dimension.calculateClosestBiomeFromSeed`方法](/docs/docs/scripts/sapi/server/dimension/main#calculateclosestbiomefromseed-方法)，取代原来的`Dimension.findClosestBiome`。
- <Add/> [`BiomeSearchOptions`接口](/docs/docs/scripts/sapi/server/dimension/biome#biomesearchoptions-接口)。

### 方块

- <Add/> [`Block.getParts`方法](/docs/docs/scripts/sapi/server/block/main#getparts-方法)，用于获取多方块方块的各个部件。

### 实体

- <Add/> [`EffectTypes.getAll`方法](/docs/docs/scripts/sapi/server/entity_and_player/effect#getall-方法)，用于获取所有已注册的状态效果类型。

### 物品

- <Add/> [`LootItem.conditions`属性](/docs/docs/scripts/sapi/server/world/loot_table#lootitem-类)，用于读取战利品物品的条件。

### 声音

- <Add/> [`SoundInstance.stop`方法](/docs/docs/scripts/sapi/server/general#soundinstance-类)，用于停止正在播放的音效。

### 修复

- 修复了[`Dimension.fillBlocks`方法](/docs/docs/scripts/sapi/server/dimension/main#fillblocks-方法)在传入方块筛选条件时的问题，并提升了配合`BlockVolume`使用时的性能。
- 修复了`LootItem`对自定义物品与方块返回错误`Name`值的问题。
- 修复了漏斗矿车不会为上方的物品触发拾取事件的问题。
- 修复了受伤前事件把伤害降低到低于来源数值时绕过无敌计时器的问题。
