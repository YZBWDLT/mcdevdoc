# 1.21.100

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

有关于 1.21.100 的完整更新日志，可见下方的中文 Minecraft Wiki。按照惯例，本文只介绍 1.21.100 的关键更改。

<WikiButton item="基岩版1.21.100"/>

## 超平坦预设

- <Add/> 为超平坦预设新增了虚空预设，现在制作地图可以直接使用无限虚空了。

## 命令

- <Add/> 为命令添加了目标选择器`@n`，以选取距离执行位置最近的实体。
- <Change/> 现在[`/spawnpoint`](/docs/docs/commands/all_commands#spawnpoint)命令可以在末地设置重生点了。
- <Change/> 现在[`/locate`](/docs/docs/commands/all_commands#locate)命令的`biome`语法需要包含命名空间。

## 方块

### 数据驱动方块组件

- <Add/> [`minecraft:movable`](/docs/docs/blocks/components#minecraftmovable)，定义方块是否可被活塞推动，及其属性。
- <Add/> [`minecraft:random_offset`](/docs/docs/blocks/components#minecraftrandom_offset)，定义方块的碰撞箱、选择箱和模型如何随机产生偏移。类似于原版的草。
- <Add/> [`minecraft:destruction_particles`](/docs/docs/blocks/components#minecraftdestruction_particles)的`particle_count`参数，定义破坏方块释放的粒子数量。
- <Add/> [`minecraft:geometry`](/docs/docs/blocks/components#minecraftgeometry)的`uv_lock`参数，定义是否锁定 UV 面。若锁定 UV 面，则方块的 UV 不会随着`minecraft:transformation`组件的旋转而旋转。

## 实体

### 数据驱动实体组件

- <Add/> [`minecraft:behavior.enderman_take_block`](/docs/docs/entities/components#minecraftbehaviorenderman_take_block)升级为[`minecraft:behavior.take_block`](/docs/docs/entities/components#minecraftbehaviortake_block)，扩展到对所有实体支持。
- <Add/> [`minecraft:behavior.enderman_leave_block`](/docs/docs/entities/components#minecraftbehaviorenderman_leave_block)升级为[`minecraft:behavior.place_block`](/docs/docs/entities/components#minecraftbehaviorplace_block)，扩展到对所有实体支持。
- <Add/> [`minecraft:behavior.transport_items`](/docs/docs/entities/components#minecraftbehaviortransport_items)，定义实体会从容器中运输物品，或将物品运输到容器中。
- <Change/> [`minecraft:body_rotation_axis_aligned`](/docs/docs/entities/components#minecraftbody_rotation_axis_aligned)更名为[`minecraft:rotation_axis_aligned`](/docs/docs/entities/components#minecraftrotation_axis_aligned)。
- <Change/> [`minecraft:tick_world`](/docs/docs/entities/components#minecrafttick_world)的解析更加严格，现在拒绝超出范围值的`radius`和`​distance_to_players`。
- <Add/> [`minecraft:equip_item`](/docs/docs/entities/components#minecraftequip_item)的`can_wear_armor`参数，用于指定装备的物品是否应该添加到盔甲槽或手部槽位。

## 生物群系

- <Change/> 现在生物群系的 ID 需要由文件内的`description`参数显式指定，而不再能通过文件名暗指。并且，ID 必须带有命名空间。
- <Add/> `minecraft:grass_appearance`组件的`grass_is_shaded`参数，若为`true`则会为草方块添加着色效果，如同顶部有遮挡。
- <Add/> `minecraft:surface_builder`组件，这将`minecraft:surface_parameters`、`minecraft:​frozen_ocean_surface`、​`minecraft:mesa_surface`、`minecraft:​swamp_surface`、`minecraft:​capped_surface`和`minecraft:​the_end_surface`合并为一个组件。每个生物群系只能使用一种构建器类型。此组件可用于世界生成设置，例如地基材质和海底深度。
- <Add/> `minecraft:humidity`组件，含有参数`is_humid`，能够强制生物群系一直湿润或永不湿润。湿度会影响火在生物群系中的蔓延概率和蔓延速率。
- <Add/> `minecraft:partially_frozen`组件，此组件会影响封冻的生物群系，致使部分区域不会冻结。例如：零散的冰雪。

## ScriptAPI

该版本开放了`@minecraft/server`的`2.1.0`版本的脚本。

### 世界

- **世界后事件**
  - <Add/> 玩家主手物品切换事件：开放了[`PlayerHotbarSelectedSlotChangeAfterEvent`类](/docs/docs/scripts/sapi/docs/world/after_events#playerhotbarselectedslotchangeafterevent-类)、[`PlayerHotbarSelectedSlotChangeAfterEventSignal`类](/docs/docs/scripts/sapi/docs/world/after_events#playerhotbarselectedslotchangeaftereventsignal-类)和[`HotbarEventOptions`接口](/docs/docs/scripts/sapi/docs/world/after_events#hotbareventoptions-接口)。
  - <Add/> 玩家物品栏物品变更事件：开放了[`PlayerInventoryItemChangeAfterEvent`类](/docs/docs/scripts/sapi/docs/world/after_events#playerinventoryitemchangeafterevent-类)、[`PlayerInventoryItemChangeAfterEventSignal`类](/docs/docs/scripts/sapi/docs/world/after_events#playerinventoryitemchangeaftereventsignal-类)、[`InventoryItemEventOptions`接口](/docs/docs/scripts/sapi/docs/world/after_events#inventoryitemeventoptions-接口)和[`PlayerInventoryType`枚举](/docs/docs/scripts/sapi/docs/world/after_events#playerinventorytype-枚举)。

### 维度

- <Add/> 开放了[`Dimension.localizationKey`属性](/docs/docs/scripts/sapi/docs/dimension/main#dimension-类)。

### 方块

- <Add/> 开放了[`Block.localizationKey`属性](/docs/docs/scripts/sapi/docs/block/main#block-类)。
- **方块组件**
  - <Add/> [`BlockMovableComponent`类](/docs/docs/scripts/sapi/docs/block/component#blockmovablecomponent-类)，用于获取方块的可推动组件，同时开放了[`MovementType`枚举](/docs/docs/scripts/sapi/docs/block/component#movementtype-枚举)和[`StickyType`枚举](/docs/docs/scripts/sapi/docs/block/component#stickytype-枚举)

### 实体

- <Add/> 开放了[`Entity.localizationKey`属性](/docs/docs/scripts/sapi/docs/entity_and_player/entity#entity-类)。
- **实体组件**：
  - <Add/> [`​EntityExhaustionComponent`类](/docs/docs/scripts/sapi/docs/entity_and_player/component#entityexhaustioncomponent-类)，用于获取实体的疲劳度组件。
  - <Add/> [`EntityHungerComponent`类](/docs/docs/scripts/sapi/docs/entity_and_player/component#entityhungercomponent-类)，用于获取实体的饥饿值组件。
  - <Add/> [`​EntitySaturationComponent`类](/docs/docs/scripts/sapi/docs/entity_and_player/component#entitysaturationcomponent-类)，用于获取实体的饱和度组件。
  - <Add/> [`EntityEquippableComponent`类](/docs/docs/scripts/sapi/docs/entity_and_player/component#entityequippablecomponent-类)的`totalArmor`和`​totalToughness`属性，用于获取实体的盔甲值和盔甲韧性值。

### 物品

- <Add/> 开放了[`ItemStack.localizationKey`属性](/docs/docs/scripts/sapi/docs/item/main#itemstack-类)。
- **物品组件**：
  - <Add/> [`ItemDyeableComponent`类](/docs/docs/scripts/sapi/docs/item/component#itemdyeablecomponent-类)，用于获取物品的染色组件，更改物品颜色。
- **容器**
  - <Add/> 为[`Container`类](/docs/docs/scripts/sapi/docs/item/container#container-类)添加了`contains()`、`​firstEmptySlot()`、`​firstItem()`、`​find()`和`​findLast()`方法。

### 自定义命令

- <Add/> 正式开放自定义命令相关接口。见[脚本文档：自定义命令](/docs/docs/scripts/sapi/docs/custom_command)。
