# 1.21.30

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

有关于 1.21.30 的完整更新日志，可见下方的中文 Minecraft Wiki。按照惯例，本文只介绍 1.21.30 的关键更改。

<WikiButton item="基岩版1.21.30"/>

## 命令

- <Add/> [`/reload`](/docs/docs/commands/all_commands#reload)命令新增`reload_all`参数，指定后会退出地图再重进，以应用大部分的附加包更改。

## 物品

### 数据驱动物品组件

- <Add/> [`minecraft:dyeable`](/docs/docs/items/components#minecraftdyeable)组件，用于定义物品在炼药锅中可染色。
- <Add/> [`minecraft:rarity`](/docs/docs/items/components#minecraftrarity)组件，用于定义物品的稀有度。

### 战利品表

- <Add/> 战利品表新增`set_potion`物品功能，用于对箭或药水添加药效。

## 方块

### 数据驱动方块组件

- <Add/> [`minecraft:geometry`](/docs/docs/blocks/components#minecraftgeometry)组件的`item_display_transforms`参数，用于自定义方块在物品栏、手持与掉落等场景中的渲染表现。

## 实体

### 数据驱动实体组件

- <Change/> `minecraft:behavior.fire_at_target`、`minecraft:behavior.jump_around_target`与`minecraft:behavior.move_around_target`三个意向不再限制于原版内容。

## ScriptAPI

该版本开放了`@minecraft/server`的`1.14.0`版本与`@minecraft/server-ui`的`1.3.0`版本。

### 系统

- <Add/> 开放了[`UIManager`类](/docs/docs/scripts/sapi/server-ui/ui_manager#uimanager-类)，用于便捷关闭所有玩家的界面。

### 世界

- <Add/> 世界后事件：开放了[`PlayerEmoteAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#playeremoteafterevent-类)与[`WorldAfterEvents.playerEmote`属性](/docs/docs/scripts/sapi/server/world/after_events)，可监听玩家播放类似挥手动作的表情。

### 方块

- <Add/> 开放了[`BlockRecordPlayerComponent`类](/docs/docs/scripts/sapi/server/block/component#blockrecordplayercomponent-类)，用于获取方块的唱片机性质。

### 实体

- <Add/> 开放了[`EntityStrengthComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entitystrengthcomponent-类)，用于获取实体承载物品能力的参数。
- <Add/> 开放了[`EntityQueryPropertyOptions`接口](/docs/docs/scripts/sapi/server/entity_and_player/entity#entityquerypropertyoptions-接口)，用于按实体属性筛选查询目标。
- <Add/> 开放了[`PlayerCursorInventoryComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#playercursorinventorycomponent-类)，用于获取玩家鼠标光标选取的物品。在移动端不会起作用。
