# 1.21.90

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

有关于 1.21.90 的完整更新日志，可见下方的中文 Minecraft Wiki。按照惯例，本文只介绍 1.21.90 的关键更改。

<WikiButton item="基岩版1.21.90"/>

## 命令

- <Add/> 新增了`/controlscheme`命令，用于修改相机预设的控制方案，需要配合`/camera`命令使用。

## 物品

### 数据驱动物品组件

- <Change/> [`minecraft:custom_components`](/docs/docs/items/components#minecraftcustom_components)组件被弃用。自`1.21.90`格式版本开始，自定义物品组件采用 V2 版本，不再通过该组件声明，而是使用类似于其他原版组件的写法，并可在组件内部传入参数。
- <Add/> [`minecraft:storage_item`](/docs/docs/items/components#minecraftstorage_item)组件的两个参数被拆分为[`minecraft:storage_weight_limit`](/docs/docs/items/components#minecraftstorage_weight_limit)与[`minecraft:storage_weight_modifier`](/docs/docs/items/components#minecraftstorage_weight_modifier)两个新组件。
- <Add/> [`minecraft:compostable`](/docs/docs/items/components#minecraftcompostable)组件，用于定义物品可在堆肥桶中用于堆肥。
- <Add/> [`minecraft:block_placer`](/docs/docs/items/components#minecraftblock_placer)组件的`replace_block_placer`参数，用于确定是否将此物品与对应方块绑定，若绑定则方块被破坏后会掉落该物品。
- <Add/> [`minecraft:wearable`](/docs/docs/items/components#minecraftwearable)组件的`hides_player_location`参数，用于确定穿戴后是否在定位栏中隐藏玩家位置。

### 物品组

- <Add/> 现在正式支持自定义物品组。格式版本`1.21.60`或更高的物品在指定物品组时必须指定命名空间。

### 战利品表

- <Change/> 战利品表的`match_tool`条件可以使用物品标签筛选。

## 方块

### 数据驱动方块组件

- <Change/> [`minecraft:custom_components`](/docs/docs/blocks/components#minecraftcustom_components)组件被弃用。自`1.21.90`格式版本开始，自定义方块组件采用 V2 版本，不再通过该组件声明，而是使用类似于其他原版组件的写法，并可在组件内部传入参数。
- <Add/> [`minecraft:material_instances`](/docs/docs/blocks/components#minecraftmaterial_instances)组件新增`ambient_occlusion`、`isotropic`与`tint_method`参数。

### 方块面剔除

- <Add/> 面剔除规则得到扩展，支持树叶在树中配置邻接规则时的表现等情形。

## 实体

### 数据驱动实体组件

- <Add/> [`minecraft:remove_in_peaceful`](/docs/docs/entities/components/functional#minecraftremove_in_peaceful)组件，用于确定实体是否在和平难度下消失。
- <Add/> [`minecraft:leashable_to`](/docs/docs/entities/components/functional#minecraftleashable_to)组件，使玩家可以将自己正拴住的实体拴在该实体上。
- <Add/> [`minecraft:input_air_controlled`](/docs/docs/entities/components/deprecated#minecraftinput_air_controlled)组件，使玩家可以控制可骑乘的飞行实体。
- <Add/> [`minecraft:leashable`](/docs/docs/entities/components/functional#minecraftleashable)组件新增`can_be_cut`、`spring_type`与`rotation_adjustment`字段。
- <Add/> [`minecraft:body_rotation_always_follows_head`](/docs/docs/entities/components/functional#minecraftbody_rotation_always_follows_head)组件，确保实体的身体始终与头部对齐。

### 实体过滤器

- <Add/> 加入了`is_riding_self`过滤器，返回实体是否骑乘着自身。
- <Add/> 加入了`is_vehicle_family`过滤器，返回实体是否正骑乘指定家族的载具。

### 实体事件

- <Add/> 加入了`stop_movement`事件，使实体停止运动。可以指定`stop_vertical_movement`与`stop_horizontal_movement`分别控制竖直方向和水平方向的运动。
- <Add/> 加入了`set_home_position`事件，设置实体的原点位置为当前位置，需要`minecraft:home`组件。

## 图形

- <Add/> Vibrant Visuals 正式可用，支持 PBR 纹理、次表面散射、大气效果、按生物群系分别设置、水体、阴影、色彩分级与色调映射、关键帧。

## ScriptAPI

该版本开放了`@minecraft/server`的`2.0.0`版本与`@minecraft/server-ui`的`2.0.0`版本。脚本的运行底层机制发生了变化，世界完全加载完毕前只有少量内容可以执行，具体变化见微软的脚本 V2 概述。

### 系统

- <Add/> 开放了[`System.isEditorWorld`属性](/docs/docs/scripts/sapi/server/system/main#system-类)，用于获取是否为编辑器世界。
- <Add/> 系统前事件：开放了[`StartupEvent`类](/docs/docs/scripts/sapi/server/system/before_events#startupevent-类)与[`SystemBeforeEvents.startup`属性](/docs/docs/scripts/sapi/server/system/before_events)，可在世界启动之前执行代码。原`WorldInitializeBeforeEvent`类、`WorldInitializeBeforeEventSignal`类与`WorldBeforeEvents.worldInitialize`属性分别更名为`StartupEvent`类、`StartupBeforeEventSignal`类与`SystemBeforeEvents.startup`属性。
- <Add/> 系统前事件：开放了[`ShutdownEvent`类](/docs/docs/scripts/sapi/server/system/before_events#shutdownevent-类)与[`SystemBeforeEvents.shutdown`属性](/docs/docs/scripts/sapi/server/system/before_events)，可在世界关闭之前执行代码。
- <Add/> 开放了`TicksPerDay`常量，值为`24000`。

### 世界

- <Change/> 世界后事件：`WorldInitializeAfterEvent`类、`WorldInitializeAfterEventSignal`类与`WorldAfterEvents.worldInitialize`属性分别更名为`WorldLoadAfterEvent`类、`WorldLoadAfterEventSignal`类与`WorldAfterEvents.worldLoad`属性。
- <Change/> 移除了玩家对方块使用物品事件，连带移除`ItemUseOnBeforeEvent`类、`ItemUseOnBeforeEventSignal`类、`WorldBeforeEvents.itemUseOn`属性与对应的后事件，应改用`WorldBeforeEvents.playerInteractWithBlock`与`WorldAfterEvents.playerInteractWithBlock`。
- <Change/> 移除了`World.playSound`方法，应改用`Dimension.playSound`方法。
- <Add/> 为多个类加入了`isValid`属性，用于检查其中的数据是否有效，包括`Block`、`Camera`、`Component`、`Container`、`ContainerSlot`、`Effect`、`Entity`、`ScoreboardIdentity`、`ScoreboardObjective`、`ScreenDisplay`与`Structure`。
- <Add/> 开放了`CustomComponentParameters`类，返回自定义组件的参数值。

### 维度

- <Change/> 移除了`Dimension.runCommandAsync`方法，应改用`Dimension.runCommand`方法。
- <Add/> 开放了[`Dimension.getBlockAbove`方法](/docs/docs/scripts/sapi/server/dimension/main#getblockabove-方法)与[`Dimension.getBlockBelow`方法](/docs/docs/scripts/sapi/server/dimension/main#getblockbelow-方法)，用于获取特定位置上方或下方的方块。

### 方块

- <Add/> 开放了[`BlockMapColorComponent`类](/docs/docs/scripts/sapi/server/block/component#blockmapcolorcomponent-类)，用于获取方块在地图中显示颜色的相关属性。
- <Change/> 将`BlockComponentPlayerDestroyEvent`类重命名为`BlockComponentPlayerBreakEvent`类。

### 实体

- <Change/> `Entity.applyKnockback`方法的参数`directionX`、`directionZ`与`horizontalStrength`合并为`horizontalForce`，用于确定水平方向的击退强度。
- <Add/> 开放了[`Entity.lookAt`方法](/docs/docs/scripts/sapi/server/entity_and_player/entity#lookat-方法)，使实体面向特定位置。
- <Change/> 移除了`Entity.runCommandAsync`方法，应改用`Entity.runCommand`方法。
- <Change/> 移除了`EntityDamageCause`枚举中的`suicide`值。
- <Change/> 移除了`EntityGroundOffsetComponent`组件。

### 玩家

- <Add/> 开放了[`Player.graphicsMode`属性](/docs/docs/scripts/sapi/server/entity_and_player/player#player-类)，用于获取玩家当前使用的画质设置。
- <Change/> `GameMode`枚举中的成员全部重命名为首字母大写。

### 脚本 UI

- <Add/> 动作表单与模态表单现在支持添加大标题、分割线与普通文本。
- <Add/> 开放了[`ActionFormData.divider`方法](/docs/docs/scripts/sapi/server-ui/data_driven#divider-方法)、[`ActionFormData.header`方法](/docs/docs/scripts/sapi/server-ui/data_driven#header-方法)与[`ActionFormData.label`方法](/docs/docs/scripts/sapi/server-ui/data_driven#label-方法)。
- <Add/> 开放了[`ModalFormData.divider`方法](/docs/docs/scripts/sapi/server-ui/data_driven#divider-方法)、[`ModalFormData.header`方法](/docs/docs/scripts/sapi/server-ui/data_driven#header-方法)与[`ModalFormData.label`方法](/docs/docs/scripts/sapi/server-ui/data_driven#label-方法)。
