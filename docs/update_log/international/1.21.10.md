# 1.21.10

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

有关于 1.21.10 的完整更新日志，可见下方的中文 Minecraft Wiki。按照惯例，本文只介绍 1.21.10 的关键更改。

<WikiButton item="基岩版1.21.10"/>

## 实体

### 数据驱动实体组件

- <Change/> 装备到第二个槽位的盔甲，其[`minecraft:equippable`](/docs/docs/entities/components/functional#minecraftequippable)组件现在应用于`slot.armor.body`，而不是`slot.armor.torso`。此更改仅影响格式版本大于等于`1.21.10`的实体。
- <Add/> 引入了作为马等实体的额外盔甲槽`slot.armor.body`。该槽位被限制为单个盔甲物品，但需要全套盔甲效果，属于测试性更改。
- <Change/> `query.armor_texture_slot`、`query.armor_color_slot`与`query.armor_damage_slot`需要使用值为`4`才能检索到`slot.armor.body`槽位的相关盔甲信息。

## Molang

- <Add/> `query.state_time`，返回当前动画控制器状态所经过的时间，单位为秒，包含混合时间。该查询不再需要开启「即将推出的创作者功能」选项。

## ScriptAPI

该版本开放了`@minecraft/server`的`1.12.0`版本。

### 系统

- <Add/> 开放了[`System.runJob`方法](/docs/docs/scripts/sapi/server/system/main#system-类)与[`System.clearJob`方法](/docs/docs/scripts/sapi/server/system/main#system-类)，用于控制生成器运行。
- <Add/> 开放了[`System.waitTicks`方法](/docs/docs/scripts/sapi/server/system/main#system-类)，用于控制异步运行。

### 世界

- <Add/> 世界后事件：开放了[`PlayerInputPermissionCategoryChangeAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#playerinputpermissioncategorychangeafterevent-类)与[`WorldAfterEvents.playerInputPermissionCategoryChange`属性](/docs/docs/scripts/sapi/server/world/after_events)，可监听玩家输入权限的更改。
- <Add/> 世界后事件：开放了[`BlockExplodeAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#blockexplodeafterevent-类)与[`WorldAfterEvents.blockExplode`属性](/docs/docs/scripts/sapi/server/world/after_events)，可监听类似重生锚爆炸的事件。
- <Add/> 开放了[`GameRules.showDaysPlayed`属性](/docs/docs/scripts/sapi/server/world/main#gamerules-类)，用于读取游玩天数游戏规则。

### 方块

- <Add/> 开放了[`BlockPermutation.getTags`方法](/docs/docs/scripts/sapi/server/block/main#gettags-方法)与[`BlockPermutation.hasTag`方法](/docs/docs/scripts/sapi/server/block/main#hastag-方法)，用于获取方块标签。

### 实体

- <Add/> 开放了[`EntityRaycastOptions`接口](/docs/docs/scripts/sapi/server/dimension/raycast#entityraycastoptions-接口)的`ignoreBlockCollision`、`includeLiquidBlocks`与`includePassableBlocks`属性，用于配置实体的射线检测。
- <Add/> 开放了[`EntityTameableComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entitytameablecomponent-类)，用于获取实体的驯服相关属性。
- <Add/> 开放了[`EntityAgeableComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entityageablecomponent-类)，用于获取实体的成长相关参数。
- <Add/> 开放了[`EntityLavaMovementComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entitylavamovementcomponent-类)与[`EntityUnderwaterMovementComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entityunderwatermovementcomponent-类)，用于获取实体在熔岩与水下的移动参数。
- <Add/> 开放了[`EntityMovementComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entitymovementcomponent-类)、[`EntityMovementGlideComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entitymovementglidecomponent-类)与[`EntityMovementSwayComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entitymovementswaycomponent-类)，用于获取实体的移动参数。
- <Add/> [`EntityHitBlockAfterEvent.hitBlockPermutation`属性](/docs/docs/scripts/sapi/server/world/after_events#entityhitblockafterevent-类)开放，用于取得被击中的方块。
- <Change/> [`Entity.addEffect`方法](/docs/docs/scripts/sapi/server/entity_and_player/entity#addeffect-方法)自`1.3.0`起就已存在，本次变化的是返回值：由`void`改为`EntityEffect`。

### 玩家

- <Add/> 开放了[`PlayerInputPermissions`类](/docs/docs/scripts/sapi/server/entity_and_player/input#playerinputpermissions-类)、[`Player.inputPermissions`属性](/docs/docs/scripts/sapi/server/entity_and_player/player#player-类)与[`InputPermissionCategory`枚举](/docs/docs/scripts/sapi/server/entity_and_player/input#inputpermissioncategory-枚举)，用于获取与设置玩家的输入权限。

### 物品

- <Add/> 开放了[`EnchantmentTypes.getAll`方法](/docs/docs/scripts/sapi/server/item/enchantment#getall-方法)，用于获取全部可用附魔。
