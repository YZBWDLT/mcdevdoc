# 26.60

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';
import Fix from '/src/components/highlight/fix';

:::warning[注意]

:::

26.60 以收紧写法为主：`minecraft:collision_box`只接受数组，还有一批实体组件与`minecraft:transformation`的字段不能再写简写。命令侧与脚本侧的世界时钟在这一版转正，脚本开放`2.11.0`版本。

有关于 26.60 的完整更新日志，可见下方的中文 Minecraft Wiki。本文只介绍 26.60 的关键技术性更改。

<WikiButton item="基岩版26.60"/>

## 命令

- <Change/> [`/time`](/docs/docs/commands/all_commands#time)命令改为基于世界时钟，`/time query`的参数与`/time set`的写法都有变化。
    - `/time query`的可填值改为`day`、`daytime`、`gametime`与`time`。
    - `/time set`改为按时间标记设置，可指定`next`、`previous`与`stay`。
    - 新增`/time pause`与`/time resume`，用于暂停与恢复世界时钟。

## 物品

### 数据驱动物品组件

- <Change/> [`minecraft:durability_sensor`](/docs/docs/items/components#minecraftdurability_sensor)组件的`sound_event`参数、[`minecraft:swing_sounds`](/docs/docs/items/components#minecraftswing_sounds)组件的`attack_miss`、`attack_hit`与`attack_critical_hit`参数，以及[`minecraft:use_modifiers`](/docs/docs/items/components#minecraftuse_modifiers)组件的`start_sound`参数，现在除内置音效名外也接受`sound_definitions.json`中定义的声音事件。

### 战利品表

- <Change/> 物品数量被设为`0`后，战利品函数会继续执行，`set_count`等后续函数可以恢复数量并保留标识与数据。

## 方块

### 数据驱动方块组件

- <Change/> [`minecraft:collision_box`](/docs/docs/blocks/components#minecraftcollision_box)组件从格式版本`1.26.60`起只接受数组写法，单个碰撞箱也必须写成数组中的一项。旧的单对象写法不再有效。
- <Add/> [`minecraft:block_entity`](/docs/docs/blocks/components#minecraftblock_entity)组件的`container`参数新增`title`字段，用于设置容器界面的标题，接受 1\~256 个字符或本地化键名。不指定时标题为空。
- <Fix/> [`minecraft:geometry`](/docs/docs/blocks/components#minecraftgeometry)组件的`n_way_visual_rotation`在多人世界中无法从房主同步到其他客户端的问题。
- <Fix/> 方块几何体中布尔型骨骼可见性字段不被支持的问题。

### 方块特征

- <Add/> 紫颂植株与火现在暴露`minecraft:connection_north`、`minecraft:connection_east`、`minecraft:connection_south`、`minecraft:connection_west`、`minecraft:connection_up`与`minecraft:connection_down`六个状态。
- <Add/> 红石粉现在暴露`minecraft:redstone_north`、`minecraft:redstone_east`、`minecraft:redstone_south`与`minecraft:redstone_west`四个状态，取值`none`、`side`与`up`。

## 实体

### 数据驱动实体组件

- <Change/> 格式版本为`1.26.60`或更高的实体定义，在下列组件中使用了无效数据时会加载失败：
    - 移动类：`minecraft:movement.basic`、`minecraft:movement.sway`、`minecraft:movement.skip`、`minecraft:movement.generic`、`minecraft:movement.amphibious`、`minecraft:movement.fly`、`minecraft:movement.hover`、`minecraft:movement.dolphin`、`minecraft:movement.glide`、[`minecraft:pushable_by_block`](/docs/docs/entities/components/attributes#minecraftpushable_by_block)。
    - 其他组件：[`minecraft:rideable`](/docs/docs/entities/components/functional#minecraftrideable)、[`minecraft:dash_action`](/docs/docs/entities/components/functional#minecraftdash_action)、[`minecraft:rail_movement`](/docs/docs/entities/components/functional#minecraftrail_movement)、[`minecraft:scale_by_age`](/docs/docs/entities/components/functional#minecraftscale_by_age)、[`minecraft:strength`](/docs/docs/entities/components/functional#minecraftstrength)、[`minecraft:teleport`](/docs/docs/entities/components/functional#minecraftteleport)、[`minecraft:economy_trade_table`](/docs/docs/entities/components/functional#minecrafteconomy_trade_table)、[`minecraft:healable`](/docs/docs/entities/components/functional#minecrafthealable)、[`minecraft:inventory`](/docs/docs/entities/components/functional#minecraftinventory)、[`minecraft:spell_effects`](/docs/docs/entities/components/functional#minecraftspell_effects)、[`minecraft:transformation`](/docs/docs/entities/components/functional#minecrafttransformation)、[`minecraft:shareables`](/docs/docs/entities/components/functional#minecraftshareables)、[`minecraft:trail`](/docs/docs/entities/components/functional#minecrafttrail)。
    - AI 意向：[`minecraft:behavior.tempt`](/docs/docs/entities/components/ai#minecraftbehaviortempt)、[`minecraft:behavior.float_tempt`](/docs/docs/entities/components/ai#minecraftbehaviorfloat_tempt)、[`minecraft:behavior.send_event`](/docs/docs/entities/components/ai#minecraftbehaviorsend_event)、[`minecraft:behavior.panic`](/docs/docs/entities/components/ai#minecraftbehaviorpanic)。
- <Change/> 下列参数需要改写：
    - [`minecraft:movement.jump`](/docs/docs/entities/components/movement#minecraftmovementjump)的`jump_delay`、[`minecraft:timer`](/docs/docs/entities/components/sensors#minecrafttimer)的`time`、[`minecraft:economy_trade_table`](/docs/docs/entities/components/functional#minecrafteconomy_trade_table)的`cured_discount`与`max_cured_discount`只接受带`min`与`max`的对象。
    - [`minecraft:rideable`](/docs/docs/entities/components/functional#minecraftrideable)的`seats`、[`minecraft:shareables`](/docs/docs/entities/components/functional#minecraftshareables)的`items`改为只接受数组。
    - [`minecraft:buoyant`](/docs/docs/entities/components/functional#minecraftbuoyant)的`movement_type`只接受`none`、`waves`与`bobbing`，`liquid_blocks`的每一项必须是非空方块标识符或有效的方块描述符。
    - [`minecraft:healable`](/docs/docs/entities/components/functional#minecrafthealable)的`items`项必须是对象，其中的`effects`必须是效果对象组成的数组。
    - [`minecraft:attack`](/docs/docs/entities/components/functional#minecraftattack)的`damage`只接受标量或带`min`与`max`的对象，数组写法不再有效。
    - [`minecraft:transformation`](/docs/docs/entities/components/functional#minecrafttransformation)的`delay`不再接受纯数字，需写成`{"value": 秒数}`；`begin_transform_sound`与`transformation_sound`不再接受单个字符串，需写成音效名数组。
        - `delay.value`、`block_radius`与`block_max`不再接受负值，`block_assist_chance`与`block_chance`取值`0.0`\~`1.0`。
- <Add/> [`minecraft:trail`](/docs/docs/entities/components/functional#minecrafttrail)组件的`replaceable_blocks`参数，用于定义轨迹可以替换的方块，不指定时只替换空气。
- <Add/> [`minecraft:trail`](/docs/docs/entities/components/functional#minecrafttrail)组件的`radius`参数，用于定义以`spawn_offset`为中心的水平方形半径，取值`-1`\~`16`。取`-1`时沿用旧版的四角放置行为。
- <Add/> [`minecraft:trail`](/docs/docs/entities/components/functional#minecrafttrail)组件的`force_replace_matched_blocks`参数，为`true`时即使正常放置规则不允许也会替换匹配的方块。默认值为`false`。
- <Change/> [`minecraft:behavior.panic`](/docs/docs/entities/components/ai#minecraftbehaviorpanic)不再在生物被困住时每刻反复停止与启动。

### 其他

- <Add/> 新增`look_direction`脱离骑乘模式，乘客会在朝向方向上不是熔岩的相邻方块上下来。

## 世界生成

### 地物与结构

- <Change/> `mega_trunk`的`trunk_width`参数现在接受浮点区间，用于配置不同厚度，例如`[2, 3]`。旧写法仍然有效。
- <Add/> 拼图结构定义新增可选的`on_placed`参数，用于指定结构放置到世界后执行的回调。
- <Change/> 省略`may_replace`参数时，矿石地物的生成规则不再被跳过。

### 自定义维度

- <Change/> `minecraft:clouds`组件现在接受`-512`\~`512`范围内的任意云高度，不再限于`-64`\~`320`。

## ScriptAPI

该版本开放了`@minecraft/server`的`2.11.0`版本与`@minecraft/server-ui`的`2.3.0`版本。

### 世界

- <Add/> 世界时钟：[`WorldClockRegistry`类](/docs/docs/scripts/sapi/server/system/custom_world_clock#worldclockregistry-类)、[`WorldClock`类](/docs/docs/scripts/sapi/server/world/world_clock#worldclock-类)、[`TimeMarker`类](/docs/docs/scripts/sapi/server/world/world_clock#timemarker-类)与`WorldClockRegistrationOptions`接口，用于注册与查询世界时钟。
- <Add/> 世界时钟错误：`WorldClockRegistrationError`、`WorldClockReloadNewWorldClockError`、`WorldClockNotFoundError`、`WorldClockTimeMarkerNotFoundError`、`WorldClockRewindError`等类。
- <Add/> [`WorldSoundOptions.isBroadcast`属性](/docs/docs/scripts/sapi/server/general#worldsoundoptions-接口)，为`true`时由服务端广播播放，在广播范围内的玩家之间保持同步。
- <Add/> [`TextPrimitive`类](/docs/docs/scripts/sapi/server/world/primitive_shapes#textprimitive-类)的`lineGapHeight`属性，用于设置多行文本的行距。
- **世界前事件**
    - <Add/> 世界时钟重启前事件：开放了`WorldClockOnRestartBeforeEvent`，以及`WorldClockEventOptions`接口。
- **世界后事件**
    - <Add/> 世界时钟事件：开放了`WorldClockOnTimeModifiedAfterEvent`、`WorldClockOnPausedAfterEvent`、`WorldClockOnResumedAfterEvent`与`WorldClockOnTimeMarkerAfterEvent`，以及`WorldClockTimeMarkerEventOptions`接口。

### 维度

- <Add/> [`Dimension.spawnXp`方法](/docs/docs/scripts/sapi/server/dimension/main#spawnxp-方法)，用于在指定位置生成经验球。

### 实体

- <Add/> [`EntityIsTamedComponent`类](/docs/docs/scripts/sapi/server/entity_and_player/component#entityistamedcomponent-类)的`tamedToPlayer`与`tamedToPlayerId`属性，用于获取驯服该实体的玩家。

### 声音

- <Add/> [`SoundInstance`类](/docs/docs/scripts/sapi/server/general#soundinstance-类)新增`setVolume`、`setPitch`、`fade`、`seekTo`、`pause`与`resume`方法。
- <Add/> `PlayerSoundOptions`与`WorldSoundOptions`新增`loopCount`参数，取`-1`时只要保留对`SoundInstance`的引用就会一直循环。
- <Change/> `setVolume`与`fade`现在把音量作为声音定义音量的乘数，而不是直接替换。

### 界面

- <Add/> 自定义表单的提示框：`DropdownOptions`、`SliderOptions`、`TextFieldOptions`、`TextOptions`与`ToggleOptions`新增`tooltip`参数。
- <Add/> 按钮图标：`ButtonOptions.imageDetails`、`ImageDetails`、`MessageBoxButtonOptions`，以及`MessageBox.button1WithOptions`与`MessageBox.button2WithOptions`方法。

## 其他

- <Change/> `.mcstructure`结构文件支持 zlib 压缩。根级新增整型的`compression`标签，取`1`时整个结构以压缩形式存储，从游戏导出的结构现在默认压缩。
- <Add/> 位图字体可以在图集旁的 JSON 中用`ascii_character_height`与`ascii_character_y_offset`配置 ASCII 字形的高度与垂直偏移。
- <Change/> 多选包设置现在会在下拉菜单上方显示名称，并支持用`selection_text`自定义显示文本。
