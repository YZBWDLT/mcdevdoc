26.30 更新了混沌立方（Chaos Cubed），主要更新了硫方怪、硫黄洞穴、~_洞穴与山崖第 114514 部分_~。本次更新中最重要的两个功能包括：实体版本升级功能和 DDUI，除此之外也新增了多个实用脚本接口。

有关于 26.30 的完整更新日志，可见下方的中文 Minecraft Wiki。本文只介绍 26.30 的关键技术性更改。

<WikiButton item="基岩版26.30"/>

## 命令

详见[`/gamerule`命令](/docs/docs/commands/all_commands#gamerule)。

- <Remove/> `locatorBar`游戏规则。
- <Add/> `playerWaypoints`游戏规则，用于取代`locatorBar`游戏规则。
    - 接受两个值：`off`（玩家不会在定位栏上显示）、`everyone`（默认值，所有玩家均会在定位栏上显示）。
    - 之前将`locatorBar`设置为`true`的世界会自动迁移到值为`playerWaypoints`的`everyone`，`false`则会迁移到`off`。

## 世界生成

### 生物群系

- <Add/> `minecraft:surface_builder`组件
- <Add/> `minecraft:subsurface_builder`组件
- <Change/> 更新了`minecraft:noise_gradient`地表生成器类型。API 与之前相同，但所提供的噪声现在会被钳制在`[-1, 1]`区间内，而不是`[0, 1]`。

### 地物

- <Add/> 新的地物类型`height_difference_filter_feature`。此功能旨在用作过滤器，以根据靠近放置地物的高度差过滤掉位置。允许粉红色花簇仅在悬崖附近放置的示例用法：

    ```json
    {
        "format_version": "1.26.30",
        "minecraft:height_difference_filter_feature": {
            "description": {
                "identifier": "minecraft:pink_petals_near_cliff_feature"
            },
            "places_feature": "minecraft:pink_petals_feature",
            "min_required_negative_height_diff": 5,
            "search_radius": 5
        }
    }
    ```

    - `min_required_upward_height_diff`：指定向上所需的最小高度差。
    - `min_required_downward_height_diff`：指定向下所需的最小高度差。
    - `max_allowed_upward_height_diff`：指定允许向上的最大高度差。
    - `max_allowed_downward_height_diff`：指定允许向下的最大高度差。
    - `search_radius`：指定每个基本方向上的长度，过滤器会根据指定的差异检查方块。
    - `places_feature`：指定过滤成功时应该放置的地物。

- <Add/> `minecraft:structure_template_feature`的`block_intersection`约束中的`only_check_intersection_for_motion_blocking_blocks`字段。设置为`true`时，仅检查结构中的运动阻止方块是否与`block_allowlist`相交；设置为`false`时，检查除空白结构外的结构中所有方块的交集，包括空气。默认为`true`，以保留现有行为。运动阻止方块是阻止运动的完整方块。
- <Add/> `minecraft:structure_template_feature`的`ground_level`字段。指定哪个 Y 坐标会被视为地面高度，用作放置过程中的垂直偏移量，并确定结构的哪一层会被`leveled`和`grounded`约束检查。处于此坐标的所有非空气方块均定义了检查`leveled`和`grounded`约束的位置。若值超出结构的高度，则其会被钳制在最大的有效值，并发出内容日志警告。默认为`0`。
- <Add/> `minecraft:structure_template_feature`的`constraints`字段中新的`leveled`选项。指定时会确保结构的地面高度位于大部分平坦的地形上。包含`max_steepness`字段，用于定义放置位置与在结构的地面高度处采集的地形样本之间允许的最大高度差。有效的地形样本由固定方块和其上方的非固体方块组成。默认为`2`。
- <Change/> `minecraft:structure_template_feature`的`block_intersection`约束中的`only_check_intersection_for_motion_blocking_blocks`字段现在是可选的。

### 地表生成器

- <Add/> `NoiseDescriptor`模式定义，用作地表或地下生成器模式的一部分。其拥有以下字段：
    - `name`：用于初始化噪声的字符串。对生成值的定性方面没有影响。（必需）
    - `first_octave`：控制所生成噪声的常规频率特点。较低的值会产生频率较低的噪声。（必需）
    - `amplitudes`：控制所生成噪声中前 n 个倍程的衰减。（必需）
- <Add/> `NoiseBlockSpecifier`模式定义，用作地表或地下生成器模式的一部分。其拥有以下字段：
    - `noise`：与特定`NoiseBlockSpecifier`相关的噪声标识符。（非必需）
    - `threshold`：与所提供方块关联的最小采样噪声值。（非必需）
    - `range`：与所提供方块关联的采样噪声值的范围。（非必需）
    - `block`：噪声样本满足阈值或范围条件时放置的方块。（必需）
- <Add/> `minecraft:noise_gradient`地表和地下生成器现在拥有新的 API，其包含：
    - `noise`：一个`NoiseDescriptor`。（必需）
    - `non_replaceable_blocks`：不允许地表生成器替换的方块列表。将此列表留空或不指定将允许替换任何（非空气）方块。（非必需）
    - `noise_block_specifiers`：定义哪些噪声采样范围与哪些方块相关联的`NoiseBlockSpecifiers`数组。提供的范围在`[0, 1]`区间内有效，并且可能在其端点重叠。（必需）
