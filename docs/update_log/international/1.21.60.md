# 1.21.60

import WikiButton from '/src/components/button/wiki';
import Add from '/src/components/highlight/add';
import Change from '/src/components/highlight/change';

有关于 1.21.60 的完整更新日志，可见下方的中文 Minecraft Wiki。按照惯例，本文只介绍 1.21.60 的关键更改。

<WikiButton item="基岩版1.21.60"/>

## 命令

- <Add/> [`/inputpermission`](/docs/docs/commands/all_commands#inputpermission)命令支持控制更多输入权限：`dismount`、`jump`、`lateral_movement`、`mount`、`move_backward`、`move_forward`、`move_left`、`move_right`与`sneak`。

## 方块

### 数据驱动方块组件

- <Change/> [`minecraft:material_instances`](/docs/docs/blocks/components#minecraftmaterial_instances)组件的`ambient_occlusion`参数可以改为浮点类型。
- <Add/> [`minecraft:item_visual`](/docs/docs/blocks/components#minecraftitem_visual)组件，用于定义方块在物品栏中的外观。
- <Add/> [`minecraft:liquid_detection`](/docs/docs/blocks/components#minecraftliquid_detection)组件，用于定义方块在接触到液体后的行为。
- <Add/> `blocks.json`中的`ambient_occlusion_exponent`字段开放，用于定义方块的环境光遮挡指数，取代了已损坏的`brightness_gamma`字段。

## 实体

### 数据驱动实体组件

- <Add/> [`minecraft:renders_when_invisible`](/docs/docs/entities/components/functional#minecraftrenders_when_invisible)组件，保证实体在不可见（例如隐身）后仍然渲染。
- <Add/> [`minecraft:breedable`](/docs/docs/entities/components/functional#minecraftbreedable)组件新增`combine_parent_colors`字段，使子代实体的颜色可以由双亲的颜色混合而来。当不会发生颜色突变时，若双亲颜色相容，子代会得到双亲颜色的组合，组合规则与染料物品的混合规则相同；不相容时子代会随机得到双亲之一的颜色。
- <Add/> [`minecraft:looked_at`](/docs/docs/entities/components/functional#minecraftlooked_at)组件的`min_looked_at_duration`参数。

### 实体过滤器

- <Add/> 加入了`home_distance`过滤器，用于检查实体与其原点的距离，需要`minecraft:home`组件。

## Molang

- <Add/> `query.last_input_mode_used`，返回上一次使用的输入模式。
- <Add/> `query.touch_only_affects_hotbar`，若触摸控制仅影响触控条则返回`1.0`，否则返回`0.0`，仅可在资源包使用。
- <Add/> `query.last_input_mode_is_any`，可传入输入模式并返回是否有这些输入模式中的其中一种，仅可在资源包使用。

## ScriptAPI

该版本开放了`@minecraft/server`的`1.17.0`版本。

### 世界

- <Add/> 世界后事件：开放了[`PlayerInputModeChangeAfterEvent`类](/docs/docs/scripts/sapi/server/world/after_events#playerinputmodechangeafterevent-类)与[`WorldAfterEvents.playerInputModeChange`属性](/docs/docs/scripts/sapi/server/world/after_events)，可监听玩家输入模式的变更。

### 玩家

- <Add/> 开放了[`InputInfo`类](/docs/docs/scripts/sapi/server/entity_and_player/input#inputinfo-类)、[`InputMode`枚举](/docs/docs/scripts/sapi/server/entity_and_player/input#inputmode-枚举)与[`Player.inputInfo`属性](/docs/docs/scripts/sapi/server/entity_and_player/player#player-类)，用于获取玩家的输入操作信息。
