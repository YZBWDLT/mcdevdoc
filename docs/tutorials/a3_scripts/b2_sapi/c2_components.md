# 2.2 组件

:::warning[本文正在编辑，预计在数天内编写完成，仅供参考。]
:::

在上一节，我们已经了解了 SAPI 的使用方法，并用 20 道练习题进行了入门。其实，原则上来说，接下来其实已不再需要我（量筒）再介绍什么，因为读者可以很快上手我们未曾介绍过的内容。然而，为了向读者展示脚本相比于命令系统的功能上的优势，我们接下来还是要介绍一些关键的概念。

在本节，我们就来介绍**组件（Components）**。

在上一节，我们不难在物品堆叠 [ItemStack](/docs/docs/scripts/sapi/server/item/main#itemstack-类)、方块 [Block](/docs/docs/scripts/sapi/server/block/main#block-类) 和实体 [Entity](/docs/docs/scripts/sapi/server/entity_and_player/entity#entity-类) 的类中发现一些关键功能的“缺失”，比如我们如何获取物品的附魔属性？如何获取方块的物品栏（比如箱子）？如何获取实体的血量？虽然看似我们不能直接在这些类中获取这些“缺失”的属性，然而也确实可以注意到，这些属性都是特定的物品、方块、实体所独有的——或者更准确地来说，特性。这时候我们就需要调用它们的组件来获取这些特性。

同时，学习过模块 2：附加包的读者应该也对这东西印象十分深刻——无论是数据驱动物品方块实体，还是维度、生物群系等，都通过一个个的组件决定它们的功能的。
